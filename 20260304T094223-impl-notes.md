# Implementation Notes

## Decisions Made
- **Transition bound formula**: Replaced the hardcoded `for _step in 0..100` loop with a computed upper bound: `(max_final_review_retries + 1) * (3 + 2 * max_review_iterations) + 10`. This accounts for the worst-case traversal (every final-review cycle exhausts all review iterations) plus a 10-transition buffer for resume edge cases and the initial checkpoint. Uses `saturating_mul`/`saturating_add` to avoid overflow with extreme config values.
- **Atomic write temp file naming**: Used a fixed `.state.json.tmp` name (same directory) rather than a random tempfile. This keeps cleanup deterministic — at most one stale temp file can exist, and it's always overwritten on the next save. Same-directory placement guarantees the rename is atomic (same filesystem).
- **Error cleanup in atomic write**: Each step (write, flush, fsync, rename) cleans up the temp file on failure via `let _ = fs::remove_file(&tmp_path)` before returning the error. This ensures no partial temp files leak on error paths.
- **Parent directory sync**: Done as best-effort (`let _ = dir.sync_all()`) since not all filesystems require it and failure here is non-fatal for correctness — the rename itself is atomic.
- **Parse failure handling**: Changed `if let Ok(partial) = serde_json::from_str(...)` to an explicit `match` with early `return` on `Err`. The `warn!` log includes both the file path and the serde error message for debuggability. On parse failure, the function returns immediately without modifying any state fields, preserving checkpoint/artifact-derived values.
