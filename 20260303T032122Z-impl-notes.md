# Implementation Notes

## Decisions Made
- **Recursive navigation for borrow checker**: Used `navigate_table_recursive` and `ensure_tables_recursive` helper functions to satisfy Rust's borrow checker when traversing mutable TOML tables. The iterative approach fails because `get_mut()` borrows the table, preventing subsequent mutation. The recursive approach naturally limits borrow lifetimes.
- **Inline-table detection before mutation**: In `navigate_table_recursive`, we check `is_table` and `is_inline_table` via immutable borrows first, then perform the inline→regular conversion and take the mutable borrow only once. This avoids the E0499 double-mutable-borrow error.
- **`set_implicit(true)` on converted tables**: When converting inline tables to regular tables, we set `implicit = true` to avoid emitting redundant `[section]` headers in the TOML output when the table was originally inline.
- **Error-returning signatures**: Changed `navigate_tables_mut` from `Option<&mut Table>` to `Result<Option<&mut Table>>` and `ensure_tables` from `&mut Table` to `Result<&mut Table>`, so callers get explicit errors for non-table path segments rather than panics.
- **`save_sparse` atomicity on error**: When `ensure_tables` or `navigate_tables_mut` returns an error (non-table path segment), the function returns the error before the `fs::write` call, leaving the file untouched.
- **`merge_tables` handles both Item::Table and Value::InlineTable**: The merge logic now checks both cases on both the existing and default sides, converting inline tables to regular tables via `clone().into_table()` when nested merging is needed.
