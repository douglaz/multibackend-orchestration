# Implementation Notes

## Decisions Made
- Added `REQUIRED_LABELS` in `src/daemon/github.rs` as the canonical lifecycle label source with the exact five name/color/description tuples from the spec.
- Implemented `ensure_labels_best_effort(owner, repo)` in `src/daemon/github.rs` to run `gh label create` once per required label, skip silently on case-insensitive `"already exists"`, warn on other failures, and never return an error.

  2. `daemon::label_ensure_already_exists` (non-zero + `"already exists"` is non-fatal and non-warning)
  3. `daemon::label_ensure_hard_failure` (non-zero other error warns and continues)
