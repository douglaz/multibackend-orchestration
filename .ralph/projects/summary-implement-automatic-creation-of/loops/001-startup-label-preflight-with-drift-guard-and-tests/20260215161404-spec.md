# Feature: Startup Label Preflight with Drift Guard and Tests

## Description
Add a best-effort daemon startup preflight that ensures the five Ralph lifecycle GitHub labels (`ralph:ready`, `ralph:in-progress`, `ralph:completed`, `ralph:failed`, `ralph:aborted`) exist in the target repository before the runtime loop begins. The feature defines a canonical `REQUIRED_LABELS` constant, a non-failing `ensure_labels_best_effort` function, wires it into `execute_start()` via `spawn_blocking_op`, includes a drift-guard unit test, and updates all mock scripts and conformance tests.

## Acceptance Criteria
- [ ] `REQUIRED_LABELS` constant defined in `src/daemon/github.rs` with all five labels, their colors, and descriptions exactly as specified.
- [ ] `ensure_labels_best_effort(owner: &str, repo: &str)` added in `src/daemon/github.rs` that runs `gh label create` for each label without `--force`, skips silently on "already exists", warns on other failures, and never returns an error.
- [ ] `execute_start()` in `src/cli/daemon.rs` calls `ensure_labels_best_effort` after `preflight_check_gh` and repo slug resolution but before runtime config assembly / `runtime::run`, inside `spawn_blocking_op`, with join-failure warn-and-continue.
- [ ] Drift-guard unit test in `src/daemon/github.rs` asserts no duplicate label names in `REQUIRED_LABELS` and asserts the set contains all five workflow lifecycle labels.
- [ ] `daemon_mock_gh_script` in `src/validate/mock_scripts.rs` updated with `label)` case handling `create` subcommand (success by default).
- [ ] `daemon_mock_gh_edit_pr_script` in `src/validate/mock_scripts.rs` updated with `label)` case.
- [ ] `daemon_mock_gh_rebase_script` in `src/validate/mock_scripts.rs` updated with `label)` case.
- [ ] Inline mock scripts in `src/validate/tests_daemon.rs` that fail on unknown commands updated with `label)` case before the catch-all.
- [ ] Conformance test: daemon single-iteration run issues exactly 5 `label create` invocations.
- [ ] Conformance test: mock returns non-zero with "already exists" text; daemon continues without failure warning for that label.
- [ ] Conformance test: mock returns non-zero with a different error; daemon continues and a warning is emitted.
- [ ] All existing daemon validate tests remain green.
- [ ] Full project checks pass: `cargo check`, `cargo test`, `nix build`, `ralph validate`.
