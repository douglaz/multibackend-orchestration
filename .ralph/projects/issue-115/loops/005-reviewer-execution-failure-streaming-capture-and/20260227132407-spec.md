# Feature: Reviewer Execution-Failure Streaming Capture and Conformance Tests

## Description
Switch the reviewer retry loop in `run_review_with_retry()` from `backend.execute()` to `backend.execute_with_log()` so that raw backend output (stdout/stderr) is captured via streaming even when the backend fails with timeout or non-zero exit. This ensures partial output emitted before a failure is preserved in the reviewer log file for diagnosis. Additionally, add conformance tests that validate raw output persistence and outcome markers for reviewer execution-failure paths (timeout after partial output, non-zero exit after emitting output).

This addresses Final Review Amendments AM-PRD-LOG-001 and AM-PRD-LOG-002.
