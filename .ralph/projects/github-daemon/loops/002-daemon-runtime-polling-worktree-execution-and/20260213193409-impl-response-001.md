# Implementation Response (Iteration 1)

## Changes Made
1. **Abort path determinism (Required Change 1)**: Modified `collect_children` in `src/daemon/runtime.rs` to check the persisted task state before transitioning. If a task is already in a terminal state (e.g. `aborted` via `ralph daemon abort`), the runtime now preserves that state, only clears PID/PGID and cleans up the worktree — it does not overwrite with `completed`/`failed`.

2. **PR no-diff detection against base branch (Required Change 2)**: Replaced `git diff --quiet HEAD` in `src/daemon/github.rs` with a two-phase check: first checking working tree/index vs HEAD, then comparing `<base>...HEAD` using `git diff --quiet` with the merge-base of the detected default branch (origin/HEAD, origin/main, origin/master, or fallback). Added `detect_base_branch()` helper to resolve the base ref.

3. **Deterministic single-iteration mode (Required Change 3)**: Replaced the non-deterministic 200ms sleep in `--single-iteration` mode with `drain_all_children()` which blocks until all spawned children have exited (with a 300s safety timeout). This guarantees every dispatched task reaches a terminal state before the daemon exits, eliminating nondeterministic test outcomes.

4. **Startup worktree reconciliation for stale tasks (Required Change 4)**: Updated `reconcile_worktrees()` in `src/daemon/worktree.rs` to accept `active_task_ids` (non-terminal only) instead of all known IDs. Updated the caller in `runtime.rs` to filter out terminal tasks. Worktrees for completed/failed/aborted tasks are now cleaned up on startup, not just truly orphaned directories.

5. **Strengthened conformance tests (Required Change 5)**: All 8 Loop 2 runtime tests now verify concrete behavior:
   - `runtime_reconciliation_on_startup`: Asserts exact reconciliation log message, verifies stale PIDs (12345/67890) are cleared, checks completed tasks remain untouched.
   - `runtime_polling_filter_overflow`: Asserts overflow warning text in stderr, verifies max_concurrent limiting.
   - `runtime_worktree_isolation`: Verifies dispatch attempt is logged with task ID, checks worktree base directory creation.
   - `runtime_pid_pgid_persistence`: Verifies `pid=` in dispatch log, asserts terminal state has cleared PID/PGID after deterministic drain.
   - `runtime_idempotent_comments`: Uses comment counter file to verify second run does NOT increment comment count (marker de-duplication).
   - `runtime_pr_reuse_no_diff`: Tracks `pr create` invocation via file; asserts it is NOT called when existing PR found.
   - `runtime_pr_create_failure_terminal`: Asserts task stays completed and `pr_url` is null despite PR creation failure.
   - `runtime_single_iteration_mode`: Asserts no tasks remain `in_progress` after drain completes.

6. **Child stdio deadlock fix (Recommended Improvement 1)**: Changed `spawn_ralph_auto` in `src/daemon/process.rs` from `Stdio::piped()` to `Stdio::inherit()` for stdout/stderr, preventing deadlocks when children produce large output.
