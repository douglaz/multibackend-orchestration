# Implementation Notes

## Decisions Made
- Added a new `daemon` subsystem module in `src/daemon/mod.rs` with:
  - `DaemonTask` and `TaskState` (`pending`, `in_progress`, `completed`, `failed`, `aborted`)
  - `TaskStore` using `fs2` locks (`lock_shared` for `load`, `lock_exclusive` for `save`/`update_task`) over `.ralph/daemon/tasks.json`
  - Abort flow that resolves full task ID or bare issue number, rejects terminal states, performs SIGTERM→10s wait→SIGKILL on PID/PGID when present, updates state to `aborted`, and applies GitHub label changes via `gh` as best-effort warnings.
- Added `ralph daemon` CLI in `src/cli/daemon.rs` and wired it through `src/cli/mod.rs`:
  - `start` parses `--repo`, `--poll-seconds`, `--max-concurrent`, repeated `--label`
  - `status` reads/prints tasks (or `no daemon tasks`)
  - `abort <task-id-or-number>` updates `tasks.json` directly, independent of daemon runtime.
- Implemented daemon config defaults and merge behavior:
  - Global workspace fields in `src/config/global.rs`: `daemon_poll_seconds`, `daemon_max_concurrent`, `daemon_labels`, `daemon_repo`
  - Project overrides in `src/config/project.rs` (`[daemon]` section with optional overrides)
  - Merge utility `resolve_daemon_config` and `EffectiveDaemonConfig` in `src/config/mod.rs`
  - Exposed daemon values in `config show/get --project` and added `config set` support for daemon keys in `src/cli/config.rs`.
- Added and registered conformance suite:
  - New `src/validate/tests_daemon.rs` with all 8 required tests
  - Registered via `src/validate/mod.rs`.
- Exported module in `src/lib.rs` with `pub mod daemon;`.
