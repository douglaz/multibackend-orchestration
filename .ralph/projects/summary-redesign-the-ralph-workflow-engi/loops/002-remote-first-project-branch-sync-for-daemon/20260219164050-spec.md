# Feature: Remote-First Project Branch Sync for Daemon Worktrees

## Description
Loop 1 is complete: structured Ralph checkpoint commit parsing/building exists in `src/git/ralph_commit.rs` (`parse_last_ralph_commit`, `derive_position`, strict trailer validation).
The next missing foundational piece is remote-first branch alignment. Current daemon/worktree flow still relies on local refs and `origin/master` fallbacks, which violates the new durability contract.

Implement remote-first project branch sync so daemon-managed worktrees always derive branch state from remote truth:
- add `sync_project_branch(repo_root, issue_number)` per spec
- reset local project branch to `origin/ralph/issue-<n>` when it exists
- create from `origin/HEAD` when it does not
- never create project branches from local refs

This unlocks deterministic restart and crash recovery semantics for later checkpoint commit+push work.

## Acceptance Criteria
- [ ] `src/git/branch.rs` exposes `sync_project_branch(repo_root, issue_number)` that computes `ralph/issue-<n>` and runs `git fetch origin` first.
- [ ] If `origin/ralph/issue-<n>` exists, sync uses `git checkout -B ralph/issue-<n> origin/ralph/issue-<n>`.
- [ ] If `origin/ralph/issue-<n>` does not exist, sync uses `git checkout -b ralph/issue-<n> origin/HEAD`.
- [ ] No project branch creation/sync path uses `master`, `main`, or other local refs.
- [ ] Local-only commits on `ralph/issue-<n>` are discarded on sync (remote branch becomes source of truth).
- [ ] Daemon dispatch/worktree preparation invokes this sync before orchestration runs for an issue.
- [ ] Remote-first sync is only callable from daemon-managed worktrees (guarded path/entrypoint behavior).
- [ ] Error messages include issue number, branch name, and failed git operation for actionable recovery.
- [ ] Unit tests cover: remote branch exists, remote branch missing, and malformed/missing `origin/HEAD` failure handling.
- [ ] Integration tests verify unpushed local commit is removed after sync to remote branch tip.
- [ ] Validate conformance coverage is added for daemon restart behavior that re-aligns to remote branch state.

## Files to Modify/Create
- `src/git/branch.rs` - add `sync_project_branch` and remote-ref existence helpers.
- `src/daemon/worktree.rs` - remove `origin/master` bootstrap assumptions and route project branch setup through remote-first sync.
- `src/daemon/runtime.rs` - call remote-first branch sync during per-issue dispatch before `ralph run`.
- `src/validate/tests_daemon.rs` - add conformance cases for remote-first branch sync and local-commit discard semantics.
- `src/validate/mod.rs` - register any new validate test module if split from `tests_daemon`.
