# Feature: Remote-First Project Branch Sync for Daemon Worktrees

## Description
Loop 1 completed the structured Ralph checkpoint commit parser/builder. The next missing foundational capability is remote-first branch alignment: daemon worktrees still rely on local ref fallbacks (`origin/master`/`master`/`HEAD`) and do not enforce `origin/ralph/issue-<n>` as source of truth.

Implement `sync_project_branch(repo_root, issue_number)` and wire daemon dispatch/worktree prep to always fetch and align project branches from remote refs only. This enables deterministic restart and correct crash recovery semantics before phase-transition checkpointing is added.

## Acceptance Criteria
- [ ] `src/git/branch.rs` adds `sync_project_branch(repo_root, issue_number)` implementing: `git fetch origin`, then `git checkout -B ralph/issue-<n> origin/ralph/issue-<n>` if remote branch exists, else `git checkout -b ralph/issue-<n> origin/HEAD`.
- [ ] Sync logic never creates project branches from local refs (`master`, `main`, local `HEAD`, or local branch names).
- [ ] When `origin/ralph/issue-<n>` exists, local diverged commits are discarded by reset-to-remote behavior.
- [ ] When remote project branch is missing, project branch is created from `origin/HEAD` only.
- [ ] Missing or invalid `origin/HEAD` produces actionable error including issue number, branch name, and failed git operation.
- [ ] Daemon dispatch path calls remote-first project sync before invoking `ralph run`.
- [ ] Daemon worktree setup removes `origin/master`-first behavior and any local-ref bootstrap assumptions.
- [ ] Remote-first sync usage is constrained to daemon-managed worktree flows (not generic project CLI paths).
- [ ] Existing behavior for non-daemon branches/worktrees is not regressed.
- [ ] Unit tests in `src/git/branch.rs` cover: remote branch exists/reset, remote branch missing/create from `origin/HEAD`, missing `origin/HEAD` failure.
- [ ] Integration-style test verifies a local-only commit on `ralph/issue-<n>` is removed after sync.
- [ ] Validate conformance tests in daemon suite cover remote-first sync and restart realignment behavior.
- [ ] `cargo test` passes with new tests.

## Files to Modify/Create
- `src/git/branch.rs` - add remote-ref existence helpers and `sync_project_branch(...)` with strict remote-first behavior and unit tests.
- `src/daemon/worktree.rs` - remove `origin/master` bootstrap path; ensure worktree branch prep uses remote-first refs.
- `src/daemon/runtime.rs` - invoke project branch sync during per-issue dispatch before orchestration.
- `src/validate/tests_daemon.rs` - add conformance tests for remote branch create/reset/discard-local-commit semantics and restart realignment.
- `src/validate/mock_scripts.rs` - extend git/gh mocks for `origin/HEAD` and remote-branch presence/absence scenarios as needed.

## Dependencies
- Requires: Ralph Structured Commit Parser and Builder (Loop 1)
- Blocks: Phase transition commit+push checkpointing, remote-truth crash recovery semantics, and status/history migration to commit+label-derived state
