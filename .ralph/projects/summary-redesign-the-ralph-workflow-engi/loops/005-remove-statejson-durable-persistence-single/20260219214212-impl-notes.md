# Implementation Notes

## Decisions Made
- Replaced durable state file IO with reconstruction in `src/project/lifecycle.rs`:
  - Added `reconstruct_project_state(...)` and `reconstruct_project_state_from_project_dir(...)` to rebuild `ProjectState` from loop artifacts + git checkpoint derivation (`derive_position` / checkpoint commit parsing).
  - Added lightweight `project.toml` metadata (`name`, `parent_project`, `created_at`) so project identity survives without `state.json`.
- Removed state persistence from orchestration/runtime paths:
  - `src/workflow/orchestrator.rs` now starts from reconstructed state and no longer calls `persist_state()` or any state save/load path.
  - `src/project/state.rs` no longer has `load`/`save` methods tied to state-file persistence.
- Updated CLI/MCP consumers to use reconstruction / git+labels:
  - `status`: now derives phase/loop from git checkpoint position and lifecycle status from GitHub labels when project id is `issue-<n>`.
  - `history`: now derives checkpoint history from remote commit trailers; falls back to reconstructed loop listing when no checkpoints exist.
  - `tail` and MCP tail events: removed state-file reads and derive state events from reconstructed state.
  - Updated `project`, `rollback`, `run`, and MCP handlers to remove state-file dependency.
- Implemented repo-scoped daemon locking:
  - Added `DaemonLock` in `src/util/lock.rs` at `/tmp/ralph-daemon-<sha256(canonical_repo_root)>.lock` using non-blocking `flock`.
  - Added new `RalphError::DaemonLocked` with non-zero exit code.
  - `daemon start` acquires and holds locks for each repo before launching runtime tasks.
- Added/updated conformance coverage in `src/validate/tests_daemon.rs`:
  - Added lock contention test.
  - Added status/history derivation test (git trailers + labels).
  - Added crash-before-push recovery mapping test via existing remote-first discard coverage.
- Removed `state.json` / `tasks.json` path references from `src/**` codepaths and updated validate references accordingly.

## Spec Deviations
- `history` now primarily reports git checkpoint transitions; when no checkpoint commits are present it falls back to artifact-derived loop summaries for compatibility with non-issue/local projects.
- Full validate suite was not executed in this pass; only compile verification was run.
