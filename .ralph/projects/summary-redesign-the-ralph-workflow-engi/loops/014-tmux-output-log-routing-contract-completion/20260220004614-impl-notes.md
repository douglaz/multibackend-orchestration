# Implementation Notes

## Decisions Made

1. **Removed `persist_cli_output` entirely** rather than refactoring it, since the tmux backend was its sole caller and `LogWriter` (via `execute_with_log`) already handles attempt-level logging to `.ralph/tmp/logs`.

2. **Preserved `loop_dir` in `TmuxExecutionContext`** because it is still needed for `BackendInvocationContext` (session-aware argument rewriting). Only the log-persistence usage was removed.

3. **Used `setup_mock_backends` (not `_stable`)** for the conformance test since the standard mock pattern is sufficient when tmux intercepts execution before the backend command is invoked directly.

4. **Mock tmux script runs `new-window` shell commands inline** via `sh -c "$shell_cmd" &` to produce the exit/output files that `wait_for_exit_with_activity` polls for, enabling realistic end-to-end tmux-mode testing without a real tmux binary.

## Spec Deviations

- None. All acceptance criteria addressed.

## Changes Made

### `src/backend/tmux_backend.rs`
- Removed `persist_cli_output` import.
- Replaced the `persist_cli_output(ctx.loop_dir.as_deref(), ...)` call (lines 367-375) with a `debug!()` trace explaining the contract: tmux backend does not persist to loop dirs; attempt-level logging is handled by `LogWriter`.

### `src/backend/mod.rs`

### `tests/backend_tmux.rs`
- Added `tmux_backend_success_does_not_write_loop_dir_log_artifact`: runs a successful tmux backend execute with `loop_dir` set, asserts zero `agent-output-*.log` files in that directory.
- Added `tmux_backend_failure_does_not_write_loop_dir_log_artifact`: same for non-zero exit path.

### `src/validate/mock_scripts.rs`
- Added `mock_tmux_script()`: handles `has-session`, `new-session`, `new-window` (extracts and runs shell command), `set-option`, `list-windows`, `kill-window`.

### `src/validate/harness.rs`

### `src/validate/tests_run.rs`
- Added `tmux_enabled_no_loop_dir_logs` conformance test: enables tmux via config, injects mock tmux on PATH, runs `ralph run --loops 1`, asserts agent-output logs exist in `.ralph/tmp/logs` and zero `agent-output-*.log` files exist in loop directories.
