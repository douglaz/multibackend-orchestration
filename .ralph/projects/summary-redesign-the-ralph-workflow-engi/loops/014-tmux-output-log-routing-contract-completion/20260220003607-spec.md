# Feature: Tmux Output Log Routing Contract Completion

## Description
Loops 1, 2, 3, 4, 5, 6, 8, 10, and 12 completed the durable-state redesign, and completion loop 13 identified one remaining contract gap: tmux-backed executions still write durable `agent-output-*.log` files into loop directories. This feature removes loop-directory tmux log persistence and guarantees tmux output logging is routed only to `.ralph/tmp/logs`, with conformance coverage for tmux-enabled runs.

## Acceptance Criteria
- [ ] Running with tmux enabled produces zero `agent-output-*.log` artifacts under `.ralph/projects/<id>/loops/**`.
- [ ] Tmux invocation stdout/stderr diagnostics are persisted only under `.ralph/tmp/logs`.
- [ ] No code path in tmux execution uses loop artifact directories as a durable log sink.
- [ ] Session-rewrite behavior (`session_id` propagation and argument rewriting) remains unchanged for tmux and non-tmux backends.
- [ ] Add backend test coverage for tmux success/failure paths asserting no loop-dir log artifact creation.
- [ ] Add validate conformance coverage for tmux-enabled `run` asserting tmp-log presence and loop-dir log absence.
