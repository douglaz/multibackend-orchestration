# Feature: State-Free Test Suite Migration and Legacy State API Cleanup

## Description
Loops 1-5 already implemented the core runtime redesign from the prompt (remote-first git sync, structured checkpoint commits, label-driven daemon lifecycle, in-memory daemon state, daemon lock, and git+label CLI derivation). The remaining gap is test coverage still depending on deleted `state.json` APIs, which breaks `cargo test`. This feature migrates tests to the new reconstruction model and removes obsolete state-file recovery expectations.

## Acceptance Criteria
- [ ] `nix develop -c cargo test` passes without unresolved imports/methods tied to `load_project_state`, `save_project_state`, `ProjectState::load`, or `ProjectState::save`.
- [ ] No integration/unit test relies on reading or writing durable `.ralph/**/state.json` for workflow position.
- [ ] `tests/orchestrator.rs` assertions are migrated to `reconstruct_project_state(...)` and commit/artifact-derived state behavior.
- [ ] `tests/recovery.rs` is replaced/updated to validate state reconstruction from git/artifacts (not corrupted `state.json` recovery behavior).
- [ ] `tests/state.rs` validates in-memory state model semantics and serde behavior without file persistence APIs.
- [ ] Test scenarios for malformed latest Ralph checkpoint commit and default `loop=1, phase=planning` remain covered.
- [ ] Existing validate conformance coverage for daemon lock, label reconciliation, and status/history derivation remains passing.

## Files to Modify/Create
- `tests/orchestrator.rs` - remove deprecated lifecycle state I/O usage; assert via reconstructed state.
- `tests/recovery.rs` - replace legacy corrupt-`state.json` recovery cases with git/artifact reconstruction cases.
- `tests/state.rs` - remove persistence API tests; keep model/invariant/serde tests only.
- `tests/reconstruction.rs` - add focused integration tests for reconstruction edge cases (if splitting from `tests/recovery.rs` is cleaner).
