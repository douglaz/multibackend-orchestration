# Implementation Response (Iteration III)

## Changes Made

### RC1 + RC2: Fix 6 failing daemon conformance tests (label-driven migration)

All 6 failing conformance tests now pass under the label-driven runtime model:

1. **`daemon::cli_parse_start_status_abort`** — Updated abort assertion to test
   two paths: (a) abort without `--repo` fails with "--repo is required", and
   (b) abort with `--repo` but no in-progress labels fails with "not in-progress".
   Both use the full daemon mock gh for label query support.

2. **`daemon::start_validates_inputs_and_workspace`** — Replaced the simple
   `write_mock_gh(... "echo octo/demo")` with `write_daemon_mock_gh()` which
   handles all subcommands (`label create`, `issue list`, `repo clone`, etc.)
   that `daemon start` now exercises during startup.

3. **`daemon::runtime_worktree_isolation`** — Removed `write_tasks()` seeding.
   Now provides a `ralph:ready` issue via `MOCK_GH_ISSUES` env var. Verifies
   terminal state via `MOCK_GH_LABEL_LOG` (checks for `ralph:completed` or
   `ralph:failed`) instead of reading `tasks.json`.

4. **`daemon::runtime_task_fails_worktree_preserved`** — Removed `write_tasks()`
   and `load_tasks()`. Provides a `ralph:ready` issue via `MOCK_GH_ISSUES`.
   Uses a mock ralph that always exits 1 to trigger failure path. Verifies
   `ralph:failed` appears in label log and worktree is preserved at expected path.

5. **`daemon::daemon_status_multi_repo`** — Removed `write_tasks()` seeding for
   both repos. Status now queries GitHub labels, so test provides issues via
   `MOCK_GH_ISSUES` and uses `write_daemon_mock_gh()` for the mock. Asserts
   on issue numbers (10, 20) and "DAEMON ISSUES" header in stdout.

6. **`daemon::discover_project_id_ignores_dirs_without_state_json`** — Removed
   `write_tasks()` seeding and `load_tasks()` verification. Provides a
   `ralph:ready` issue (#500) via `MOCK_GH_ISSUES`. Worktree pre-creation and
   project directory setup remain unchanged. Verifies dispatch used
   `ralph run --project valid-proj` via args log.
