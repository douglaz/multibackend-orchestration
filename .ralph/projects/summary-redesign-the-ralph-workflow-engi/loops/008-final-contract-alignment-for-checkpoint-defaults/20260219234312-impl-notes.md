# Implementation Notes

## Decisions Made
- **Log path format**: `{log_dir}/{project_id}-{NNN}-{role}.log` (with loop) or `{log_dir}/{project_id}-{role}.log` (without loop). The `slug` parameter was dropped from the `LogWriter::open` API since logs are now in a flat directory under `.ralph/tmp/logs` and the project_id+loop+role triple is sufficient for deterministic collision-safe naming.
- **LogWriter API change**: Signature changed from `open(project_dir, loop_number, slug, role)` to `open(log_dir, project_id, loop_number, role)`. The `log_dir` is computed as `workspace.root.join("tmp/logs")` in the orchestrator.
- **Newest-only checkpoint validation**: `parse_last_ralph_commit` was rewritten to iterate commits and only validate the first (newest) `ralph(` prefixed commit. `list_ralph_commits` validates the newest strictly but silently skips older malformed commits via `if let Ok(parsed) = ...`.
- **No-checkpoint default**: Consistently `loop=1, phase=planning` everywhere. Removed the loop `1→0` remap from both `lifecycle.rs` and `status.rs`.
- **Artifact-based position fallback removed**: `infer_position_from_artifacts()` was deleted entirely. Position is always from checkpoint commits.
- **Status derivation unchanged**: `ProjectStatus::Pending` is still derived when `last_loop_number() == 0` (no loop artifacts), which correctly coexists with `current_loop=1` (meaning "next loop will be 1").
