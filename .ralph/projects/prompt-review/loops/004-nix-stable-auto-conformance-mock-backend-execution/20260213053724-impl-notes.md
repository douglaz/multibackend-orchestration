# Implementation Notes

## Decisions Made
- The root cause was that `auto_mock_script()` was defined inline in `tests_prompt_review.rs`, which was NOT listed in the `flake.nix` `postPatch` substituteInPlace list. The `postPatch` only patched `src/validate/mock_scripts.rs` (among validate files), so the inline script's `#!/usr/bin/env bash` shebang was not replaced with the Nix store bash path during sandboxed builds, causing execution failure.
- Moved `auto_mock_script()` from inline in `tests_prompt_review.rs` to the shared `mock_scripts.rs` module, which is already in the `postPatch` list. This ensures the shebang gets patched during `nix build`.
- The shared `auto_mock_script()` uses `echo "$INPUT" | grep -q` (pipe syntax) consistently with other mock scripts in `mock_scripts.rs`, instead of the herestring `grep -q ... <<<"$INPUT"` syntax used by the old inline version.
- Added `setup_mock_backends_stable()` helper to `harness.rs` that uses `bash <script>` invocation with cleared args, providing an interpreter-stable alternative. While this helper is not used by the current fix (due to model injection prepending `--model` flags that bash rejects), it remains available for future tests that need sandbox-safe mock setup without relying on shebangs at all.
- The test still uses `setup_mock_backends()` (not `_stable`) because the existing approach works correctly when the shebang is properly patched — the script ignores extra CLI args since it reads from stdin.

## Spec Deviations
- `setup_mock_backends_stable()` was added as specified but is not actively used by `auto_skip_flag_bypasses` because model injection (e.g., `--model opus` prepended to args by `claude.rs`/`codex.rs`) conflicts with `bash` as the command — bash interprets `--model` as an invalid option. The stable helper remains useful for tests that use bare backend specs without model injection.
- `tests_run.rs` did not require any changes — the existing tests already use `setup_mock_backends()` with scripts in `mock_scripts.rs` which are properly patched by `flake.nix`.
