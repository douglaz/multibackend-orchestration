# Implementation Notes

## Decisions Made
- Added `prompt_review_completed` to `ProjectState` with `#[serde(default)]` and initialized it to `false` in `ProjectState::new()` to keep legacy state JSON backward-compatible.
- Extended config plumbing end-to-end:
  - Global: `workflow.prompt_review_enabled` (default `true`), `workflow.prompt_review_backend` (default `"codex(gpt-5.3-codex-xhigh)"`), `templates.prompt_reviewer` (default `"templates/prompt_reviewer.md"`).
  - Project overrides: optional `prompt_review_*` workflow fields and optional `templates.prompt_reviewer`.
  - Effective config: resolved with project-over-global precedence, template path resolution via `resolve_template_path()`, and backend validation through `validate_backend_spec()`.
- Implemented `parse_prompt_reviewer_output()` and `PromptReviewerDecision` in `src/workflow/parser.rs`:
  - Requires H1 `# Prompt Review`.
  - Requires both `## Issues Found` and `## Refined Prompt`.
  - Enforces section ordering (`Issues Found` before `Refined Prompt`).
  - Extracts refined prompt from `## Refined Prompt` to EOF (supports nested `##` inside refined prompt).
  - Rejects refined prompts shorter than 10 chars after trimming.
- Added `default_prompt_reviewer_template()` in `src/prompts/templates.rs` starting with `"You are a prompt reviewer"` and including `{{prompt_content}}`.
- Updated `ralph init` to write `templates/prompt_reviewer.md` from `default_prompt_reviewer_template()`.
- Added `write_project_scoped_artifact()` in `src/project/artifacts.rs` with project-scoped frontmatter only: `artifact`, `project`, `backend`, `role`, `created_at`.
- Updated `src/cli/config.rs`:
  - `set_global_value()` and `set_project_value()` now support `workflow.prompt_review_enabled`, `workflow.prompt_review_backend`, and `templates.prompt_reviewer`.
  - Project-scope `config get/show` JSON now includes new workflow/template effective fields so lookups resolve correctly.
- Added/updated tests for parser behavior, config defaults/deserialization, state backward compatibility, prompt reviewer template content, project-scoped artifact schema, and init template coverage.
