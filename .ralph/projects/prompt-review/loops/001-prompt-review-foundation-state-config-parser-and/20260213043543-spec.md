# Feature: Prompt Review Foundation — State, Config, Parser, and Template

## Description
Implement the foundational layers required by the prompt review phase: the `prompt_review_completed` state field, all configuration plumbing (`workflow.prompt_review_enabled`, `workflow.prompt_review_backend`, `templates.prompt_reviewer`), the `parse_prompt_reviewer_output()` parser with extract-to-EOF semantics, the default prompt reviewer template, and the `write_project_scoped_artifact()` helper. This loop delivers all the building blocks that the orchestrator integration (next loop) will consume.

## Acceptance Criteria
- [ ] `ProjectState` has a `prompt_review_completed: bool` field with `#[serde(default)]` that defaults to `false`; deserializing legacy state JSON without the field succeeds and defaults to `false`
- [ ] `WorkflowConfig` has `prompt_review_enabled: bool` (default `true`) and `prompt_review_backend: String` (default `"codex(gpt-5.3-codex-xhigh)"`)
- [ ] `ProjectWorkflowOverrides` has `prompt_review_enabled: Option<bool>` and `prompt_review_backend: Option<String>`
- [ ] `EffectiveWorkflowConfig` has `prompt_review_enabled: bool` and `prompt_review_backend: String`, wired through `resolve_effective_config()` with two-tier precedence (project > global) and backend validation via `validate_backend_spec()`
- [ ] `TemplateConfig` has `prompt_reviewer: String` (default `"templates/prompt_reviewer.md"`); `ProjectTemplateOverrides` has `prompt_reviewer: Option<String>`; `EffectiveTemplateConfig` has `prompt_reviewer: PathBuf`, wired via `resolve_template_path()`
- [ ] `parse_prompt_reviewer_output()` in `src/workflow/parser.rs` returns `PromptReviewerDecision { body, refined_prompt }`, validates H1 `# Prompt Review`, requires `## Issues Found` before `## Refined Prompt`, extracts refined prompt from `## Refined Prompt` heading to EOF, rejects empty/short (<10 chars) refined prompts
- [ ] Unit tests for the parser cover: valid input, missing H1, missing `## Issues Found`, missing `## Refined Prompt`, empty refined prompt, too-short refined prompt, nested `##` headings in refined prompt, wrong section ordering
- [ ] `default_prompt_reviewer_template()` in `src/prompts/templates.rs` returns a template opening with `"You are a prompt reviewer"` and containing a `{{prompt_content}}` placeholder
- [ ] `ralph init` writes `templates/prompt_reviewer.md` using `default_prompt_reviewer_template()`
- [ ] `write_project_scoped_artifact()` in `src/project/artifacts.rs` writes a markdown file with project-scoped frontmatter (fields: `artifact`, `project`, `backend`, `role`, `created_at`; no `loop`/`iteration`/`iterations`)
- [ ] `src/cli/config.rs` supports `workflow.prompt_review_enabled`, `workflow.prompt_review_backend`, and `templates.prompt_reviewer` in both `set_global_value()` and `set_project_value()`
- [ ] Config unit tests verify defaults and backward-compatible deserialization
- [ ] State unit tests verify `prompt_review_completed` defaults to `false` on new and legacy state
