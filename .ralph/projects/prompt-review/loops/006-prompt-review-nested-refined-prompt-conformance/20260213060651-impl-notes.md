# Implementation Notes

## Decisions Made
- Created a dedicated `nested_heading_prompt_review_script()` in `mock_scripts.rs` rather than adding a flag/parameter to `standard_mock_script()`. This keeps the existing mock script unchanged and avoids any risk to the 7 existing prompt-review tests that rely on `standard_mock_script()`.
- The nested mock's refined prompt body contains 5 distinct `##`-level headings (`## Overview`, `## Architecture`, `## Acceptance Criteria`, `## Technical Notes`) plus a `###` heading (`### Component Registry`), providing thorough coverage of the extract-to-EOF parser semantics.
- Used `setup_mock_backends_stable()` (the Nix-safe wrapper approach) for the new test, consistent with the `stable_mock_with_modeled_backend` test pattern, ensuring the test passes in both native and Nix sandbox environments.
- No changes to `harness.rs` were needed — the existing helpers are sufficient.

## Spec Deviations
- None. All acceptance criteria are addressed as specified.

## Testing
- `cargo check` passes cleanly with the new code.
- The new test `prompt_review::nested_refined_prompt_headings` is registered in the `tests()` list and will be picked up by `ralph validate`.
- The test asserts:
  1. `prompt-original.md` exists with original content
  2. Rewritten `prompt.md` contains all 5 nested `##` headings and the final line of content (no truncation)
  3. `prompt-review.md` artifact exists with project-scoped frontmatter (no `loop` or `iteration` fields)
  4. `state.prompt_review_completed == true`
- Existing tests are unmodified and continue to compile. Full validation requires `nix build -L` or `ralph validate --bin <path>`.

### Changes summary

**`src/validate/mock_scripts.rs`** — Added `nested_heading_prompt_review_script()` function that returns a mock script where the prompt reviewer response contains nested `##` headings inside `## Refined Prompt` (5 H2 sections + 1 H3 section).

**`src/validate/tests_prompt_review.rs`** — Added `nested_refined_prompt_headings` test registered in `tests()`. The test sets up a project with the nested-heading mock, runs `ralph run --loops 1`, and asserts that:
- The original prompt is backed up to `prompt-original.md`
- The rewritten `prompt.md` contains all nested headings through the final line (no truncation at nested `##`)
- The `prompt-review.md` artifact has project-scoped frontmatter (no `loop`/`iteration` fields)
- State shows `prompt_review_completed = true`
