# Feature: Prompt Review Runtime Integration and Conformance Validation

## Description
Loop 1 already delivered the prompt-review foundation (state field, config plumbing, parser, template, and project-scoped artifact helper). This feature wires that foundation into the actual runtime path: execute prompt review once before loop planning, support explicit skipping on `run`/`auto`, enforce migration-safe behavior for existing projects, and add validate conformance coverage for the full prompt-review lifecycle.

## Acceptance Criteria
- [ ] `Orchestrator::run()` executes a one-shot prompt review step before the phase loop when all gates pass: `!state.prompt_review_completed`, `effective.workflow.prompt_review_enabled`, `!options.skip_prompt_review`, `state.loops.is_empty()`, and `state.completion_attempts.is_empty()`.
- [ ] Prompt review reads and rewrites the prompt file via `state.prompt_file` (no hardcoded `prompt.md` paths).
- [ ] Prompt review renders `effective.templates.prompt_reviewer`, invokes `effective.workflow.prompt_review_backend`, parses with `parse_prompt_reviewer_output()`, and treats parse/validation failures as hard errors.
- [ ] If `prompt-original.md` already exists in the project directory, prompt review fails with a validation error and does not overwrite backup or prompt content.
- [ ] On success, prompt review writes `prompt-original.md` backup, overwrites the prompt file with `refined_prompt`, writes `prompt-review.md` via `write_project_scoped_artifact()`, updates `state.prompt_hash` and `state.prompt_hash_at_loop_start`, sets `state.prompt_review_completed = true`, and persists state.
- [ ] Migration safety is enforced: for projects with existing loops/completion attempts and `prompt_review_completed == false`, runtime sets `prompt_review_completed = true` and persists without running reviewer.
- [ ] `RunOptions` includes `skip_prompt_review`; `ralph run --skip-prompt-review` and `ralph auto --skip-prompt-review` propagate this flag and mark `prompt_review_completed = true` without running prompt review.
- [ ] Dry-run output includes prompt review status (`completed`, `disabled`, `will be skipped`, or `pending (backend: ...)`) and performs no prompt-review side effects.
- [ ] `standard_mock_script()` recognizes prompt-review prompts (`"You are a prompt reviewer"`) and returns a valid `# Prompt Review` payload with required sections.
- [ ] New validate conformance suite covers: run-and-rewrite success path, run skip flag, auto skip flag, resume skip after completion, disabled config behavior, dry-run status reporting, and legacy migration behavior.
- [ ] CLI parser tests confirm `run --skip-prompt-review` and `auto --skip-prompt-review` parse successfully.

## Files to Modify/Create
- `src/workflow/orchestrator.rs` - add pre-loop prompt-review execution, migration guard, skip handling, state/hash persistence, and dry-run prompt-review status output.
- `src/cli/mod.rs` - add `--skip-prompt-review` to `RunArgs` and `AutoArgs`; add parse tests for both commands.
- `src/cli/run.rs` - pass `skip_prompt_review` into `RunOptions`.

- `src/validate/mod.rs` - register `tests_prompt_review`.
- `src/validate/tests_prompt_review.rs` - add new prompt-review conformance tests.
