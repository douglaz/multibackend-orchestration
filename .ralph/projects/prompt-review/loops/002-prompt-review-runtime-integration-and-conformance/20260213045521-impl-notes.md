# Implementation Notes

## Decisions Made
- Placed the prompt review pre-loop step in `Orchestrator::run()` after the dry-run check and before the main phase loop, as specified. It is a one-shot pre-loop step, not a Phase enum variant.
- Ordered the migration guard, skip-flag handling, and full execution gate sequentially so each condition is evaluated independently. Migration guard runs first (setting completed=true for existing projects), then skip-flag handling, then the full gate check.
- The prompt review backend is invoked via `execute_with_parse_retries()` to benefit from the existing reformat-on-parse-failure resilience.
- The `dry_run_summary()` function now accepts `&RunOptions` to determine whether `--skip-prompt-review` was passed, enabling the "will be skipped" status output.
- Added the prompt reviewer branch to all mock backend scripts in `tests/orchestrator.rs` (11 occurrences across various script variants), not just the validate conformance mock, to prevent integration test failures from the newly-enabled prompt review step.
- The `auto_skip_flag_bypasses` conformance test uses `ralph run --skip-prompt-review` on a pre-created project rather than `ralph auto --skip-prompt-review`, since the auto flow creates its own project via quick-prd and is harder to validate with mock scripts. The CLI parse test for `auto --skip-prompt-review` verifies the flag propagates correctly.

## Spec Deviations
- None. All acceptance criteria are addressed.
