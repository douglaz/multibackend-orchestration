# Feature: Harden PID/PGID handling with nix signal APIs

## Description
Replace all `unsafe` libc signal calls in `src/daemon/process.rs` with safe `nix` crate APIs for process probing (`pid_exists`) and process-group termination (`terminate_process_group`). Add safety guards that reject PID/PGID values ≤ 1, and add six targeted unit tests covering the new behavior including a real spawned-process-group kill test.

## Acceptance Criteria
- [ ] `nix` crate (with `signal` and `process` features) is added to `Cargo.toml` dependencies
- [ ] `pid_exists` returns `false` immediately for `pid <= 1` (guard)
- [ ] `pid_exists` uses `nix::sys::signal::kill(Pid::from_raw(pid), None)` instead of `unsafe { libc::kill(pid as i32, 0) }`
- [ ] `pid_exists` maps: `Ok(_)` → `true`, `Err(EPERM)` → `true`, `Err(ESRCH)` → `false`, other errors → `false`
- [ ] `terminate_process_group` guards against `pgid <= 1` (currently only guards `pgid == 0`; extend to also reject `pgid == 1`)
- [ ] `terminate_process_group` uses `nix::sys::signal::killpg(Pid::from_raw(pgid), Signal::SIGTERM)` for the initial SIGTERM
- [ ] `terminate_process_group` uses `nix::sys::signal::killpg(...)` with `Signal::SIGKILL` for the escalation
- [ ] `terminate_process_group` uses `nix::sys::signal::kill(Pid::from_raw(-(pgid as i32)), None)` or equivalent `killpg` probe for the existence check loop (replacing `unsafe { libc::kill(neg_pgid, 0) }`)
- [ ] `Err(ESRCH)` from `killpg` is treated as success (process group already dead)
- [ ] All `unsafe` blocks related to signal calls in `pid_exists` and `terminate_process_group` are removed
- [ ] The `unsafe` block in `spawn_ralph_auto` (for `setsid`) is left unchanged (out of scope)
- [ ] Test `test_pid_exists_self` exists and passes — probes own PID via `std::process::id()`
- [ ] Test `test_pid_exists_bogus` exists and passes — probes a very large PID (e.g., `u32::MAX - 1`) and asserts `false`
- [ ] Test `test_pid_exists_rejects_low_pids` exists and passes — asserts `pid_exists(0)` and `pid_exists(1)` both return `false`
- [ ] Test `test_terminate_process_group_noop_for_low_pgid` exists and passes — calls with pgid 0 and 1, asserts no panic
- [ ] Test `test_terminate_process_group_dead_pgid` exists and passes — calls with a PID known to not be a process group, asserts no panic
- [ ] Test `test_terminate_spawned_process_group` exists and passes — spawns a real child via `std::process::Command` with `.process_group(0)`, calls `terminate_process_group` on its PGID, asserts the child exits due to signal, uses bounded timeout and cleanup
- [ ] All six new tests are gated with `#[cfg(unix)]` where appropriate
- [ ] Existing `spawn_command_uses_long_idea_flag` test continues to pass
- [ ] `nix develop -c cargo check` passes
- [ ] `nix develop -c cargo test` passes
- [ ] Function signatures and return types remain unchanged
