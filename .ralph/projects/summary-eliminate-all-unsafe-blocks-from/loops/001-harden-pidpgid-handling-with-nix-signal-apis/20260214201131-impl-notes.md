# Implementation Notes

## Decisions Made
- Added `nix = { version = "0.29", features = ["signal", "process"] }` to `Cargo.toml` and accepted the corresponding `Cargo.lock` updates.
- Replaced `unsafe libc::kill` probing in `pid_exists` with `nix::sys::signal::kill(..., None)`, with explicit guards and mappings:
  - `pid <= 1` => `false`
  - `Ok(_)`/`EPERM` => `true`
  - `ESRCH`/other errors => `false`
- Reworked `terminate_process_group` to use safe `nix` APIs:
  - Guard returns immediately for `pgid <= 1`
  - Uses `killpg(..., SIGTERM)` then probe loop via `kill(Pid::from_raw(-pgid), None)`
  - Escalates with `killpg(..., SIGKILL)`
  - Treats `ESRCH` from `killpg` as success (already dead)
- Kept the `unsafe` `setsid` block in `spawn_ralph_auto` unchanged (out of scope).
- Added six Unix-gated tests in `src/daemon/process.rs`:
  - `test_pid_exists_self`
  - `test_pid_exists_bogus`
  - `test_pid_exists_rejects_low_pids`
  - `test_terminate_process_group_noop_for_low_pgid`
  - `test_terminate_process_group_dead_pgid`
  - `test_terminate_spawned_process_group` (real spawned process group with bounded wait + cleanup, asserts SIGTERM exit)
- Preserved existing `spawn_command_uses_long_idea_flag` test and existing function signatures.
