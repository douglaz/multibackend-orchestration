# Feature: Stale-base-branch fix for daemon project branch sync

## Description
Fix daemon-dispatched branching so new project branches always start from the latest remote base branch instead of `origin/HEAD`. This involves three coordinated changes:
1. Extend `sync_project_branch()` to accept a `base_branch` parameter, and after `git fetch origin`, force-sync the local base branch to match `origin/{base_branch}` via `git branch -f`.
2. Change `maybe_create_project_branch()` to use `origin/{base_branch}` (not bare `base_branch`) as the `from_ref` for parentless project branches.
3. Add `base_branch: String` to `DaemonRuntimeConfig`, populate it from workspace config at startup, and pass it through `dispatch_task()` into `sync_project_branch()`.

All existing tests that call `sync_project_branch` must be updated for the new signature, and new tests must cover the force-sync and custom-base-branch scenarios.
