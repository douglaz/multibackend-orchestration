# Feature: Fix stage-skip bug and add section-check retry

## Description
Fix two bugs in the PRD pipeline (`src/prd/pipeline.rs`):

1. **MaybeRerun forward-jump skips intermediate stages** — When `check_gaps_phase` or `apply_answers_phase` computes a `rerun_stage` that is *ahead* of the current stage (e.g., Research gap questions all have `impact_stage: Prd`), `MaybeRerun(Prd)` clears only stages >= Prd and jumps directly to Prd, skipping Synthesis entirely. Fix by (a) advancing to `next_stage(stage)` in the auto-apply path when `rerun_stage > stage`, and (b) capping `rerun_stage` to `fallback_stage` in `apply_answers_phase`.

2. **Deterministic section check is fatal with no retry** — When `check_stage_output()` detects missing required sections, the pipeline immediately returns `Err(RalphError::PrdMissingInfo)`. A single malformed LLM response kills the run. Fix by adding a per-stage retry counter (up to 2 retries), clearing the bad output and re-entering `RunStage` on failure, and falling through to LLM gap analysis on exhaustion instead of aborting.

Both fixes are accompanied by 4 new integration tests in `tests/prd.rs`.

## Acceptance Criteria
- [ ] In `check_gaps_phase`, when `rerun_stage > stage`, the pipeline advances to `next_stage(stage)` (or `ValidatePrd` if no next stage) instead of `MaybeRerun(rerun_stage)`
- [ ] In `apply_answers_phase`, `rerun_stage` is capped to `fallback_stage` via `.min()` so it never jumps forward past intermediate stages
- [ ] `PrdPipeline` struct has a new `stage_section_retries: BTreeMap<Stage, u8>` field initialized to empty in `::new()`
- [ ] A `MAX_SECTION_RETRIES` constant is set to `2`
- [ ] When `check_stage_output()` finds missing sections and retries remain, the pipeline clears `stage_outputs`, `stage_input_hashes`, and `skipped_stages` for that stage, logs a status message, and returns `Ok(PrdPhase::RunStage(stage))`
- [ ] When retries are exhausted, the pipeline logs a warning and falls through to LLM gap analysis (no fatal error)
- [ ] Test `forward_impact_stage_advances_without_skipping_stages` passes — verifies all 4 stages run when Research gap has `impact_stage: Prd` in non-interactive mode (9 backend calls)
- [ ] Test `apply_answers_caps_rerun_to_current_stage` passes — verifies interactive rerun is capped to Research, Synthesis is not skipped
- [ ] Test `missing_sections_retried_then_succeeds` passes — malformed first attempt, valid second attempt, pipeline succeeds (10 backend calls)
- [ ] Test `missing_sections_retry_exhaustion_continues_best_effort` passes — 3 malformed attempts, pipeline falls through to gap analysis and continues
- [ ] `nix develop -c cargo test` — all tests pass
- [ ] `nix build -L` — clean build
