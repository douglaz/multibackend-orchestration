# Implementation Notes

## Decisions Made
- Added `MAX_SECTION_RETRIES: u8 = 2` and `stage_section_retries: BTreeMap<Stage, u8>` to `PrdPipeline` in `src/prd/pipeline.rs`, initialized in `PrdPipeline::new()`.
- Replaced fatal deterministic section-check behavior in `check_gaps_phase` with retry logic: on missing required sections and retries remaining, clear `stage_outputs`, `stage_input_hashes`, and `skipped_stages` for that stage, log status, and return `PrdPhase::RunStage(stage)`.
- On section-check retry exhaustion, log a warning and continue to LLM gap analysis (no `PrdMissingInfo` abort).
- In non-interactive auto-apply flow in `check_gaps_phase`, added forward-jump guard: if `rerun_stage > stage`, advance to `next_stage(stage)` (or `ValidatePrd` when none) instead of `MaybeRerun(rerun_stage)`.
- In `apply_answers_phase`, capped rerun with `.min(fallback_stage)` to prevent forward jumps that skip intermediate stages.
- Added 4 integration tests in `tests/prd.rs`:

  - `apply_answers_caps_rerun_to_current_stage`
  - `missing_sections_retried_then_succeeds`
  - `missing_sections_retry_exhaustion_continues_best_effort`
