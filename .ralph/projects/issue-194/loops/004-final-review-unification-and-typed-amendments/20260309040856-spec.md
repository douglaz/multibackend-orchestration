# Feature: Final-Review Unification and Typed Amendments Config

## Description
Loops 1-3 already delivered the queue model, `ralph amend` CLI intake, planner/quick-dev queue draining, and completion guard.  
The next missing requirement is the opt-in final-review unification path: add first-class `amendments.unify_final_review` config support (global + project override), mirror accepted final-review amendments into the external queue when enabled, and keep planner prompt dedupe behavior correct.

## Acceptance Criteria
- [ ] Add typed config support for `amendments.unify_final_review` with default `false` in global config.
- [ ] Add project-level override support for `amendments.unify_final_review` (project value overrides global value).
- [ ] Effective config resolution exposes one merged `unify_final_review` boolean used by orchestrators.
- [ ] `ralph config set/get/show` supports `amendments.unify_final_review` for both global and project scopes.
- [ ] During final-review restart handling, if `unify_final_review == true`, each accepted amendment is enqueued as `AmendmentRequest` with:
- [ ] `source = final-review`
- [ ] `source_detail = reviewer backend`
- [ ] `priority = P2` (unless explicit mapping is later introduced)
- [ ] `id` and `body` copied from the accepted final-review amendment
- [ ] `created_at` set to current UTC timestamp
- [ ] If `unify_final_review == false`, no final-review amendments are mirrored to queue and existing behavior is unchanged.
- [ ] Planning-phase dedupe remains correct: when unify is enabled, drained `source == final-review` items are excluded from `external_amendments` text while still being drained/deleted from queue.
- [ ] Failure invariant: if mirroring one accepted amendment fails to enqueue, orchestration logs a warning and continues final-review restart flow; already-enqueued items remain valid and no malformed published queue files are created.
- [ ] Failure invariant: invalid `amendments.unify_final_review` config types fail config loading before orchestration starts; queue state is not mutated.
- [ ] Add/extend conformance tests to cover: opt-in mirroring of accepted final-review amendments, planner dedupe under unify mode, and default-off behavior.
