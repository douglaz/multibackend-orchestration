# Feature: CLI Amendment Intake Command

## Description
Loop 1 completed the amendment data model and crash-safe queue APIs in `src/project/amendments.rs`.  
The next logical feature is adding `ralph amend` so operators can enqueue external amendments from the CLI (inline text or `@file`) into the active project, with command-level validation and conformance coverage.

## Acceptance Criteria
- [ ] Add `ralph amend` command with args:
  `--project <id>` (optional), `--body <text|@path>` (required), `--priority <P0|P1|P2|P3>` (optional, default `P2`), `--id <id>` (optional, default `EXT-<YYYYMMDDHHMMSS>`).
- [ ] Command resolves workspace and project using existing active-project logic when `--project` is omitted.
- [ ] `--body @path` loads file content; plain `--body` uses inline text.
- [ ] Command validates priority before enqueue and returns non-zero on invalid values.
- [ ] Command constructs `AmendmentRequest` with `source = cli`, `source_detail = None`, and `created_at = Utc::now()`.
- [ ] Command calls `enqueue_amendment(project_dir, &request)` and prints the final queue filepath on success.
- [ ] Failure invariant: if project resolution fails, no queue directory/files are created or modified.
- [ ] Failure invariant: if `@path` read fails or request validation fails, enqueue is not attempted and no published `.json` queue file is created.
- [ ] Failure invariant: if enqueue fails during publish, command returns error and does not print a success path; only non-published temp artifacts (if any) may remain.
- [ ] CLI unit tests cover arg parsing, defaults, invalid priority rejection, and `@file` body handling.
- [ ] Integration test runs `ralph amend`, verifies produced JSON deserializes to `AmendmentRequest`, and verifies it drains successfully.
- [ ] Conformance tests include `ralph amend` command behavior and are registered in `src/validate/mod.rs`.

## Files to Modify/Create
- `src/cli/amend.rs` - New command implementation for body resolution, request construction, enqueue call, and output/error behavior.
- `src/cli/mod.rs` - Register `amend` module, add `Commands::Amend`, add `AmendArgs`, dispatch execution, add CLI parse tests.
- `tests/amend_cli.rs` - New integration test for end-to-end enqueue + deserialize + drain flow.
- `src/validate/tests_amendments.rs` - New conformance module for `ralph amend` command behavior.
- `src/validate/mod.rs` - Register `tests_amendments`.

- Blocks: Standard orchestrator planning-boundary drain/injection, quick-dev drain/injection, completion-request pending-queue guard, final-review unification opt-in behavior
