## Decisions Made
- Added `src/project/amendments.rs` with:
- `AmendmentRequest` (`id`, `body`, `priority` defaulting via serde, `source`, optional `source_detail`, `created_at`).
- `AmendmentPriority` (`P0|P1|P2|P3`, `Default = P2`, ordered/comparable derives).
- `AmendmentSource` (`Cli|FinalReview|File`, serde kebab-case for `cli|final-review|file`).
- Implemented `sanitize_id` to preserve `[A-Za-z0-9._-]` and replace all other chars with `_`.
- Implemented queue APIs:
- `enqueue_amendment`: creates `<project>/amendment-queue`, writes `.tmp-<uuid>.json`, renames to `<YYYYMMDDHHMMSS>-<sanitized-id>.json`, and appends `-<n>` on final-name collisions.
- `drain_amendment_queue`: reads `*.json` and `*.inflight` sorted lexicographically, claims `.json -> .inflight`, parses, deletes on success, quarantines malformed entries under `.quarantine` with unique names, skips `NotFound` race on claim-rename.
- `pending_amendment_count`: counts pending `*.json` and `*.inflight`, returns `0` when queue dir is missing.
- `format_external_amendments_for_prompt`: returns empty string for empty input; otherwise emits formatted id/priority/source/body blocks.
- Added validation for non-empty `id` and `body` during enqueue and drain parse.
- Registered module with `pub mod amendments;` in `src/project/mod.rs`.
- Added comprehensive unit tests in `src/project/amendments.rs` for:
- enqueue naming/rename + collision suffixing,
- deterministic drain ordering,
- post-drain cleanup,
- `.inflight` recovery,
- malformed JSON quarantine behavior,
- missing/empty queue behavior,
- priority default deserialization,
