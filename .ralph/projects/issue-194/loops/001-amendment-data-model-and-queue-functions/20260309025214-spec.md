# Feature: Amendment Data Model and Queue Functions

## Description
Create `src/project/amendments.rs` with the `AmendmentRequest` struct, `AmendmentPriority` and `AmendmentSource` enums, and the four required queue functions: `enqueue_amendment`, `drain_amendment_queue`, `pending_amendment_count`, and `format_external_amendments_for_prompt`. Register the new module in `src/project/mod.rs`. This is the foundational layer that all subsequent features (CLI, orchestrator integration, conformance tests) depend on.

## Acceptance Criteria
- [ ] `AmendmentRequest` struct is defined with `id`, `body`, `priority` (serde default P2), `source`, `source_detail` (Option), and `created_at` (DateTime<Utc> serialized as RFC3339).
- [ ] `AmendmentPriority` enum has variants `P0`, `P1`, `P2`, `P3` with `Default = P2`; derives `Serialize`, `Deserialize`, `Clone`, `Debug`, `PartialEq`, `Eq`, `PartialOrd`, `Ord`.
- [ ] `AmendmentSource` enum has variants `Cli`, `FinalReview`, `File`; derives `Serialize`, `Deserialize`, `Clone`, `Debug`, `PartialEq`, `Eq`.
- [ ] Missing `priority` in JSON input deserializes to `P2`.
- [ ] `enqueue_amendment(project_dir, req)` writes a temp file `.tmp-<uuid>.json` then renames to `<YYYYMMDDHHMMSS>-<sanitized-id>.json` in `<project_dir>/amendment-queue/`. Creates queue dir if missing. If final filename exists, appends `-<n>` before `.json`.
- [ ] `sanitized-id` keeps `[A-Za-z0-9._-]` and replaces all other characters with `_`.
- [ ] `drain_amendment_queue(project_dir)` lists `*.json` and `*.inflight` sorted lexicographically, renames each `.json` to `.inflight`, parses each `.inflight`, deletes on success, quarantines on parse failure with a warning log (path + error), and skips `NotFound` on rename (race condition). Other IO errors propagate as `Err`.
- [ ] `pending_amendment_count(project_dir)` returns the count of `*.json` and `*.inflight` files. Missing queue dir returns `Ok(0)`.
- [ ] `format_external_amendments_for_prompt(amendments)` returns a formatted string listing each amendment with its id, priority, source, and body — suitable for injection into planner/implementer prompts. Returns empty string for empty input.
- [ ] Quarantine dir is `<project_dir>/amendment-queue/.quarantine/`. Quarantined files get a unique name (original stem + timestamp or counter suffix) to avoid collisions.
- [ ] Module is declared as `pub mod amendments;` in `src/project/mod.rs`.
- [ ] Unit tests cover: enqueue naming and atomic rename, deterministic drain ordering, post-drain file removal, `.inflight` recovery on restart, malformed JSON quarantine, missing/empty queue returning empty results, priority default deserialization, and full serialization roundtrip.
