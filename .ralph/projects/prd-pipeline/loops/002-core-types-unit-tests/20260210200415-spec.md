# Feature: Core Types + Unit Tests

## Description
Loop 1 completed scaffolding/CLI wiring; the PRD module internals are still stubs. Implement the foundational typed schema for PRD state and gap analysis so downstream cache, interaction, and pipeline features can build on stable contracts. This loop should only add types and tests, not stage execution behavior.

## Acceptance Criteria
- [ ] `src/prd/state.rs` defines `Stage` with derives: `Debug`, `Clone`, `Copy`, `PartialEq`, `Eq`, `PartialOrd`, `Ord`, `Hash`, `Serialize`, `Deserialize`.
- [ ] `Stage::all()`, `Stage::index()`, and `Stage::artifact_filename()` are implemented with canonical order: `Ideation`, `Research`, `Synthesis`, `Prd` and filenames `01_ideation.md`..`04_prd.md`.
- [ ] `PrdPhase` is implemented with variants: `RunStage(Stage)`, `CheckGaps(Stage)`, `AskUser(Vec<Question>)`, `ApplyAnswers`, `MaybeRerun(Stage)`, `ValidatePrd`, `Done`.
- [ ] `PipelineContext` is implemented with typed maps (`BTreeMap<Stage, String>`) plus `idea`, `answers`, `answers_hash`, and `question_rounds`.
- [ ] `PrdMeta` is implemented with fields from the prompt contract, including `stage_timings: BTreeMap<Stage, f64>` and `rerun_stages: Vec<Stage>`.
- [ ] `src/prd/gaps.rs` defines `GapReport`, `MissingField`, `Ambiguity`, `SuggestedDefault`, `Question`, and `QuestionKind` with serde derives.
- [ ] `Question.impact_stage` is typed as `Stage` (not stringly typed).
- [ ] Unit tests in `src/prd/state.rs` verify stage ordering, index mapping, artifact filename mapping, and serde roundtrip for stage-bearing types.
- [ ] Unit tests in `src/prd/gaps.rs` verify JSON serde roundtrip for `GapReport` and `QuestionKind` variants (including `Choice` and typed `impact_stage`).
- [ ] `cargo test` passes with these new unit tests.

## Files to Modify/Create

- `src/prd/gaps.rs` - replace stub with gap-analysis data model types and unit tests.

- Blocks: Cache + lock + answers; Stages + deterministic parsers; Interaction layer; Pipeline + non-interactive happy path; Gap analysis + interactive flow; Validation + resume
