# Implementation Notes

## Decisions Made

- **Stage ordering**: Used explicit `PartialOrd` and `Ord` implementations based on index rather than derive, ensuring canonical ordering: Ideation(0), Research(1), Synthesis(2), Prd(3).
- **Artifact filenames**: Zero-padded 2-digit prefixes (`01_ideation.md`, etc.) for consistent lexical sorting.
- **BTreeMap usage**: Used `BTreeMap<Stage, T>` throughout for deterministic iteration order (stage order).
- **Question.impact_stage**: Typed as `Stage` enum, enabling direct min-stage calculation for rerun targeting without string parsing.
- **Serde derives**: All types include `Serialize` and `Deserialize` for JSON/YAML serialization.
- **Test coverage**: Unit tests verify stage ordering, index mapping, artifact filename generation, and serde roundtrip for all new types.

## Spec Deviations

None. All acceptance criteria implemented exactly as specified.
