# Implementation Notes

## Decisions Made
- Added `serde_yaml = "0.9"` to `Cargo.toml` and introduced `RalphError::Yaml(serde_yaml::Error)` for YAML error plumbing.
- Created PRD scaffolding under `src/prd/` with `mod.rs` plus stub submodules: `state`, `pipeline`, `stages`, `gaps`, `interaction`, `answers`, and `cache`.
- Exported the new module from `src/lib.rs` with `pub mod prd;`.
- Added PRD-specific `RalphError` variants in `src/error.rs` and mapped exit codes: `PrdPipelineFailed` -> `10`, `PrdValidationFailed` -> `11`, `PrdMissingInfo` -> `12`, `PrdCacheMismatch` -> `2`.
- Added `src/cli/prd.rs` with full `PrdArgs` surface (`--idea`, `--non-interactive`, `--interactive`, `--ask-max`, `--answers`, `--resume`, `--dry-run`, `--backend`) and a skeleton `execute()` that:
  - discovers workspace,
  - resolves/validates backend spec,
  - creates backend registry with tmux disabled,
  - gets backend via `get_or_create_for_spec`,
  - performs backend health check,
  - auto-detects non-TTY stdin for non-interactive mode,
  - prints a placeholder not-yet-implemented message.
- Wired CLI dispatch in `src/cli/mod.rs` with `mod prd;`, `Commands::Prd(prd::PrdArgs)`, and match-arm dispatch to `prd::execute(args).await`.
- Added parser tests for the new command and interactive-flag conflict handling.
