# Implementation Notes

## Decisions Made
- Implemented `CacheManager` in `src/prd/cache.rs` with cache directory creation at `.ralph/prd/<idea_hash>`, where `idea_hash` is the first 12 chars of `sha256_hex(idea)`.
- Added `PrdLock` RAII guard in `src/prd/cache.rs` using `fs2` exclusive file locking on `.lock`, with unlock-on-drop behavior.
- Added stage artifact persistence (`read_stage_output`/`write_stage_output`), metadata JSON persistence (`read_meta`/`write_meta`), and missing info report persistence (`write_missing_info_report`) in `src/prd/cache.rs`.
- Implemented hash-based skip logic in `CacheManager` via `compute_stage_input_hash` and `should_skip_stage`, hashing idea + current answers + prior stage outputs.
- Implemented resume mismatch validation in `CacheManager::validate_resume_idea()` returning `RalphError::PrdCacheMismatch` when `meta.json` idea differs.
- Implemented `AnswerStore` in `src/prd/answers.rs` with YAML `load`/`save`, `merge` overwrite semantics, and deterministic `hash()` via serialized answers.
- Exposed `AnswerStore`, `CacheManager`, and `PrdLock` from `src/prd/mod.rs`.
- Added unit tests in `src/prd/cache.rs` and `src/prd/answers.rs` for all requested behaviors: roundtrips, merge semantics, hash stability, skip logic, resume mismatch detection, and lock RAII behavior.
