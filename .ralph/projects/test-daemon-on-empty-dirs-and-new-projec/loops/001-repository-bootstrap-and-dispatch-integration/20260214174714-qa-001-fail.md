# QA: FAIL

## Failures
1. No-`origin` PR flow does not skip push/PR; it attempts push and fails.
   - Command:
     ```bash
     PATH="$TMP:$PATH" RALPH_DAEMON_BIN="$TMP/mock_ralph_commit" ./result/bin/ralph daemon start --repo acme/widgets --single-iteration
     ```
   - Expected: warning about missing `origin`, skip push/PR, task remains `completed`.
   - Actual stderr:
     ```text
     warning: failed to push branch ralph/daemon/acme-widgets-801 ... fatal: 'origin' does not appear to be a git repository
     ```
     Task did end `completed`, but push was attempted instead of being skipped.

2. Invalid-base/single-commit `has_diff` path produces false positive and triggers push.
   - Command (single-commit `trunk` repo, child makes no commit):
     ```bash
     PATH="$TMP:$PATH" RALPH_DAEMON_BIN="$TMP/mock_ralph_noop" ./result/bin/ralph daemon start --repo acme/widgets --single-iteration
     ```
   - Expected: invalid/missing revision treated as no diff; no push attempt.
   - Actual stderr:
     ```text
     fatal: ambiguous argument 'HEAD~1...HEAD': unknown revision ...
     warning: failed to push branch ralph/daemon/acme-widgets-1001 ...
     ```
     This is the false “has changes” behavior the spec says to avoid.

3. Required validate coverage for new daemon bootstrap/PR/diff behaviors is missing.
   - Command:
     ```bash
     ./result/bin/ralph validate --bin ./result/bin/ralph --list > /tmp/qa-validate-list.txt
     rg 'daemon_bootstrap_non_git_dir|daemon_bootstrap_zero_commit_repo|daemon_bootstrap_idempotent|daemon_bootstrap_existing_repo_noop|daemon_pr_no_origin_skips_push_and_pr|daemon_pr_no_default_branch_fallback_head_only|daemon_has_diff_invalid_base_returns_false' /tmp/qa-validate-list.txt
     ```
   - Expected: required test names present.
   - Actual: no matches.
   - Also, required implementation hooks are absent (e.g. no `has_origin_remote` in `src/daemon/github.rs`).

## Suggested Fixes
1. Add `github::has_origin_remote()` and guard PR flow in `handle_pr_flow()` so missing `origin` logs a warning and returns before push/PR.
2. Harden `github::has_diff()`:
   - run diff via `output()` and inspect stderr,
   - if failure is invalid/missing revision, return `Ok(false)` with warn/debug log,
   - keep non-revision git failures as real errors.
3. Add and register required conformance coverage:
   - `daemon_bootstrap_non_git_dir`
   - `daemon_bootstrap_zero_commit_repo`
   - `daemon_bootstrap_idempotent`
   - `daemon_bootstrap_existing_repo_noop`
   - `daemon_pr_no_origin_skips_push_and_pr`
   - `daemon_pr_no_default_branch_fallback_head_only`
   - `daemon_has_diff_invalid_base_returns_false`
   and extend `src/validate/harness.rs` with bare/zero-commit constructors.
