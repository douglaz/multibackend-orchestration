# Implementation Notes

## Decisions Made
- Added `pub async fn ensure_repo_ready(repo_root: &Path) -> Result<()>` in `src/daemon/bootstrap.rs`.
- Implemented idempotent bootstrap logic:
- Initialize git with `git init` when `repo_root` is not a repo.
- Detect and reject bare repos with typed `RalphError::Unsupported`.
- Detect unborn `HEAD` and create exactly one empty bootstrap commit (`ralph: bootstrap empty commit`) using `-c commit.gpgsign=false` and `--no-verify`.
- Set repo-local fallback identity (`ralph-daemon` / `ralph@localhost`) only when `user.name`/`user.email` are missing.
- Initialize `.ralph` via existing internal workspace init (`crate::cli::init::create_workspace`) only when missing.
- Exported module in `src/daemon/mod.rs` with `pub mod bootstrap;`.
- Integrated bootstrap into `dispatch_task()` in `src/daemon/runtime.rs` before `create_worktree()`.
- Mapped dispatch errors to terminal task failure by calling `complete_task(..., TaskState::Failed)` in both poll-dispatch and re-adopt dispatch paths.

## Spec Deviations
- Kept this pass scoped to loop-1 bootstrap/dispatch integration only. PR guard changes, `has_diff()` invalid-base handling, validate harness extensions, and new daemon conformance tests were not implemented in this iteration.
