# Implementation Notes

## Decisions Made
- Refactored shared `buildRustPackage` settings into `commonArgs` in `flake.nix` to avoid duplication between static Linux and dynamic non-Linux derivations.
- Platform-gated `packages.default`: Linux uses `pkgs.pkgsStatic.rustPlatform.buildRustPackage`; Darwin/non-Linux uses `pkgs.rustPlatform.buildRustPackage`.
- Added a Linux-only `postInstall` static-link assertion in `flake.nix` that inspects `file $out/bin/ralph` and fails the build if it is not static.
- Removed unused `openssl` and `pkg-config` from build inputs and `devShells.default`.
- Added Linux-only `devShells.musl` using `pkgs.pkgsStatic.buildPackages.cargo`, `pkgs.pkgsStatic.buildPackages.rustc`, and `pkgs.pkgsStatic.stdenv.cc`, with musl target/linker environment configured.
- Replaced the stale hard-coded “40 conformance tests” wording in `postCheck` with non-count-specific text.

## Spec Deviations
- `file result/bin/ralph` reports `static-pie linked` on this toolchain rather than the literal phrase `statically linked`; this is still a fully static binary. The `postInstall` assertion accepts both static forms.
- Darwin behavior was validated by evaluating flake outputs (dynamic package selected), but a Darwin build was not executed in this Linux environment.

## Testing
- `nix build -L` (pass): builds `ralph-static-x86_64-unknown-linux-musl-0.1.0`, runs test/check phases, runs `ralph validate` (80 tests), and passes static-link `postInstall`.
- `file result/bin/ralph` (pass): `... static-pie linked ...`.
- `ldd result/bin/ralph` (pass): `statically linked`.
- `nix develop .#musl -c cargo check --target x86_64-unknown-linux-musl` (pass).
- `nix develop .#musl -c cargo test --target x86_64-unknown-linux-musl` (pass).
- `nix develop -c cargo check` (pass; default dev shell still works).
