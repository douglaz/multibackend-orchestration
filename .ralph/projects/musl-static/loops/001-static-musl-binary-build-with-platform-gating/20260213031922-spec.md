# Feature: Static musl binary build with platform gating

## Description
Replace the default `nix build` output on Linux with a fully static, musl-libc-linked binary using `pkgsStatic.rustPlatform.buildRustPackage`. Darwin outputs fall back to the existing dynamic glibc-based build since musl is Linux-only. Remove the unused OpenSSL and pkg-config dependencies from all derivations and dev shells. Add a `postInstall` static-linkage assertion so the Linux build fails automatically if the binary is not fully static. Add a dedicated `devShells.musl` (Linux only) that provisions a musl Rust toolchain for `cargo check`/`cargo test` against `x86_64-unknown-linux-musl`. Factor shared derivation arguments into a `commonArgs` attrset to avoid duplication. Fix the stale hard-coded "40" test count in the `postCheck` comment.

## Acceptance Criteria
- [ ] On Linux: `nix build` produces a statically-linked binary at `result/bin/ralph`
- [ ] On Linux: `file result/bin/ralph` reports `statically linked`
- [ ] On Linux: `ldd result/bin/ralph` reports `not a dynamic executable` (or exits non-zero)
- [ ] On Linux: the Nix derivation's `postInstall` phase automatically verifies static linking; the build fails if the binary is not fully static
- [ ] `nix build` succeeds including the existing `postCheck` conformance tests (`ralph validate`)
- [ ] On Linux: `nix develop .#musl -c cargo check --target x86_64-unknown-linux-musl` succeeds
- [ ] On Linux: `nix develop .#musl -c cargo test --target x86_64-unknown-linux-musl` succeeds (all existing tests pass)
- [ ] The `devShells.default` continues to work for local development (remains glibc-based, unchanged minus unused deps)
- [ ] No OpenSSL dependency remains in the build (it is unused)
- [ ] On Darwin: `nix build` continues to produce a working (dynamically linked) binary using the existing glibc-based derivation; Darwin outputs are unaffected

## Files to Modify/Create
- `flake.nix` - Platform-gate `packages.default`: Linux uses `pkgsStatic.rustPlatform.buildRustPackage` (static musl), Darwin uses `pkgs.rustPlatform.buildRustPackage` (dynamic). Remove `openssl` and `pkg-config` from all build inputs and dev shell. Add `postInstall` static-link assertion to the Linux derivation. Add `devShells.musl` (Linux only) with musl Rust toolchain. Factor shared args into `commonArgs`. Remove stale "40" test-count comment.
