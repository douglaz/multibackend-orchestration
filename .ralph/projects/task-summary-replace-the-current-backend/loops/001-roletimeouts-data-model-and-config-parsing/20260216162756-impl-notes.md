# Implementation Notes

## Decisions Made
- Added `RoleTimeouts` to `src/config/global.rs` with six role fields, `Default` at `7200`, and `for_role(&str) -> Option<u64>`.
- Extended `BackendConfig` with `timeouts: RoleTimeouts` and changed deprecated `timeout_seconds` to `Option<u64>` with `skip_serializing_if = "Option::is_none"`.
- Updated partial backend deserialization so `[backends.<backend>.timeouts]` can be partial and missing role keys auto-fill to `7200`.
- Added load-time deprecated key detection in `GlobalConfig::load` and emit warning text exactly:
  `warning: backends.<backend>.timeout_seconds is deprecated and ignored at runtime; use backends.<backend>.timeouts.<role>`.
- Updated CLI config handling in `src/cli/config.rs`:
  - `config set backends.{claude|codex}.timeouts.{planner|implementer|reviewer|qa|completer|reformatter}`
  - Deprecated `config set backends.{claude|codex}.timeout_seconds` now persists `Some(value)` and prints warning.
- Updated backend constructors in `src/backend/claude.rs` and `src/backend/codex.rs` to handle `Option<u64>` via `unwrap_or(7200)`.
- Added/updated tests in:
  - `src/config/global.rs`
  - `src/cli/config.rs`
  - `tests/init_command.rs`
  - `tests/orchestrator.rs`
  - `tests/mcp_handlers.rs`
  - `src/validate/tests_commands.rs`
  - `src/validate/tests_mcp.rs`
- Removed one unused import in `src/validate/tests_auto_init.rs` to keep `cargo check` warning-free.

## Spec Deviations
- `timeout_seconds` default behavior is implemented as `None` (not `Some(7200)`) so it is only serialized when explicitly set, while runtime still defaults to `7200` via backend constructors. This matches the “deprecated storage only” and “serialize only when explicitly set” requirements.
