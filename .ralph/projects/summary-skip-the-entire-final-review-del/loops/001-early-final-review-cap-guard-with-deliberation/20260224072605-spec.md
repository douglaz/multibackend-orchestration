# Feature: Early Final-Review Cap Guard with Deliberation Skip

## Description
Add an early guard in `run_final_review_phase` that checks whether the restart cap has been reached immediately after computing `restart_count` and `round`. When the cap is hit, the function force-completes the project without invoking any deliberation backend calls (reviewer proposals, planner positions, votes, arbiter). Additionally, remove the existing late/post-deliberation restart-cap guard that currently handles this case after deliberation has already run. This prevents wasted backend calls when deliberation results would be discarded anyway.

## Acceptance Criteria
- [ ] Early cap guard is placed immediately after `restart_count`/`round` computation and before any reviewer/proposal deliberation begins
- [ ] Guard condition is `restart_count >= effective.workflow.max_final_review_restarts`
- [ ] When cap is reached, `write_force_complete_artifact(project_dir, round, restart_count, effective.workflow.max_final_review_restarts, &BTreeSet::new())` is called
- [ ] When cap is reached, state is set to `status = ProjectStatus::Completed`, `current_phase = Phase::Completing`, `phase_iteration = 1`
- [ ] When cap is reached, a log line containing `"skipping deliberation"` is emitted
- [ ] When cap is reached, function returns `Ok(Some((Phase::FinalReview, Phase::Completing)))`
- [ ] When cap is reached, no reviewer/planner/voter/arbiter deliberation backend calls are made
- [ ] The existing late/post-deliberation restart-cap guard (the one that force-completes using `final_accepted`) is removed
- [ ] Guard is NOT placed before `resolve_effective_final_review_backends(...)`
- [ ] For `restart_count < cap`, the entire deliberation flow remains unchanged
- [ ] Validate conformance test `cap_reached_skips_deliberation_and_force_completes` is added and registered in `src/validate/mod.rs`
- [ ] Validate conformance test `cap_boundary_force_completes_even_if_no_amendments_would_be_found` is added and registered in `src/validate/mod.rs`

## Files to Modify/Create
- `src/workflow/orchestrator.rs` - Add early cap guard in `run_final_review_phase` after `restart_count`/`round` computation; remove the late post-deliberation cap guard that uses `final_accepted`
- `src/validate/final_review_cap_skip.rs` (or similar) - Add two validate conformance tests: `cap_reached_skips_deliberation_and_force_completes` and `cap_boundary_force_completes_even_if_no_amendments_would_be_found`
- `src/validate/mod.rs` - Register the new validate conformance test module and its test functions
