# Implementation Notes

## Decisions Made
- **PRD resume test (`prd_resume_fewer_invocations`)**: Uses `prd_invocation_counting_script` to count backend invocations. First run generates a fresh PRD, second run with `--resume` reuses cached stages. Counter is reset between runs to isolate measurement. Asserts second count is strictly less than first.
- **PRD answers test (`prd_answers_ingested`)**: Uses `prd_stdin_capturing_script` to capture all stdin passed to the backend. Writes a YAML answers file with a unique sentinel value, then verifies the sentinel appears in at least one captured stdin file.
- **on_prompt_change flag acceptance test**: Uses `setup_with_standard_mock` (stable mocks, no mutation) with `--on-prompt-change abort --loops 1`. Since no prompt change occurs, the run succeeds — proving the flag is parsed and accepted.
- **on_prompt_change abort triggers test**: Creates project with standard mock first, then replaces backends with `prompt_mutating_mock_script` that mutates `prompt.md` during planner phase. Runs with `--on-prompt-change abort` and asserts non-zero exit, stderr contains `"prompt changed"`, no completed loops, and HEAD unchanged.
- **workspace_root test**: Initializes workspace and project normally at `h.repo_root`, then moves `.ralph` to an alternate temp directory. Proves discovery fails without `--workspace-root` (non-vacuous invariant), then succeeds with `--workspace-root <alt>`.
- **Mock script wrappers**: Used `write_stable_mock_script` for bash-based scripts (`prd_invocation_counting_script`, `prd_stdin_capturing_script`, `prompt_mutating_mock_script`) to ensure Nix-sandbox compatibility via POSIX `/bin/sh` wrapper.
