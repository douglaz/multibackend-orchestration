# Implementation Notes

## Decisions Made
- **Recursive navigation for borrow checker**: Used `navigate_table_recursive` and `ensure_tables_recursive` helper functions to satisfy Rust's borrow checker when traversing mutable TOML tables. The iterative approach fails because `get_mut()` borrows the table, preventing subsequent mutation.
- **Inline-table detection before mutation**: In `navigate_table_recursive`, we check `is_table` and `is_inline_table` via immutable borrows first, then perform the inline-to-regular conversion and take the mutable borrow only once, avoiding E0499.
- **`set_implicit(true)` on converted tables**: When converting inline tables to regular tables, we set `implicit = true` to avoid emitting redundant `[section]` headers in the TOML output.
- **Error-returning signatures**: Changed `navigate_tables_mut` from `Option<&mut Table>` to `Result<Option<&mut Table>>` and `ensure_tables` from `&mut Table` to `Result<&mut Table>`, providing explicit errors for non-table path segments instead of panics.
- **`save_sparse` atomicity on error**: The function returns errors before `fs::write`, leaving the file untouched when path traversal fails.
- **`merge_tables` handles both `Item::Table` and `Value::InlineTable`**: The merge logic now checks both cases on both sides, converting inline tables via `clone().into_table()` when nested merging is needed.
