# Feature: Harden inline-table handling for `init --copy-files` overlay and sparse global config writes

## Description
Address the remaining correctness gap after loops 1–2 by making config mutation and overlay merge resilient to inline-table segments (e.g., `workspace = { ... }`) and invalid path segments without panics or silent no-ops. This includes fixing sparse write clear semantics for inline-table-backed paths, ensuring overlay inserts missing defaults into actual TOML bytes (not just deserialized shape), and removing known cleanup artifacts.

## Acceptance Criteria
- [ ] `save_sparse()` never panics for valid TOML with inline tables encountered on the key path.
- [ ] `navigate_tables_mut()` and `ensure_tables()` in `src/config/global.rs` return errors instead of panicking when a path segment is non-table/scalar/array.
- [ ] When a path segment is an inline table, traversal logic creates or converts to a mutable table preserving existing keys, then continues safely.
- [ ] `save_sparse(..., key, config)` removes an optional key from disk on `null` even if the parent table or target value is inline-table-backed; it must fail with a clear error and leave file untouched if the path is structurally invalid.
- [ ] `merge_tables()` in `src/cli/init.rs` handles existing inline tables for nested defaults (e.g., `workspace = { default_backend = "codex" }`) by converting/merging so missing nested defaults are physically inserted into merged TOML.
- [ ] `init --copy-files` on existing workspace preserves user values, fills missing defaults, and keeps unknown keys; when existing values are inline-table-backed, missing default keys are added in file output.
- [ ] Conformance `copy_files_overlay_fills_missing_keys` verifies missing keys by inspecting merged file content (not only deserialized `GlobalConfig` equality).
- [ ] Add regression coverage for:
  - inline-table path set in sparse writes,
  - inline-table clear in sparse writes,
  - inline-table path in overlay merge.
- [ ] Remove obsolete dead `plan_actions()` + `#[allow(dead_code)]` in `src/cli/init.rs`.
- [ ] Remove `/tmp/ralph-daemon-data/douglaz/multibackend-orchestration/.ralph/daemon/worktrees/douglaz-multibackend-orchestration-90/20260303T023119Z-impl-notes.md`.
- [ ] Failure invariants:
  - If path traversal encounters non-table value, command returns an explicit error and does not write partial config.
  - If `ralph.toml` cannot be parsed, no config modifications are written and error is returned.
