# Feature: Minimal `ralph init` Default Behavior

## Description
Change `ralph init` to produce a minimal workspace by default: only `ROOT/projects/` directory and a minimal `ROOT/ralph.toml` containing guidance comments and a `[workspace]` header with no explicit config keys. No templates directory or template files are created. The minimal TOML must round-trip through `toml::from_str::<GlobalConfig>()` to `GlobalConfig::default()`. Add the `--copy-files` flag to `InitArgs` (but its full behavior is deferred to a later feature). Update `ralph auto` and daemon bootstrap callers to use the minimal init path. Update `Workspace::init()` to remain unchanged for test compatibility. Add `toml_edit` dependency to `Cargo.toml` (needed now for the minimal TOML constant validation and later for sparse writes/overlay).

## Acceptance Criteria
- [ ] `ralph init` creates only `ROOT/projects/` and `ROOT/ralph.toml` (no `ROOT/templates/` directory, no template files).
- [ ] The minimal `ralph.toml` contains guidance comments, a `[workspace]` header, and no explicit config keys.
- [ ] `toml::from_str::<GlobalConfig>(MINIMAL_TOML)` equals `GlobalConfig::default()`.
- [ ] `ralph init --dry-run` outputs only `create-dir <root>/projects` and `write-config <root>/ralph.toml` (no template-related actions).
- [ ] `ralph init --copy-files` flag is accepted by the CLI parser (actual full-scaffold/overlay behavior is deferred).
- [ ] `ralph auto` workspace bootstrap uses the minimal init path (no templates created).
- [ ] Daemon bootstrap (`src/daemon/bootstrap.rs`) uses the minimal init path (no templates created).
- [ ] `Workspace::init()` signature and behavior remain unchanged (it still creates templates + full config for test compatibility).
- [ ] `Workspace::load()` successfully loads a workspace with only the minimal `ralph.toml`.
- [ ] `toml_edit` is added to `Cargo.toml` dependencies.
- [ ] Existing `validate_target` still rejects non-empty directories for plain `ralph init` (no `--copy-files`).
- [ ] Unit test: minimal TOML constant parses to `GlobalConfig::default()`.

- [ ] Conformance tests updated: `auto_init::*` tests expect no templates directory or template files after auto-init.
- [ ] All existing `cargo test` passes (no regressions).
