# Feature: Expand validate conformance suite with tail, config-show, project-list, and template-fallback tests

## Description
Add 9 new conformance tests to the `ralph validate` suite covering previously untested features: the `tail` command (one-shot mode with plain text, JSON output, `--last` flag, and error handling), the `config show` command (global and project-scoped), the `project list` command (empty and populated workspace), and template fallback resilience (QA phase recovery when template file is missing). This involves creating a new `tests_tail.rs` module with 4 tests, adding 4 tests to `tests_commands.rs`, adding 1 test to `tests_run.rs`, and registering the new module in `mod.rs`.
