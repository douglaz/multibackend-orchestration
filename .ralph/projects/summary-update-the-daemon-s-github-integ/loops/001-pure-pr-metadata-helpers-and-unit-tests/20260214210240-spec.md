# Feature: Pure PR metadata helpers and unit tests

## Description
Implement the three pure helper functions that build PR metadata — `extract_project_ref`, `build_pr_title`, and `build_pr_body` — in `src/daemon/runtime.rs`, along with comprehensive unit tests. These are zero-I/O functions that transform inputs into sanitized PR title and body strings. They form the foundation that the subsequent PR flow integration will consume.

## Acceptance Criteria
- [ ] `extract_project_ref(branch: &str) -> Option<String>` parses `ralph/{project_id}` branches and returns `Some(project_id)`; returns `None` for non-matching branches (e.g. `main`, `feature/foo`, `ralph/` with empty id)
- [ ] `build_pr_title(raw: &str) -> String` replaces `\n` and `\r` with spaces, trims whitespace, and if `.chars().count() > 80` truncates to first 77 chars and appends `...`; result is always `<= 80` chars by `.chars().count()`
- [ ] `build_pr_body(branch: &str, diff_stat: Option<&str>, issue_body: Option<&str>, task_id: &str, issue_number: u32) -> String` constructs a markdown body with: (a) diff stat section capped at 100 lines, (b) issue/context section capped at 4,000 characters, (c) project reference footer from `extract_project_ref(branch)` with explicit fallback text when extraction fails, (d) graceful handling when all optional fields are `None` (legacy task support)
- [ ] `extract_issue_body(raw_idea: Option<&str>) -> Option<String>` extracts the issue body text from the raw idea string for use as context in the PR body
- [ ] Unit test `build_pr_title_sanitizes_newlines` — verifies newlines/carriage returns replaced with spaces
- [ ] Unit test `build_pr_title_truncates_long_title` — asserts `.chars().count() <= 80` on an input longer than 80 chars, and that it ends with `...`
- [ ] Unit test `build_pr_body_no_context_legacy_task` — all optional fields `None`, produces valid body with fallback project ref
- [ ] Unit tests for `extract_project_ref` — success case (`ralph/my-project` → `Some("my-project")`) and failure cases (`main`, `feature/foo`, empty)
- [ ] All functions are `pub(crate)` or `pub` to allow use from `handle_pr_flow` and test modules
- [ ] `src/daemon/mod.rs` is NOT modified
- [ ] `cargo check` passes with no errors
- [ ] `cargo test --lib` passes with no failures
