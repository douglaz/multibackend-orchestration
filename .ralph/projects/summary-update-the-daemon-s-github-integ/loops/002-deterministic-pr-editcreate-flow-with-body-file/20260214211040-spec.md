# Feature: Deterministic PR Edit/Create Flow with Body-File Safety

## Description
Loop 1 already completed the pure metadata helpers and unit tests (`extract_project_ref`, `build_pr_title`, `build_pr_body`, `extract_issue_body`).  
The next feature should wire those helpers into `handle_pr_flow` so daemon PR handling is deterministic: edit existing PRs by URL, create only when no PR exists, never duplicate on edit failure, and always send large bodies via `--body-file` with fallback diff/context handling.

## Acceptance Criteria
- [ ] `handle_pr_flow` uses `build_pr_title` and `build_pr_body` for PR operations (no inline title/body formatting).
- [ ] PR body context is sourced from `extract_issue_body(task.raw_idea.as_deref())`, and legacy tasks with missing optional context still produce valid bodies.
- [ ] Diff stat collection is attempted for PR body content; if diff stat generation fails (or is unavailable), PR flow continues and body includes fallback diff text.
- [ ] Diff/body size limits already implemented in `build_pr_body` are preserved in runtime integration (100 diff lines, 4,000 context chars).
- [ ] Add `create_pr_with_body_file(...)` logic that writes body to `tempfile::NamedTempFile` and calls `gh pr create ... --body-file <path>`.
- [ ] Add `edit_pr(...)` logic/signature using PR URL positional target (`gh pr edit <pr_url> ... --body-file <path>`), not branch-targeted edit.
- [ ] Existing-PR flow: when `find_existing_pr` returns a URL, runtime attempts edit only.
- [ ] Edit failure path: runtime surfaces error and does not fall through to `pr create`.
- [ ] No-existing-PR flow: runtime creates a new PR and persists the returned URL.
- [ ] Add/extend tests for `runtime_pr_edit_failure_no_duplicate_create`.
- [ ] Add/extend tests for `runtime_pr_diff_stat_failure_fallback`.
- [ ] `src/daemon/mod.rs` remains unchanged.
- [ ] Conformance coverage under `src/validate/` is updated to lock observable daemon behavior (edit-vs-create and body-file usage).

## Files to Modify/Create
- `src/daemon/runtime.rs` - Integrate helper-based title/body generation into PR flow; add body-file create/edit helpers; enforce edit-only existing-PR behavior; add runtime tests for edit-failure and diff-stat fallback.
- `src/validate/tests_daemon.rs` - Add/adjust daemon conformance tests for no-duplicate-create-on-edit-failure and diff-stat fallback behavior.
- `src/validate/mock_scripts.rs` - Extend mock `gh` behavior to support/assert `pr edit` and `--body-file` flows in validate tests.

## Dependencies
- Requires: Pure PR metadata helpers and unit tests
- Blocks: Project completion validation for GitHub PR hardening
