# Feature: Propagate Existing-PR Edit Failures as Runtime Errors

## Description
Loops 1 and 2 already covered helper extraction, title/body sanitization, body-size limits, project-ref footer, `--body-file` for create/edit, PR URL edit targeting, and no-fallthrough edit/create behavior. The remaining gap is required behavior 6: when editing an existing PR fails, the runtime currently logs and continues instead of returning an error from PR flow. This feature makes edit failure propagation explicit and deterministic while preserving the non-duplicative create/edit contract.

## Acceptance Criteria
- [ ] `handle_pr_flow` in `src/daemon/runtime.rs` returns `Result<()>` (not `()`).
- [ ] If `find_existing_pr` returns a URL and `github::edit_pr(...)` fails, `handle_pr_flow` returns `Err(...)` (no silent swallow).
- [ ] On edit failure, PR flow exits immediately and does not call `create_pr_with_body_file(...)`.
- [ ] `complete_task` handles `handle_pr_flow(...).await` explicitly, recording/logging a deterministic PR-flow error for the task while still running label updates and cleanup.
- [ ] Existing-PR success path still persists `pr_url` and returns `Ok(())`.
- [ ] No-existing-PR path remains create-only and unchanged.
- [ ] Extend conformance coverage for `runtime_pr_edit_failure_no_duplicate_create` to assert both no duplicate create and surfaced PR-flow error reporting.
- [ ] Existing PR metadata/body-file behavior remains intact (no regressions in title/body/project-ref/diff fallback requirements).
- [ ] `src/daemon/mod.rs` remains unchanged.
- [ ] `cargo check`, `cargo test --lib`, and daemon validate tests pass.

## Files to Modify/Create
- `src/daemon/runtime.rs` - Update `handle_pr_flow` return type and error propagation semantics; update `complete_task` callsite error handling.
- `src/validate/tests_daemon.rs` - Tighten edit-failure conformance assertions for propagated runtime PR-flow error behavior.

## Dependencies
- Requires: Deterministic PR Edit/Create Flow with Body-File Safety
- Blocks: Project completion validation for GitHub PR hardening
