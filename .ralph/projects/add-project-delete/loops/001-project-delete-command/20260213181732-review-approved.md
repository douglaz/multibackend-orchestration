## Acceptance Criteria Checklist
- [x] `ralph project delete my-proj` removes `.ralph/projects/my-proj/` and prints `project 'my-proj' deleted` — `fs::remove_dir_all` on `workspace.project_dir(&project_id)` followed by `println!("project '{project_id}' deleted")`; conformance test `delete_removes_directory` verifies both
- [x] If the project does not exist (no `state.json`), the command exits with code 2 and prints a `ProjectNotFound` error — `workspace.project_exists()` checks `state.json`, returns `RalphError::ProjectNotFound` (exit code 2 per error.rs:116); test `delete_nonexistent_fails` asserts stderr contains `"project not found: no-such-proj"`
- [x] If the project is the currently active project, the command exits with code 2 and prints a `Validation` error with the "switch first" message — active-project guard at project.rs:166 returns `RalphError::Validation` with exact message; test `delete_refuses_active` asserts stderr and directory preservation
- [x] If no project is currently active, the delete command proceeds normally — `active_project_id()` returns `None`, comparison `None == Some(...)` is false, guard does not fire; test `delete_no_active_project` clears the active-project file and verifies successful deletion
- [x] If the project ID contains characters outside `[a-zA-Z0-9_-]` or is empty, the command exits with code 2 and prints a `Validation` error before any filesystem access — `validate_project_id()` is called before `Workspace::discover()`, reusing the existing validated function; existing unit tests in lifecycle.rs cover the validation logic
- [x] If the project's `.lock` file is held by another process, the command exits with code 3 and prints a `StateLocked` error — `ProjectLock::acquire()` propagates `RalphError::StateLocked` (exit code 3 per error.rs:119); lock is explicitly dropped before `remove_dir_all` to avoid cross-platform file descriptor issues
- [x] Conformance test `project::delete_removes_directory` passes — test creates two projects, switches active to `keep-test`, deletes `del-test`, asserts stdout and path removal
- [x] Conformance test `project::delete_refuses_active` passes — test creates one project (auto-activated), attempts delete, asserts exit code 2, stderr message, and directory preserved
- [x] Conformance test `project::delete_nonexistent_fails` passes — test attempts to delete non-existent `no-such-proj`, asserts exit code 2 and stderr message
- [x] Conformance test `project::delete_no_active_project` passes — test clears active-project file, deletes orphaned project, asserts stdout and path removal
