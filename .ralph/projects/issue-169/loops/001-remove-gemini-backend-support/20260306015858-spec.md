# Feature: Remove Gemini backend support

## Description
Delete all Gemini backend code, configuration, tests, and references from the Ralph codebase. This is a removal-only change: delete `src/backend/gemini.rs`, delete `src/validate/tests_gemini_backend.rs`, and surgically remove all Gemini-specific branches, config fields, guardrails, defaults, and test fixtures from every file that references them. Retarget tests that exercise optional-backend-skip and required-backend-failure semantics to use `openrouter` (a real supported backend that can be disabled) so behavioral coverage is preserved. After this change, Ralph recognises exactly three backends: `claude`, `codex`, and `openrouter`.
