# Implementation Notes

## Decisions Made
- Used `fn()` pointer (`fn() -> Result<()>`) rather than a boxed trait object for the tmux checker injection. This is simpler, zero-cost at runtime, and sufficient since the checker is a stateless function. `tmux::check_tmux_available` already has exactly this signature, so `Option::unwrap_or` naturally selects between injected and real checkers.
- Exposed the injection via a `set_tmux_preflight_checker` setter rather than a constructor parameter. This keeps `Orchestrator::new` unchanged for all existing call sites (production CLI, other tests) and only requires the two tmux preflight tests to opt in.
- Removed `PathGuard`, `PATH_LOCK`, and `lock_path` entirely from `tests/orchestrator.rs` since no test in that binary mutates PATH anymore. The `two_loop_happy_path_with_separate_backends` test previously held the lock defensively but never mutated PATH itself.
- Left `tests/backend.rs` unchanged. Its PATH manipulation (prepending a temp dir, not emptying) is safe, serialized by its own `PATH_LOCK`, and lives in a separate test binary that doesn't race with orchestrator tests.
- Left `flake.nix` unchanged. The existing `nix build` check phase already runs `cargo test` with default parallelism, which is sufficient. No special stress-test wiring is needed since the race condition is eliminated at the source.

## Spec Deviations
- None. All acceptance criteria are addressed.

## Testing
- `cargo test --test orchestrator -- --test-threads=16` should be stable across repeated runs, as no orchestrator test mutates process-wide `PATH` anymore.
- `cargo test --test orchestrator tmux_mode_fails_early_when_tmux_is_unavailable` verifies that injected `TmuxUnavailable` propagates as the early error.
- `cargo test --test orchestrator tmux_mode_dry_run_skips_tmux_availability_check` verifies that dry-run skips the preflight even when the checker would fail.
- `nix build` should pass since all existing tests continue to work and no public API changed (only an additive setter was introduced).
