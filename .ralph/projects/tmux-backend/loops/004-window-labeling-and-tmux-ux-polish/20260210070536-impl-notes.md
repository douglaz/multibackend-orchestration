# Implementation Notes

## Decisions Made

- **Window label format**: Used `L{loop}-{role}-{backend}` (e.g., `L3-impl-codex`) as specified. Role names are abbreviated: `plan`, `impl`, `review`, `complete` to keep labels compact while remaining readable in the tmux status bar.

- **Label sanitization strategy**: Characters outside `[A-Za-z0-9_-]` are replaced with `_`. Labels are truncated at 32 characters. This is more conservative than tmux requires but ensures clean status bar rendering.

- **Context passing without changing Backend::execute signature**: Added a `set_tmux_exec_context(&self, ctx: TmuxExecContext)` method to the `Backend` trait with a default no-op implementation. Non-tmux backends (CliBackend, MockBackend) inherit the no-op. TmuxBackend stores the context in a `Mutex<Option<TmuxExecContext>>` and consumes it at the start of `execute()`. The orchestrator sets context before each invocation.

- **Retention delay**: Uses `tokio::time::sleep` for the configured duration only on successful command completion (not on errors/timeouts). The delay occurs after reading output but before killing the window, so the user can inspect the final state.

- **Window keep seconds default**: Set to 5 seconds. This gives users a brief window to inspect completed commands without accumulating stale windows. Set to 0 for immediate cleanup.

- **Session/window disappearance handling**: Three layers of resilience:
  1. `create_window_with_retry`: If window creation fails due to missing session, re-ensures the session once and retries.
  2. `kill_window_best_effort`: Window cleanup uses warn+continue instead of hard failure, since the window may already be gone.
  3. Post-timeout session check: After a timeout, checks if the session still exists. If not, returns `BackendCommandFailed` with actionable diagnostics instead of an ambiguous `BackendTimeout`.

- **`ralph tail --tmux` implementation**: When `--tmux` flag is passed, the command discovers the workspace, reads the configured `tmux_session` name, verifies the session exists, then runs `tmux attach -t <session>` with inherited stdio. Returns a clear error if tmux is not installed or the session doesn't exist.
