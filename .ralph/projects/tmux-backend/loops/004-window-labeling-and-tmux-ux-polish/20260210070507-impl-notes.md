# Implementation Notes

## Decisions Made
- **All acceptance criteria are already satisfied** by the code changes made during prior loops (1-3) and the work already present in the current working tree on the `ralph/tmux-backend` branch. The diff for this branch already contains every feature described in the Loop 4 spec.
- **Contextual label generation** uses `window_label(loop_number, role, backend)` in `src/backend/tmux.rs`, producing `L{loop}-{role}-{backend}` format. Invalid characters are replaced with `_` and labels are truncated to 32 characters.
- **`TmuxExecContext`** is a lightweight struct set on the backend via `set_tmux_exec_context()` (a default no-op on the `Backend` trait). This avoids changing the trait signature while passing context from the orchestrator.
- **`tmux_window_keep_seconds`** defaults to `5` seconds (non-zero "brief" duration). The field uses `#[serde(default = "default_tmux_window_keep_seconds")]` for backward-compatible deserialization. A value of `0` means immediate cleanup.
- **Retention delay** is applied only on success (`wait_result.is_ok()`) and only when `window_keep_seconds > 0`, then best-effort window cleanup follows.
- **Session loss during window creation** uses `create_window_with_retry()` which catches "can't find session" errors, re-ensures the session, and retries once.
- **Best-effort cleanup** uses `kill_window_best_effort()` which logs warnings instead of returning errors when the window/session is already gone.
- **Window disappearance during execution** is detected at timeout: if the exit file was never written, `BackendCommandFailed` is returned with actionable diagnostics mentioning the window label and suggesting re-run.
- **`ralph tail --tmux`** checks tmux availability, verifies the session exists, then execs `tmux attach -t <session>` with inherited stdio. Non-tmux tail behavior is completely unchanged (early return when `--tmux` is set).
- **Config wiring** for `workspace.tmux_window_keep_seconds` is handled in `config get` (via serde-json lookup) and `config set` (via `set_global_value` match arm using `parse_u64`).

## Spec Deviations
- None. All acceptance criteria are met as specified.

## Testing
- **Unit tests** in `src/backend/tmux.rs` cover: label formatting (basic, invalid chars, truncation, determinism), session ensure/create, window creation, wait_for_exit, kill_window, has_session, best-effort cleanup, and create_window_with_retry (success, retry on session loss, non-session error propagation).
- **Unit tests** in `src/backend/tmux_backend.rs` cover: shell command construction (basic, args, env, escaping), execute success/failure/timeout paths, temp file cleanup, name delegation, kill_window on non-zero exit.
- **Integration tests** in `tests/backend_tmux.rs` cover: full call sequence, session creation when missing, non-zero exit error, timeout, temp file cleanup (success/failure), backend name preservation, env/args in shell command, no stderr redirect, contextual labels (with/without context), set_tmux_exec_context via trait, retry on session loss, best-effort cleanup on missing window, window disappeared diagnostics.
- **CLI tests** in `tests/tail_tmux.rs` cover: `--tmux` flag parsing, coexistence with `--project` and `-F`, non-tmux parsing, `--last`/`--json` flags.
- **Orchestrator tests** in `tests/orchestrator.rs` cover: tmux preflight failure when tmux is unavailable, dry-run skips tmux check.
- **Config tests** in `src/config/global.rs` cover: default values, deserialization with/without tmux fields.
- **Run `cargo test`** to verify all tests pass. No real tmux binary is required in CI — all tmux interactions use the `MockTmuxRunner` abstraction.
