# Implementation Notes

## Decisions Made
- Added `src/backend/tmux.rs` with a mockable async runner abstraction (`TmuxCommandRunner`) and a real implementation (`RealTmuxRunner`) using `tokio::process::Command` for all tmux CLI calls.
- Implemented `check_tmux_available`, `ensure_session`, `create_window`, `wait_for_exit`, and `kill_window` in the new module. `create_window` uses `tmux new-window -P -F "#{window_index}"` so it can return a stable window identifier.
- Added `RalphError::TmuxUnavailable` to `src/error.rs` with an install/PATH guidance message.
- Declared `pub mod tmux;` in `src/backend/mod.rs`.
- Added unit tests with a `MockTmuxRunner` that records invocations and returns queued results, covering session exists/create, window creation, wait-for-exit success/timeout/non-zero, and window cleanup.
