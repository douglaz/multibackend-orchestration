# Feature: tmux session and window management

## Description

Add a `tmux` module (`src/backend/tmux.rs`) providing low-level functions for managing tmux sessions and windows via the `tmux` CLI. This is the foundational layer that all subsequent tmux features build on. It handles checking whether tmux is installed, ensuring a named session exists, creating labeled windows that run shell commands, polling for command completion via exit-code files, reading captured output, and tearing down windows after use. All tmux interactions go through `tokio::process::Command` so they are async-compatible. The module is designed for testability: the command-execution layer is abstracted behind a trait (`TmuxCommandRunner`) so unit tests can use a mock implementation without requiring tmux to be installed.

## Acceptance Criteria

- [ ] A new file `src/backend/tmux.rs` exists and is declared as `pub mod tmux;` in `src/backend/mod.rs`
- [ ] A `TmuxCommandRunner` trait is defined with an async method for running tmux subcommands (e.g., `async fn run(&self, args: &[&str]) -> Result<String>`) to enable mocking
- [ ] A `RealTmuxRunner` struct implements `TmuxCommandRunner` by invoking the `tmux` binary via `tokio::process::Command`
- [ ] `check_tmux_available()` returns `Ok(())` if `tmux` is in PATH (via `which` crate) or a clear `RalphError` variant if not
- [ ] `ensure_session(runner, session_name)` creates the tmux session if it doesn't already exist, using `tmux has-session` to check and `tmux new-session -d -s <name>` to create
- [ ] `create_window(runner, session_name, label, shell_command)` creates a new tmux window via `tmux new-window -t <session> -n <label> <shell_command>` and returns the window identifier
- [ ] `wait_for_exit(exit_file_path, timeout, poll_interval)` polls the filesystem for the exit file to appear, reads its contents as an exit code, and returns it; returns `RalphError::BackendTimeout` if the timeout elapses
- [ ] `kill_window(runner, session_name, window_id)` kills a specific tmux window via `tmux kill-window`
- [ ] A new `RalphError::TmuxUnavailable` variant is added to `src/error.rs` with a helpful message telling the user to install tmux
- [ ] Unit tests exist using a `MockTmuxRunner` that records invocations and returns configurable responses, covering: session creation (already exists vs. new), window creation, wait-for-exit (success, timeout, non-zero exit), and window cleanup
- [ ] All existing tests pass without modification (`nix build` / `cargo test`)
- [ ] No new external crate dependencies are required (uses existing `tokio`, `which`, `tracing`)
