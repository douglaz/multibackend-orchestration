# Implementation Notes

## Decisions Made
- Added `workspace.tmux` and `workspace.tmux_session` to `WorkspaceConfig` with backward-compatible serde defaults, and set `GlobalConfig::default()` to `tmux = false` and `tmux_session = "ralph"`.
- Added mutually exclusive CLI flags `--tmux` / `--no-tmux` on `RunArgs` as `Option<bool>`, and threaded the resolved override into `RunOptions.tmux`.
- Implemented orchestrator tmux resolution (`CLI override > config > default false`) and added an explicit tmux preflight check before backend health checks when `tmux` is enabled and `dry_run` is false.
- Updated `BackendRegistry::new` to accept tmux settings and wrap each `CliBackend` in `TmuxBackend<RealTmuxRunner>` only when enabled.
- Added tests for config deserialization defaults/overrides, CLI flag parsing, registry wrapping behavior, and tmux preflight behavior (including dry-run skip).

## Spec Deviations
- Used `#[serde(default = "default_tmux_session")]` for `tmux_session` instead of plain `#[serde(default)]` so missing `tmux_session` correctly defaults to `"ralph"` (plain `#[serde(default)]` on `String` would default to `""`).

## Testing
- Ran full test suite: `nix develop -c cargo test` (all tests passing).
- New/updated coverage includes:
- `src/config/global.rs` tmux default/deserialization tests
- `src/cli/mod.rs` tmux flag parsing tests
- `tests/backend.rs` registry wrapping vs non-wrapping behavior tests
- `tests/orchestrator.rs` early tmux unavailable + dry-run skip tests
