# Feature: Prompt De-duplication (A)

## Description
Add a `template_introspection` module that provides functions to inspect template sources for placeholder usage, and update all five prompt builders (`build_planner_prompt`, `build_implementer_prompt`, `build_reviewer_prompt`, `build_qa_prompt`, `build_completer_prompt`) to conditionally append hardcoded sections only when the corresponding placeholder is absent from the template source. This prevents content duplication when default templates contain placeholders (which expand inline) while ensuring custom templates that omit placeholders still receive the content exactly once via appending.

## Acceptance Criteria
- [ ] New file `src/prompts/template_introspection.rs` exists with `pub fn template_uses_var(template_source: &str, var_name: &str) -> bool` and `pub fn load_template_source(path: &Path, fallback: &str) -> String`.
- [ ] `template_uses_var` checks for the exact `{{var_name}}` pattern in the template source string and returns `true` if found.
- [ ] `load_template_source` reads the file at `path` if it exists, otherwise returns the `fallback` string. It returns the raw template source (not rendered).
- [ ] `src/prompts/mod.rs` declares `pub mod template_introspection;`.
- [ ] `build_planner_prompt` loads the planner template source once via `load_template_source`, checks each hardcoded section's placeholder with `template_uses_var`, and only appends sections whose placeholder is absent from the template.
- [ ] `build_implementer_prompt` follows the same conditional-append pattern for its hardcoded sections.
- [ ] `build_reviewer_prompt` follows the same conditional-append pattern for its hardcoded sections.
- [ ] `build_qa_prompt` follows the same conditional-append pattern for its hardcoded sections.
- [ ] `build_completer_prompt` follows the same conditional-append pattern for its hardcoded sections.
- [ ] Default templates with all placeholders present produce output with exactly one occurrence of each section (e.g., exactly one `## Master Prompt` heading).
- [ ] Custom templates that omit a placeholder still receive the corresponding content exactly once via appending after the rendered template.
- [ ] Unit test: `template_uses_var` returns `true` for present placeholder, `false` for absent, `false` for partial match (e.g., `var` doesn't match `{{variable}}`), `true` for repeated placeholders.
- [ ] Unit test: rendering a default template produces exactly one `## Master Prompt` section (no duplication).
- [ ] Unit test: a custom template that omits `{{master_prompt}}` (or equivalent) causes exactly one appended `## Master Prompt` section.
- [ ] `cargo check` and `cargo test` pass.
