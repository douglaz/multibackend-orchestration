# Implementation Notes

## Decisions Made
- Placed `PlannerStateInPrompt` and `PreviousSpecsInPrompt` enums in `src/config/global.rs` with `#[serde(rename_all = "kebab-case")]` to match the existing enum serialization style (kebab-case used by `CommitMessageStyle`, `PromptChangeAction`).
- Used `Summary` as default for `PlannerStateInPrompt` and `Titles` as default for `PreviousSpecsInPrompt` per spec, reducing tokens from the start.
- `planner_max_prior_loops` defaults to `Some(10)` at the global level via a dedicated default function, matching the spec exactly.
- For project overrides, `planner_max_prior_loops` uses `Option<Option<usize>>` — outer `None` = inherit from global, `Some(None)` = override to unlimited, `Some(Some(n))` = cap at n.
- CLI parse semantics: `"none"` = unlimited, integer = capped, `"null"` = inherit (project scope only). This matches the existing pattern for other nullable config fields.
- `summarize_state_for_planner` produces a human-readable text summary rather than JSON — includes loop metadata (status, iteration count, spec path) but explicitly excludes review feedback and QA report bodies by not reading those files at all.
- `summarize_previous_specs_for_planner` replaces the old `collect_previous_specs` function with mode-aware behavior: `None` mode returns empty, `Titles` returns bullet titles only, `FullText` reads and returns full spec content.
- Both `build_planner_prompt` and `build_completer_prompt` now use the new config-driven functions. The completer prompt builder's signature was changed to accept `project_dir` instead of pre-computed `previous_specs` string, allowing it to honor the config modes internally.
- Removed the now-unused `collect_previous_specs` function (its logic is subsumed by `summarize_previous_specs_for_planner` in `FullText` mode).
- Added the three new fields to both `execute_show` and `execute_get` JSON output in `src/cli/config.rs` so they appear in `ralph config show` / `ralph config get`.

## Spec Deviations
- None — all acceptance criteria are implemented as specified.
