# Feature: Planner/Completer Prompt Compression (B)

## Description
Loop 1 completed **Prompt De-duplication (A)**. The next logical feature is deterministic compression for planner/completer prompts so they stop embedding full raw state/spec text by default and instead use configurable summary modes, reducing token usage without changing orchestration behavior.

## Acceptance Criteria
- [ ] Add `PlannerStateInPrompt { FullJson, Summary }` and `PreviousSpecsInPrompt { None, Titles, FullText }` in `src/config/global.rs`, with defaults `Summary` and `Titles`.
- [ ] Add `workflow.planner_state_in_prompt`, `workflow.planner_previous_specs_in_prompt`, and `workflow.planner_max_prior_loops` to global config defaults (`Some(10)` for `planner_max_prior_loops`).
- [ ] Add project override fields in `src/config/project.rs`: `planner_state_in_prompt: Option<...>`, `planner_previous_specs_in_prompt: Option<...>`, `planner_max_prior_loops: Option<Option<usize>>`.
- [ ] Resolve the three new fields into non-optional values in `EffectiveWorkflowConfig` (`src/config/mod.rs`) with project-over-global precedence.
- [ ] Extend `ralph config set` handling (`src/cli/config.rs`) for all three fields at global/project scope, including `"none"` parsing for unlimited `planner_max_prior_loops` and inherit-vs-override behavior for project config.
- [ ] Implement `summarize_state_for_planner(state, max_loops)` in `src/workflow/orchestrator.rs` with deterministic loop selection: sort by loop number ascending, then keep latest `N` when capped.
- [ ] `summarize_state_for_planner` must include loop metadata (status/iteration/verdict/spec path) but exclude raw review feedback body and raw QA report body text.
- [ ] Implement `summarize_previous_specs_for_planner(state, project_dir, mode, max_specs)` with exact mode semantics:
- [ ] `None` returns empty.
- [ ] `Titles` returns bullet titles only.
- [ ] `FullText` returns full prior spec content.
- [ ] `max_loops/max_specs = None` means unlimited; `Some(0)` means include none.
- [ ] Update `build_planner_prompt` and `build_completer_prompt` to honor the new modes/caps from effective config.
- [ ] Add/extend unit tests covering summary content filtering, `Titles` output shape, cap semantics (`None`, `Some(0)`, capped latest N), and global/project merge precedence for all new B fields.
- [ ] `cargo check` and `cargo test` pass with new tests.

## Files to Modify/Create
- `src/workflow/orchestrator.rs` - add summary helpers and wire planner/completer prompt builders to new config-driven compression modes.
- `src/config/global.rs` - add enums, workflow fields, serde/default behavior, and enum parsing support as needed.
- `src/config/project.rs` - add project-level override fields for the new planner compression settings.
- `src/config/mod.rs` - add resolved effective workflow fields and merge logic.
- `src/cli/config.rs` - add `config get/set/show` support and parse helpers for enum values and `"none"` semantics.
- `src/workflow/orchestrator.rs` - add/extend unit tests for summary/spec rendering and cap behavior.
- `src/config/mod.rs` - add/extend tests for global/project precedence of new fields.
- `src/config/global.rs` - add/extend enum/default serialization/deserialization tests.

- Requires: Prompt De-duplication (A)
- Blocks: none
