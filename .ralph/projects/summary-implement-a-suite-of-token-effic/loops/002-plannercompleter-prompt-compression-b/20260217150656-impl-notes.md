# Implementation Notes

## Decisions Made
- Placed `PlannerStateInPrompt` and `PreviousSpecsInPrompt` enums in `src/config/global.rs` with `#[serde(rename_all = "kebab-case")]` to match existing enum style.
- Used `Summary` default for state-in-prompt and `Titles` default for previous-specs-in-prompt per spec.
- `planner_max_prior_loops` defaults to `Some(10)`. Project override uses `Option<Option<usize>>` for 3-way semantics (inherit/unlimited/capped).
- `summarize_state_for_planner` produces human-readable text with loop metadata but excludes raw feedback/report bodies by design (never reads those files).
- `summarize_previous_specs_for_planner` replaces `collect_previous_specs` with mode-aware behavior.
- Both `build_planner_prompt` and `build_completer_prompt` now use config-driven compression. The completer's signature changed to accept `project_dir` instead of pre-computed specs.
- Removed unused `collect_previous_specs`.
