# Feature: Deterministic Daemon Auto-Rebase Runtime and PR Failure Deduplication

## Description
Loop 1 completed the foundation (state fields, config plumbing, PR merge query parsing, branch-targeted worktree helper, and `LAST REBASE` status output), but runtime auto-rebase behavior is still missing. Implement the daemon rebase phase that runs each cycle, rebases eligible PR-backed task branches onto `origin/<baseRefName>`, enforces bounded runtime, and posts deduplicated PR failure comments keyed by `task_id + head_sha`.

## Acceptance Criteria
- [ ] Daemon runs an auto-rebase phase immediately after `collect_children` in each cycle.
- [ ] Auto-rebase is skipped when `daemon.auto_rebase_enabled` is false, with a clear log reason.
- [ ] Rebase candidates are processed in deterministic ascending `task_id` order.
- [ ] Tasks are skipped (with explicit reason) when: no PR URL, PR URL is unparsable, no task branch, PR state is not `OPEN`, merge status is `Conflicting`/`Unknown`, or `last_rebase_at` is within interval.
- [ ] PR metadata is fetched only via `query_pr_merge_info` (`gh pr view ... --json mergeable,state,baseRefName,headRefOid`); if this command fails for a task, daemon logs stderr and stops further rebase processing for that cycle.
- [ ] Rebase target is always `origin/<baseRefName>` from PR metadata; no hardcoded default branch fallback.
- [ ] Rebase uses `create_worktree_on_branch(...)` and rebases the task’s actual stored branch (including branch-switched tasks).
- [ ] Each attempt performs fetch + rebase + `git push --force-with-lease`, with per-attempt timeout `REBASE_TIMEOUT_SECONDS = 120`.
- [ ] Per-cycle rebase attempts are capped at `MAX_REBASES_PER_CYCLE = 3`.
- [ ] Successful rebase+push updates `last_rebase_at` (RFC3339 UTC) and continues.
- [ ] Lease mismatch push rejection is treated as a per-task failure for the cycle and processing continues to next task.
- [ ] Rebase failure posts a PR comment (not issue comment) containing marker `<!-- ralph:rebase:{task_id}:failed:{head_sha} -->`.
- [ ] Failure comment dedup is enforced by `last_rebase_head_sha`: same task+head SHA does not post again; new head SHA posts once and updates dedup state.
- [ ] `src/validate/tests_daemon.rs` adds remaining auto-rebase conformance coverage: disabled skip, conflict/unknown skip, closed/merged skip, branch-switched rebase branch, baseRefName targeting, PR comment surface, dedup by head SHA, force-with-lease rejection, `gh pr view` failure break, per-cycle cap, and interval skip.
- [ ] `nix develop -c cargo check`, `nix develop -c cargo test`, and daemon validate filter pass.
