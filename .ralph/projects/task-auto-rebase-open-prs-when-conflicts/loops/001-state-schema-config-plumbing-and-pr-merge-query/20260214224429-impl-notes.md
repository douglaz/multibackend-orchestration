# Implementation Notes

## Decisions Made
- Added `DaemonTask` rebase-tracking fields `last_rebase_at` and `last_rebase_head_sha` with `#[serde(default)]` in `src/daemon/mod.rs`, and initialized them where new tasks are created in `src/daemon/runtime.rs`.
- Added PR merge query infrastructure in `src/daemon/github.rs`:
  - `PrMergeStatus` (`Conflicting`, `Mergeable`, `Unknown`) with exact mapping from `CONFLICTING` / `MERGEABLE` / `UNKNOWN`.
  - `PrMergeInfo` with `merge_status`, `state`, `base_branch`, `head_oid`.
  - `query_pr_merge_info(owner, repo, pr_number)` using `gh pr view <pr> --repo <owner/repo> --json mergeable,state,baseRefName,headRefOid`.
  - `post_pr_comment(owner, repo, pr_number, body)` using `gh pr comment`.
- Added `create_worktree_on_branch(repo_root, workspace_root, task_id, branch)` in `src/daemon/worktree.rs`:
  - Uses/reuses `.ralph/daemon/worktrees/rebase-{task_id}`.
  - Ensures checkout of the provided branch.
  - Left existing `create_worktree` behavior unchanged.
- Added workspace auto-rebase config keys and defaults in `src/config/global.rs`:
  - `daemon_auto_rebase_enabled: true`
  - `daemon_rebase_interval_seconds: 1800`
  - `daemon_max_rebases_per_cycle: 3`
  - `daemon_rebase_timeout_seconds: 120`
- Added matching optional project overrides in `src/config/project.rs` and merged them in `resolve_daemon_config` (`src/config/mod.rs`), with project values taking precedence.
- Extended config CLI plumbing in `src/cli/config.rs` so `config get/set/show` supports the new keys in global (`workspace.*`) and project (`daemon.*`) scopes.
- Added `LAST REBASE` column to `ralph daemon status` in `src/cli/daemon.rs`, printing stored RFC3339 text or `-`.
- Expanded tests:
  - Unit tests for PR merge parsing/mapping and backward-compatible daemon task deserialization.
  - Config default/merge assertions for new keys.
  - Daemon conformance config test updates for new `config get/set` keys and status header check.
