# Implementation Notes

## Decisions Made
- Added `src/daemon/interactive_prd.rs` with:
  - `PrdWorkflowState` (`Pending`, `AwaitingAnswers`, `AwaitingFeedback`, `Done`, `Failed`) deriving `Serialize`, `Deserialize`, `Debug`, `Clone`, `PartialEq`, `Eq`.
  - `InteractivePrdState` with all required persisted fields and `new(owner, repo, issue_number)` initializing `Pending`, zeroed counters, and `None` optionals.
  - Atomic persistence via temp file + rename in `save(data_dir)`, and `load(data_dir, owner, repo, issue_number)` returning `Ok(None)` on missing state file.
  - `is_terminal()` for `Done`/`Failed`.
  - `detect_approval(text)` that strips fenced/inline code, checks negative phrases before positive phrases (word-boundary, case-insensitive), and returns `false` on mixed signals.
  - `prd_marker(issue_number, kind, version)` marker helper.
  - PRD label constants in `PRD_LABELS` plus alias `PRD_LIFECYCLE_LABELS`.
  - Unit tests covering serialization round-trip, approval detection edge cases, marker generation, terminal state checks, and save/load round-trip using `tempdir`.
- Exported the new daemon module in `src/daemon/mod.rs` with `pub mod interactive_prd;`.
- Added `InteractivePrdFailed(String)` to `RalphError` in `src/error.rs` and mapped it to exit code `14`.
- Extended `WorkspaceConfig` in `src/config/global.rs` with:
  - `daemon_prd_enabled` (default `true`)
  - `daemon_prd_question_backends` (default `["claude", "codex"]`)
  - `daemon_prd_writer_backend` (default `"claude"`)
  - `daemon_prd_reviewer_backend` (default `"codex"`)
  - `daemon_prd_max_revisions` (default `3`)
  - `daemon_prd_backend_timeout_secs` (default `120`)
  - plus default wiring and config tests.
- Added validation in `src/config/mod.rs`:
  - `daemon_prd_question_backends` must contain exactly 2 entries.
  - Each PRD backend spec (question backends, writer, reviewer) must parse and resolve through existing backend-spec validation.
  - Returns clear `Validation` errors on invalid config.
- Propagated PRD daemon settings into `EffectiveDaemonConfig` for downstream runtime use.
