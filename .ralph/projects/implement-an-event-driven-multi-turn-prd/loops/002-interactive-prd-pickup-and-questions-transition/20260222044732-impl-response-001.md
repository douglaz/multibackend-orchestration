3. **Added conformance coverage for runtime behaviors (Required #3)** — Added 3 new tests to `src/validate/tests_interactive_prd.rs`: `startup_prd_label_ensure`, `prd_ready_conflict_in_claim_path`, and `idempotent_state_reprocessing`.

5. **Validate PRD config at daemon startup (Recommended #1)** — Added `validate_interactive_prd_workspace_config` call in `src/cli/daemon.rs` (gated by `prd_enabled`), made the function `pub`.
