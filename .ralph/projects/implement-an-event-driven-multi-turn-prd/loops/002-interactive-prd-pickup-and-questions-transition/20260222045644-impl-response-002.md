# Implementation Response (Iteration 2)

## Changes Made
1. **Fixed label swap order to prevent orphaned PRD issues (Required #1)** — Changed `do_pending_to_awaiting` in `src/daemon/interactive_prd.rs:424-441` to add `ralph:prd-active` BEFORE removing `ralph:prd`. Previously the remove happened first, so if the subsequent add failed the issue had neither label and would never be found by future polls. Now `ralph:prd-active` is added first (with retry + error propagation), and only after that succeeds is `ralph:prd` removed (best-effort). This fixes the false-positive count that caused the conformance test to fail.
