# Feature: Interactive PRD Round-2 Compliance Hardening

## Description
Loops 1-8 already delivered the core interactive PRD state machine, transitions, persistence, labels, and Round 1 reliability fixes. The next missing work is Round 2 final-review remediation: enforce strict 6-section draft completeness in all draft/revision acceptance paths, and make integration test binary discovery Nix/Cargo layout-safe so `nix build -L` can pass.

## Acceptance Criteria
- [ ] `run_draft_with_section_retry_sync` only returns success when all required sections are present; after final retry with missing sections, it returns `InteractivePrdFailed` including missing section names.
- [ ] `generate_draft_from_answers_with_timeout` and `generate_revision_from_feedback_with_timeout` only accept revised content when `missing.is_empty()`; reviewer approval does not bypass section completeness.
- [ ] Section-incomplete outputs flow through normal retry/failure accounting (`error_count`, `last_error`, eventual `Failed` after exhaustion) without posting incomplete draft comments.
- [ ] Unit tests in `src/daemon/interactive_prd.rs` cover section-incomplete writer/reviewer outputs for both initial draft and revision paths.
- [ ] Conformance coverage in `src/validate/tests_interactive_prd.rs` verifies incomplete drafts/revisions are rejected and do not satisfy the 6-section requirement.
- [ ] `tests/daemon_interactive_prd.rs` uses a layout-agnostic `ralph_bin_absolute()` resolver: compile-time `option_env!("CARGO_BIN_EXE_ralph")`, runtime env fallback, `target/{debug,release}`, `target/<triple>/{debug,release}`, and `CARGO_TARGET_DIR` roots.
- [ ] Resolver panic message lists all searched paths to aid CI diagnosis.
- [ ] `nix build -L` succeeds through checkPhase with interactive PRD integration tests enabled.

## Files to Modify/Create
- `src/daemon/interactive_prd.rs` - tighten section-completeness acceptance logic and add failure-on-missing behavior with regression unit tests.
- `src/validate/tests_interactive_prd.rs` - add/adjust conformance tests for strict 6-section enforcement.
- `tests/daemon_interactive_prd.rs` - replace `ralph_bin_absolute()` with robust multi-layout binary resolution and clear failure diagnostics.

## Dependencies
- Requires: Interactive PRD Final-Review Reliability Hardening (Loop 8)
- Blocks: Project completion sign-off for interactive PRD workflow
