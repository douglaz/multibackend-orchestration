# Feature: Add `ralph:waiting-feedback` label lifecycle

## Description
Introduce the `ralph:waiting-feedback` informational label to the interactive PRD workflow. This label signals that an issue is blocked on user input during the `AwaitingAnswers` and `AwaitingFeedback` states. The implementation covers the full lifecycle: label catalog registration, automatic startup ensure, best-effort application and reconciliation during waiting states, idempotent no-op when already present, and removal on terminal (`Done`/`Failed`) transitions only after durable state save succeeds.
