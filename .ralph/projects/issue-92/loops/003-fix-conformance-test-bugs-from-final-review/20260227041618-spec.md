# Feature: Fix conformance test bugs from final review amendments

## Description
Two bugs were identified during final review of the `ralph:waiting-feedback` label implementation. Both are in conformance tests (`src/validate/tests_interactive_prd.rs`):

1. **FR-PRD-001 (Invalid JSON in mock scripts):** Four conformance tests use a `format!(...) + raw-string` pattern for mock `gh` scripts. The embedded JSON inside the raw-string portion retains Rust format-string double-brace escaping (`{{` / `}}`), but because it is inserted verbatim (not processed by `format!`), the mock emits literal `{{` / `}}` instead of `{` / `}`, producing invalid JSON. This causes the daemon parser to fail, so state files are never written and assertions on state or error counts fail.

2. **FR-PRD-002 (Weak label-removal assertions):** The Done-path and Failed-path tests assert that `ralph:waiting-feedback` was removed by checking `label_raw.contains("--remove-label") && label_raw.contains("ralph:waiting-feedback")`. This can pass even when the two tokens appear in unrelated commands (e.g., `--remove-label ralph:prd-active` plus `--add-label ralph:waiting-feedback`). The assertions must verify both tokens appear in the same command invocation.
