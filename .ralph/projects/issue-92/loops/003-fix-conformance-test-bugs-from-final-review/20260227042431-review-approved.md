## Notes

**FR-PRD-001 root cause verified:** The four affected mock scripts construct their shell content using either `format!("...{}", ..., r#"raw_string"#)` or `r#"..."#.replace(...)`. In both patterns, the raw string body is NOT processed by Rust's `format!` macro as a template — it's used as a plain value. Therefore `{{` inside these raw strings was emitted literally as `{{` in the mock shell output, producing invalid JSON. Changing to single braces `{` is the correct fix.

**FR-PRD-002 assertion strengthening:** The `.lines().any(|line| line.contains("--remove-label") && line.contains("ralph:waiting-feedback"))` pattern correctly ensures both tokens appear on the same logged command line, preventing false positives from unrelated commands that happen to contain the individual tokens separately.
