# Feature: Refined Title Persistence and PR/Comment Title Precedence

## Description
Loop 1 already completed structured refinement parsing (`RefinedPrompt`, parser contract, prompt format). The next missing feature is wiring refined titles through daemon task state and runtime behavior: persist `refined_title`, use it for PR title derivation, and include it in refined-prompt issue comments with safe fallbacks.

## Acceptance Criteria
- [ ] `DaemonTask` includes `#[serde(default)] pub refined_title: Option<String>` in `src/daemon/mod.rs`.
- [ ] Legacy task JSON without `refined_title` deserializes with `refined_title == None`.
- [ ] Round-trip serialization preserves `refined_title: Some(...)`.
- [ ] New tasks created in daemon polling/claim flow initialize `refined_title: None`.
- [ ] In `dispatch_task()`, refinement success uses `RefinedPrompt.body` as the `--idea` input and captures `RefinedPrompt.title` into in-memory task state.
- [ ] On refinement success, `refined_title` is persisted via best-effort store update; persistence errors are logged as warnings and do not abort dispatch.
- [ ] On refinement disabled or refinement failure, `refined_title` is not set and raw idea path is preserved.
- [ ] `extract_original_title(raw_idea: &str) -> Option<String>` exists with exact split/trim behavior (before first `\n\n`, trimmed, empty => `None`).
- [ ] `handle_pr_flow()` derives PR title with precedence: `task.refined_title` -> `extract_original_title(task.raw_idea.as_deref().unwrap_or_default())` -> `format!("ralph: {}", task.task_id)`.
- [ ] Refined-prompt comment body is `**{title}**\n\n{body}` when refined title exists; otherwise body-only behavior remains.
- [ ] Runtime unit tests cover all required `extract_original_title` cases.
- [ ] Validate conformance tests are added for:
- [ ] `refinement_title_in_pr`
- [ ] `refinement_disabled_pr_uses_original_title`
- [ ] `refinement_failure_pr_uses_original_title`
- [ ] `legacy_task_without_raw_idea_pr_uses_fallback`
- [ ] `refined_prompt_comment_includes_title`

## Files to Modify/Create
- `src/daemon/mod.rs` - Add `refined_title` field to `DaemonTask`; add serde compatibility tests for missing/present field.
- `src/daemon/runtime.rs` - Add `extract_original_title`; wire refinement success persistence of `refined_title`; update refined-prompt comment formatting; update PR title precedence logic; add runtime unit tests.
- `src/validate/tests_daemon.rs` - Add conformance tests for refined-title PR/comment behavior and fallback paths.
- `src/validate/mod.rs` - No registration change expected if tests stay in `tests_daemon`; update only if tests are split into a new module.

## Dependencies
- Requires: Structured refinement parsing and RefinedPrompt type (Loop 1)
- Blocks: none (this completes remaining master-prompt scope)
