# Implementation Notes

## Decisions Made
- Added `project_id: Option<String>` (with `#[serde(default)]`) to `DaemonTask` in `src/daemon/mod.rs` and updated daemon unit tests for legacy deserialization and round-trip coverage.
- Added `spawn_ralph_run` plus `build_ralph_run_command` in `src/daemon/process.rs` to support `ralph run --project <id>`, and added a unit test for command argv shape.
- Implemented a shared terminal cleanup policy in `src/daemon/runtime.rs` with `should_cleanup_worktree(state)` and routed cleanup decisions through `cleanup_worktree_for_terminal_state(...)` so:
- `Completed` and `Aborted` clean up worktrees
- `Failed` preserves worktrees for retry
- Updated `complete_task()` and dispatch CAS-race handling to apply the shared cleanup policy and avoid removing failed-task worktrees.
- Updated dispatch routing to use `task.project_id.as_deref()` only:
- `Some(project_id)` -> `spawn_ralph_run`
- `None` -> `spawn_ralph_auto`
- Updated startup worktree reconciliation to treat failed tasks as active (`src/daemon/runtime.rs`), preserving failed-task worktrees on startup.
- Added conformance tests in `src/validate/tests_daemon.rs`:
- `daemon::runtime_task_fails_worktree_preserved`
- `daemon::runtime_activation_failed_task_preserved`
- `daemon::runtime_fresh_dispatch_ignores_discovered_project`
