# Implementation Notes

## Decisions Made
- Reworked `src/daemon/worktree.rs`:
- Added `daemon_branch_name(task_id)`.
- Changed `remove_worktree` to `remove_worktree(repo_root, workspace_root, task_id, branch) -> Result<()>`.
- Implemented the required cleanup order:
  1. `git worktree remove --force <path>` (only if path exists)
  2. `git worktree prune` (always)
  3. `git show-ref --verify refs/heads/<branch>` (always)
  4. `git branch -D <branch>` (only if branch exists)
- Added contextual `RalphError::Orchestration` errors for failures in remove/prune/delete commands.
- Updated `worktree::reconcile_worktrees` to:
- Return `Result<()>`.
- Accept task branch mapping and pass branch names to `remove_worktree`.
- Cleanup stale branches for active tasks that have no worktree directory (restart stale-branch case), without adding a separate orphan-branch sweep.
- Updated `src/daemon/runtime.rs` call sites:
- `reconcile_worktrees` now passes branch mapping to `worktree::reconcile_worktrees`.
- Terminal-race cleanup in `dispatch_task` now passes branch to `remove_worktree`.
- `cleanup_worktree` now takes an optional branch and passes branch/default daemon branch to `remove_worktree`.
- `complete_task` now passes `task.branch` into cleanup when available.
- Updated `src/validate/tests_daemon.rs`:
- Extended `runtime_reconciliation_on_startup` to seed branches and assert cleanup via `git show-ref --verify refs/heads/<branch>` exit status.
- Added `runtime_restart_in_progress_with_stale_branch` to verify:
  - redispatch signal (`dispatched task ...`)
  - terminal task state in `tasks.json`
  - branch ref cleanup via `show-ref --verify` non-zero exit
- Added test helpers for branch creation and `show-ref --verify` status checks.
