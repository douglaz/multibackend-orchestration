# Feature: Commands Conformance Test Suite

## Description
Loops 1–3 are complete (framework + init/project + run suites). The remaining missing scope is `commands::` coverage: `src/validate/tests_commands.rs` is still empty, and `ralph validate --list` currently exposes 28 tests instead of the target 40. Implement the 12 command-level black-box conformance tests for `status`, `history`, `rollback`, `config`, and command exit-code behavior.

## Acceptance Criteria
- [ ] `src/validate/tests_commands.rs` registers exactly 12 tests with names: `commands::status_shows_info`, `commands::status_no_active_project`, `commands::history_shows_loops`, `commands::history_json`, `commands::history_verbose`, `commands::rollback_removes_loops`, `commands::rollback_resets_phase`, `commands::rollback_hard`, `commands::config_get`, `commands::config_set`, `commands::exit_code_workspace_not_found`, `commands::exit_code_project_not_found`.
- [ ] `commands::status_shows_info` creates a project and verifies `ralph status` output includes project identity and current phase/status fields.
- [ ] `commands::status_no_active_project` initializes workspace without an active project, runs `ralph status`, and verifies a non-crash failure with exit code `2` and a meaningful message.
- [ ] `commands::history_shows_loops` runs at least one feature loop and verifies `ralph history` lists loop entries.
- [ ] `commands::history_json` verifies `ralph history --json` is valid JSON and contains expected loop-history data (including loop entries).
- [ ] `commands::history_verbose` verifies `ralph history --verbose` includes richer detail than default history output (timestamps/backends/artifacts or equivalent additional fields).
- [ ] `commands::rollback_removes_loops` runs two loops, executes `ralph rollback 1`, and verifies loop-2 artifacts/state are removed while loop-1 remains.
- [ ] `commands::rollback_resets_phase` rolls back from a non-planning phase and verifies state resets to `current_phase = planning` (and reset iteration semantics).
- [ ] `commands::rollback_hard` verifies `ralph rollback --hard 1` updates state and resets git history to the expected reference (e.g., loop-1 tag/base) in addition to artifact rollback.
- [ ] `commands::config_get` verifies reading planner-backend config via canonical key path (e.g., `workflow.planner_backend`) returns the current value.
- [ ] `commands::config_set` verifies setting planner-backend config persists and is observable via a subsequent `config get`.
- [ ] `commands::exit_code_workspace_not_found` runs a workspace-dependent command without `.ralph` and verifies exit code `2`.
- [ ] `commands::exit_code_project_not_found` verifies `ralph project show nonexistent` exits with code `2`.
- [ ] All command tests remain strict black-box checks (CLI invocation + filesystem/git/stdout/stderr inspection only).
- [ ] After implementation, `ralph validate --bin <path> --list` reports `running 40 tests`.
