# Implementation Notes

## Decisions Made
- Followed the exact same `run_case` + `catch_unwind` pattern used by `tests_run.rs` for all 12 tests, keeping the test file structurally consistent with the rest of the suite.
- Duplicated the `setup_with_standard_mock` and `run_case` helper locally (same as `tests_run.rs`) rather than extracting into a shared module; this avoids cross-module coupling and matches the existing convention.
- For `history_verbose`, compared output length between default and `--verbose` modes rather than asserting specific additional fields; this is more resilient to format changes while still verifying verbose mode emits richer content.
- For `history_shows_loops`, used a flexible case-insensitive substring check (`Loop 1` / `loop 1` / `loop-1`) to accommodate reasonable formatting variations.
- For `status_no_active_project`, checked combined stdout+stderr for a non-empty message rather than asserting a specific string, as the spec requires "a meaningful message" without specifying the exact text.
- For `rollback_resets_phase`, used `rollback 0` (roll back to before any loops) to verify phase reset, since `--until-review` leaves the project in `committing` phase.
- Added assertion helpers `assert_stderr_contains`, `assert_path_not_exists`, `git_head_commit`, and `git_tag_commit` to `assertions.rs`; the first two are available for future tests but not all were used directly by these 12 tests.

## Spec Deviations
- No harness.rs changes were needed; the existing `loop_dir()`, `load_state()`, and `ralph_*()` methods were sufficient for all command tests.

### Summary of changes

**`src/validate/tests_commands.rs`** — Implemented all 12 conformance tests:
1. `commands::status_shows_info` — Creates project, verifies `ralph status` includes project ID, phase, and status
2. `commands::status_no_active_project` — Inits workspace without project, verifies exit code 2 with a message
3. `commands::history_shows_loops` — Runs a loop, verifies `ralph history` lists loop entries
4. `commands::history_json` — Verifies `ralph history --json` is valid JSON with loops array
5. `commands::history_verbose` — Verifies verbose output is richer than default
6. `commands::rollback_removes_loops` — Runs 2 loops, rolls back to 1, verifies loop-2 artifacts removed
7. `commands::rollback_resets_phase` — Rolls back from committing phase, verifies reset to planning
8. `commands::rollback_hard` — Verifies `--hard` rollback resets git HEAD to loop-1 tag commit
9. `commands::config_get` — Reads `workflow.planner_backend`, verifies non-empty value
10. `commands::config_set` — Sets planner_backend to codex, reads back and verifies
11. `commands::exit_code_workspace_not_found` — Runs status without `.ralph`, verifies exit code 2
12. `commands::exit_code_project_not_found` — Runs `project show nonexistent`, verifies exit code 2

**`src/validate/assertions.rs`** — Added 4 helpers:
- `assert_stderr_contains()` — Checks stderr contains a needle string
- `assert_path_not_exists()` — Asserts a path does not exist
- `git_head_commit()` — Returns current HEAD commit hash
- `git_tag_commit()` — Returns commit hash for a given tag

Total test count: 5 (init) + 9 (project) + 14 (run) + 12 (commands) = **40 tests**.
