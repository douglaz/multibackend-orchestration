# Feature: Core CLI Contract Compliance and Validation Build Stability

## Description
Loops 1-4 and 6 completed the `validate` framework and 40-test suite, but core CLI behavior still diverges from `prompt.md` in four places: template filename contract, `history --json` shape, `planner_backend` config key support, and `tests/validate_cli.rs` binary discovery under Nix/release test runs. This feature closes those remaining conformance gaps so the project can complete.

## Acceptance Criteria
- [ ] `ralph init` creates non-empty canonical template files: `.ralph/templates/spec.md`, `.ralph/templates/implementation.md`, `.ralph/templates/review.md`, `.ralph/templates/completion.md`.
- [ ] Default template paths in generated `.ralph/ralph.toml` are `templates/spec.md`, `templates/implementation.md`, `templates/review.md`, and `templates/completion.md`.
- [ ] Legacy template naming (`planner.md`, `implementer.md`, `reviewer.md`, `completer.md`) remains backward-compatible for existing workspaces via alias files or compatible loading behavior.
- [ ] `ralph history --json` outputs a top-level JSON array (not full state object), ordered deterministically by loop number.
- [ ] `ralph config get planner_backend` and `ralph config set planner_backend <value>` work as aliases to `workflow.planner_backend` with read-after-write persistence.
- [ ] `planner_backend` alias behavior works in both global and project config scopes.
- [ ] `tests/validate_cli.rs` no longer assumes `target/debug/ralph` and can locate the built binary in release/Nix test environments when `CARGO_BIN_EXE_ralph` is unavailable.
- [ ] `nix build .#default` succeeds.
- [ ] Self-conformance run (`ralph validate --bin <freshly built ralph>`) passes all 40 tests with exit code 0.

## Files to Modify/Create
- `src/cli/init.rs` - switch/init canonical template filenames and add legacy compatibility handling.
- `src/config/global.rs` - update default template path values; adjust related config test fixtures.
- `src/cli/history.rs` - change JSON mode to emit top-level loop history array.
- `src/cli/config.rs` - add `planner_backend` alias mapping for `get`/`set`.
- `tests/validate_cli.rs` - harden binary discovery logic for profile-agnostic test environments.
- `tests/init_command.rs` - update init expectations to canonical template filenames/paths.
- `tests/orchestrator.rs` - update template setup to follow canonical/configured template paths.
