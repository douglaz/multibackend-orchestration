# Implementation Notes

## Decisions Made
- Extracted `panic_message()` helper into `mod.rs` as `pub(crate)` so all test submodules share it via `use super::*`, avoiding duplication across `tests_init.rs` and `tests_project.rs`.
- Each test function uses `std::panic::catch_unwind(AssertUnwindSafe(|| { ... }))` to convert assertion panics into `TestResult::Fail`, matching the runner's expected test function signature `fn(&RalphHarness) -> TestResult`.
- Added 5 new assertion helpers to `assertions.rs`: `assert_dir_exists`, `assert_file_not_empty`, `load_toml`, `assert_toml_field`, and `assert_json_array_len` — these are reusable by future test suites (`tests_run.rs`, `tests_commands.rs`).
- For `project::new_copies_prompt`, content comparison uses `.trim()` on both sides to tolerate trailing newlines that some implementations may add when writing the prompt file.
- For `project::new_rejects_duplicate`, the test constructs the ralph CLI args as `Vec<String>` to avoid mixed-type iterator issues with the prompt path.
- No changes to `harness.rs` were needed — the existing helpers (`init_workspace`, `create_project`, `load_state`, `load_index`, `ralph`, `ralph_ok`, `ralph_exit`) were sufficient for all 14 tests.

## Spec Deviations
- None. All 14 tests (5 init + 9 project) are implemented exactly as specified with the correct names.
