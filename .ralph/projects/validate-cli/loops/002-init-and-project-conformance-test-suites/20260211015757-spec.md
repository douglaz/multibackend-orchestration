# Feature: Init and Project Conformance Test Suites

## Description

The next logical feature is to implement the foundational black-box conformance coverage for `init` and `project` commands (14 tests total), which verifies workspace/project lifecycle behavior before adding more complex `run` and `commands` suites.

- [ ] `src/validate/tests_init.rs` registers exactly 5 tests with names: `init::creates_workspace_structure`, `init::creates_template_files`, `init::default_config`, `init::default_index`, `init::rejects_nonempty_dir`.
- [ ] `init::creates_workspace_structure` verifies `.ralph/`, `ralph.toml`, `index.json`, `projects/`, and `templates/` after `ralph init`.

- [ ] `init::rejects_nonempty_dir` runs `ralph init` twice and asserts exit code `2` on the second run.

- [ ] `project::list_shows_project`, `project::show_displays_info`, and `project::show_json` validate human and JSON outputs for correctness and parseability.
