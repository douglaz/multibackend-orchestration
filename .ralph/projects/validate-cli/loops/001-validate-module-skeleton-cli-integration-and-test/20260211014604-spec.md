# Feature: Validate Module Skeleton, CLI Integration, and Test Harness

## Description
Create the foundational infrastructure for the `ralph validate` subcommand. This includes the `src/validate/` module with its public interface (`ValidateArgs`, `execute()`), the `TestRunner` and `ConformanceTest` types, the `RalphHarness` for black-box testing, assertion helpers, and mock script generators. Wire the new `Validate` command into the CLI dispatcher. Move `tempfile` from dev-dependencies to dependencies. Update `flake.nix` for shebang patching. This feature delivers a working `ralph validate --bin <path>` that runs zero tests but has the complete framework ready for test registration.
