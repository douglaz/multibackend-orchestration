# Implementation Notes

## Decisions Made
- Added `prd_shutdown_timeout_secs: u64` to `DaemonRuntimeConfig` (default `60`, minimum `1`) and threaded it through config resolution and CLI daemon config construction.
- Introduced a shared `Arc<tokio::sync::Semaphore>` in `run()` and passed it into `dispatch_task`, `auto_rebase_phase`, `collect_children`, `poll_and_claim`, and worktree/task completion paths that touch repo-root git state.
- Refactored `dispatch_task` to stop mutating `children` directly and return `Result<ChildHandle>`; caller now inserts into `children` only after success.
- Preserved rollback behavior by keeping per-issue failure path in `poll_and_claim` for `ralph:in-progress` → `ralph:failed` when dispatch returns an error.
- Scoped semaphore acquisition to repo-root operations (`ensure_repo_ready`, `create_worktree`, `remove_worktree`, `sync_project_branch`, `git fetch` in rebase) and released before worktree-local/refinement work.
