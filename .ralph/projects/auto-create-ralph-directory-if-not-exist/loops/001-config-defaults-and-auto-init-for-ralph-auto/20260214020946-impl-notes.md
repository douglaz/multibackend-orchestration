# Implementation Notes

## Decisions Made
- Added full serde default coverage in `src/config/global.rs` by:
  - marking `GlobalConfig` and all nested config structs with `#[serde(default)]`
  - implementing `Default` for `WorkspaceConfig`, `BackendConfigs`, `BackendConfig`, `WorkflowConfig`, `TemplateConfig`, `GitConfig`, `CommitMessageStyle`, and `PromptChangeAction`
  - introducing backend-specific deserialization for `backends.claude` and `backends.codex` so missing backend blocks and missing backend fields both inherit the correct per-backend defaults.
- Refactored `src/cli/init.rs` to add `pub(crate) fn create_workspace(root: &Path) -> Result<Workspace>` and moved all template + legacy symlink creation there; `execute()` now delegates to it.
- Added `ensure_workspace()` in `src/cli/auto.rs` to:
  - return `Workspace::discover()` on success
  - catch only `RalphError::WorkspaceNotFound`, create `<cwd>/.ralph` via `init::create_workspace`, and print exactly `initialized workspace at .ralph` to stderr
  - propagate all other discovery/load errors unchanged.
- Added required unit tests:
  - `empty_toml_deserializes_to_defaults`
  - `whitespace_toml_deserializes_to_defaults`
  - `partial_sections_default_correctly`
  - `missing_single_backend_uses_backend_specific_default`
  - `ensure_workspace_creates_workspace_when_missing`
  - `create_workspace_writes_all_templates`
- Added new validate conformance module `src/validate/tests_auto_init.rs` with:
  - `auto_initializes_workspace_when_missing`
  - `auto_init_prints_stderr_notice`
  - `auto_does_not_change_other_commands_workspace_not_found_behavior`
  - `auto_on_existing_workspace_with_missing_ralph_toml_still_errors`
  - `init_behavior_unchanged_for_non_empty_target`
- Registered new validate tests in `src/validate/mod.rs`.
