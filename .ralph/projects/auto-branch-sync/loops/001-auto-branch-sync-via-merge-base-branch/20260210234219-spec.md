# Feature: Auto-Branch Sync via merge_base_branch

## Description
Fix a race condition where `ralph run` checks out a project branch that's behind the base branch (master), causing "No such file or directory" errors. After checking out the project branch, automatically merge the base branch into it so that any commits made to master after the branch was created (e.g. `.ralph/` project state files) become available on the project branch. This is implemented by adding a new `merge_base_branch()` helper in `src/git/branch.rs` and calling it from the auto-branch block in `Orchestrator::run()`.
