# Feature: GitHub Actions CI Workflow

## Description
Create a GitHub Actions CI workflow file that automatically validates the project on pull requests targeting `master` and pushes to `master`. The workflow uses the project's Nix Flakes setup to run build, lint (clippy), and format checks in a single job with proper caching.

## Acceptance Criteria
- [ ] `.github/workflows/ci.yml` exists and is valid GitHub Actions YAML
- [ ] Workflow triggers on `pull_request` with `branches: [master]`
- [ ] Workflow triggers on `push` with `branches: [master]`
- [ ] Workflow has a single job named `ci` running on `ubuntu-latest`
- [ ] Job has `permissions: contents: read`
- [ ] Step 1: `actions/checkout@v4`
- [ ] Step 2: `DeterminateSystems/nix-installer-action@v21`
- [ ] Step 3: `DeterminateSystems/magic-nix-cache-action@v13`
- [ ] Step 4: Runs `nix build -L`
- [ ] Step 5: Runs `nix develop -c cargo clippy --all-targets -- -D warnings`
- [ ] Step 6: Runs `nix develop -c cargo fmt -- --check`
- [ ] No other files are modified
- [ ] No bare `cargo` commands outside `nix develop -c`
- [ ] No extra jobs or matrix strategy
- [ ] All action references use exact pinned version tags (no `@main`, `@master`, or unpinned refs)

## Files to Modify/Create
- `.github/workflows/ci.yml` - Create this file with the complete CI workflow definition containing the single `ci` job with all six steps in the specified order

## Dependencies
- Requires: none
- Blocks: none
