# Feature: Quick-Dev CLI Commands (quick-dev-run and quick-dev-auto)

## Description
Wire the `QuickDevOrchestrator` (completed in Loop 2) into two new CLI subcommands: `quick-dev-run` and `quick-dev-auto`. `quick-dev-run` resumes or starts a quick-dev orchestration for an existing project. `quick-dev-auto` runs the `QuickPrdPipeline` to generate a spec, creates the project, then runs the quick-dev orchestrator — mirroring the existing `auto` command pattern but targeting the quick-dev 4-phase flow. Both commands must be registered in the top-level `Commands` enum and dispatch table.

## Acceptance Criteria
- [ ] New file `src/cli/quick_dev_run.rs` with `QuickDevRunArgs` struct containing clap args: `--project`, `--implementer-backend`, `--reviewer-backend`, `--pr-url`, `--workspace-root`, `--skip-commit`, `--max-review-iterations` (positive u32), `--max-final-review-retries` (positive u32).
- [ ] `quick_dev_run::execute(args)` loads or discovers workspace (using `--workspace-root` if provided, same pattern as `run.rs`), constructs `QuickDevOrchestrator`, and calls `run()` with `QuickDevRunOptions` mapped from args.
- [ ] New file `src/cli/quick_dev_auto.rs` with `QuickDevAutoArgs` struct containing clap args: `--idea` (required, non-empty), `--implementer-backend`, `--reviewer-backend`, `--project-id`, `--pr-url`, `--workspace-root`, `--skip-commit`, `--max-review-iterations` (positive u32), `--max-final-review-retries` (positive u32).
- [ ] `quick_dev_auto::execute(args)` runs `QuickPrdPipeline` (reusing the existing pattern from `auto.rs` — resolving writer/reviewer specs from workspace config defaults), creates the project via `create_project()`, then runs `QuickDevOrchestrator` with the created project ID.
- [ ] `quick-dev-auto` derives `project_id` from `--idea` via slugification (reusing existing `slugify_idea` pattern) when `--project-id` is not provided; fails if the derived ID is empty.
- [ ] `Commands` enum in `src/cli/mod.rs` gains two new variants: `QuickDevRun(quick_dev_run::QuickDevRunArgs)` and `QuickDevAuto(quick_dev_auto::QuickDevAutoArgs)`.
- [ ] `run()` dispatch in `src/cli/mod.rs` routes `Commands::QuickDevRun` to `quick_dev_run::execute` and `Commands::QuickDevAuto` to `quick_dev_auto::execute`.
- [ ] Module declarations `mod quick_dev_run;` and `mod quick_dev_auto;` added to `src/cli/mod.rs`.
- [ ] CLI parsing tests added for both commands: default args, all args, validation of non-empty `--idea`, positive integer validation for `--max-review-iterations` and `--max-final-review-retries`.
- [ ] `quick-dev-auto` uses workspace config `daemon_prd_writer_backend` and `daemon_prd_reviewer_backend` as fallback specs for the PRD pipeline (same pattern as existing `auto.rs`).
- [ ] Neither CLI command calls `mark_pr_ready()` or imports daemon PR lifecycle helpers.
- [ ] `cargo test` passes (`nix develop -c cargo test`).
- [ ] `nix build -L` passes.

## Files to Modify/Create
