# Implementation Notes

## Decisions Made
- Added `#[arg(long)] pub verbose: bool` only to `DaemonStartArgs` in `src/cli/daemon.rs` and plumbed it into `DaemonRuntimeConfig` so `--verbose` is accepted only for `daemon start` and rejected for `status`/`abort` by clap.
- Added `pub verbose: bool` to `DaemonRuntimeConfig` in `src/daemon/runtime.rs` and guarded all new diagnostics with `if config.verbose` (or `verbose` in blocking closures), with every new line emitted via `eprintln!` and prefixed `verbose:`.
- Updated `reconcile_tasks` to accept a `verbose: bool` parameter and logged per-task reset actions there; updated the startup call site accordingly.
- Instrumented required runtime event points:
  - poll-cycle summary (iteration, active child count, available slots, planned sleep seconds),
  - child collection terminal events (task id, pid, exit status/exit code) plus one still-running summary line when count > 0,
  - dispatch CAS success/race logs,
  - completion CAS success/race logs,
  - per-task adopt/re-adopt logs in `adopt_pending_tasks`.
- Added and registered four conformance tests in `src/validate/tests_daemon.rs`:
  - `daemon::verbose_flag_accepted_by_start`
  - `daemon::verbose_flag_rejected_by_status_and_abort`
  - `daemon::verbose_output_present_when_enabled`
  - `daemon::verbose_output_absent_when_disabled`
