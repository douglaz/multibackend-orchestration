## Failures

1. **Test `daemon::runtime_dispatch_backfills_legacy_failed_task_project_id` fails at line 7258**: The assertion `"prior loop artifacts should be preserved after dispatch"` panics because the artifact file at `.ralph/projects/backfill-proj-501/loops/001-initial/artifact.md` no longer exists after the daemon completes.

   **Root cause**: The test's mock `ralph` script exits with `exit 0` (success). When the spawned child completes successfully, the daemon transitions the task to `Completed` state. The `should_cleanup_worktree()` function (runtime.rs:171-173) returns `true` for `Completed` state, triggering `remove_worktree()` which runs `git worktree remove --force` on the worktree path. Since the pre-created worktree is not a real git worktree, the removal falls back to `fs::remove_dir_all()` (worktree.rs:232), deleting the entire directory including all `.ralph/projects/*/loops/` artifacts.

   **Expected**: Artifacts should survive dispatch.  
   **Actual**: The worktree (and all artifacts) are deleted by post-completion cleanup.

   **Evidence**:
   ```

   prior loop artifacts should be preserved after dispatch
   ```
