# Feature: Oracle System Prompt Exactness Fix

## Description
The master prompt specifies: _"Use this system prompt exactly"_ followed by the exact text. The current implementation in `combined_oracle_prompt()` appends `"\n\nReview the attached PR diff."` to the required prompt before passing it via `--prompt`. This extra sentence was introduced during Loop 3 (ORACLE-REV-001) when folding the former `--system` content into `--prompt`, but it deviates from the spec's "exactly" requirement. The validate test also asserts the wrong combined string, locking in the deviation.

Fix: pass `ORACLE_SYSTEM_PROMPT` verbatim as the `--prompt` argument and update the validate test to enforce the exact contract.

## Acceptance Criteria
- [ ] `combined_oracle_prompt()` is removed; `ORACLE_SYSTEM_PROMPT` is passed directly to `--prompt`
- [ ] The `--prompt` argument value is exactly: `You are a senior code reviewer. Review this PR diff for bugs, security issues, performance problems, and code quality. Be concise and actionable. Focus on substantive issues, not style nits.`
- [ ] The `eligible_pr_reviewed` validate test asserts the exact spec prompt without the appended `\n\nReview the attached PR diff.` suffix
- [ ] All existing validate conformance tests and unit tests continue to pass

## Files to Modify/Create

- `src/validate/tests_daemon_oracle_review.rs` — Update the prompt assertion in `eligible_pr_reviewed` (line ~389–395) to match the exact spec prompt without the extra suffix; update the mock oracle script if it logs/checks the prompt value
