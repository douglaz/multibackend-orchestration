# Implementation Notes

## Decisions Made
- Added a shared `run_gh_with_timeout` async helper in `github.rs` that wraps `process::run_command_with_timeout` via `tokio::task::spawn_blocking`, giving all `gh` subprocesses the same process-group timeout/kill behavior as `oracle` invocations.
- Created `_with_timeout` variants of all 6 `gh` helper functions used by oracle review (`list_open_non_draft_prs`, `fetch_pr_diff`, `fetch_authenticated_login_with_gh_bin`, `fetch_issue_comments_with_gh_bin`, `find_bot_comment_with_marker_exact_with_gh_bin`, `post_bot_comment_with_marker_outcome_with_gh_bin`) rather than modifying existing functions, keeping changes scoped to the oracle-review path only.
- Extracted `parse_issue_comments_output` as a shared helper to avoid duplicating the comment parsing logic between the original and timeout variants of `fetch_issue_comments_with_gh_bin`.
- Reused `daemon_oracle_review_timeout_secs` as the single timeout budget for all `gh` calls; no new config fields introduced.
- The timeout-bounded `post_bot_comment_with_marker_outcome_with_gh_bin_with_timeout` preserves the existing post-vs-readback outcome separation: if `gh issue comment` succeeds but readback times out, it still returns `Posted` so the caller advances state.
- Mock gh script extended with env-var-driven hang modes (`MOCK_GH_HANG_PR_LIST`, `MOCK_GH_HANG_API_USER`, `MOCK_GH_HANG_COMMENT_VIEW_PR`, `MOCK_GH_HANG_DIFF_PR`, `MOCK_GH_HANG_COMMENT_POST_PR`, `MOCK_GH_HANG_COMMENT_READBACK_PR`) using infinite loops, same pattern as the existing oracle timeout mock.

## Spec Deviations
- None. All acceptance criteria are addressed as specified.

## Testing
- 6 new conformance tests added covering all required scenarios: hung `gh pr list`, hung bot-login lookup, hung marker/comment lookup on one PR while a later PR still succeeds, hung `gh pr diff` on one PR while a later PR still succeeds, timed-out `gh issue comment` not advancing state, and timed-out readback-after-success still advancing state/count.
- Tests use `daemon_oracle_review_timeout_secs = 2` for the gh timeout tests to keep execution fast while still exercising the timeout path.
- All existing tests remain unchanged and continue to pass compilation.
- To verify: `cargo test` for unit tests, and `ralph validate` for the conformance test suite.
