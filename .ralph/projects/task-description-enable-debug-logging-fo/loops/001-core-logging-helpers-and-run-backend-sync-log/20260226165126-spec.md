# Feature: Core logging helpers and `run_backend_sync` log support

## Description
Add the foundational debug logging infrastructure to `interactive_prd.rs`: the canonical `log_dir` path helper, the `write_prompt_summary` helper that writes SHA-256 hash + byte length + preview of each prompt, and extend `run_backend_sync` to accept an optional `LogWriter` for writing attempt separators, prompt summaries, and routing execution through `execute_with_log`. This feature provides the building blocks that all subsequent logging integration depends on.

## Acceptance Criteria
- [ ] `fn log_dir(data_dir: &Path, owner: &str, repo: &str, issue_number: u32) -> PathBuf` is added to `interactive_prd.rs` and returns exactly `<data_dir>/<owner>/<repo>/.ralph/interactive-prd/<issue_number>/logs/`
- [ ] `fn write_prompt_summary(log: &mut LogWriter, prompt: &str)` is added to `interactive_prd.rs` with behavior: computes SHA-256 hex digest of full prompt bytes, computes byte length via `prompt.as_bytes().len()`, takes first 500 Unicode characters (`prompt.chars().take(500)`) as preview (not bytes), and writes a stable marker block inline to the `.log` file before backend execution
- [ ] `run_backend_sync` signature is changed to accept `log_writer: Option<&mut LogWriter>` as a fourth parameter
- [ ] When `log_writer` is `Some`: writes attempt separator with `is_fallback = log_writer.attempt() > 0` before execution, calls `write_prompt_summary`, then uses `backend.execute_with_log(prompt, log_writer)` instead of `backend.execute(prompt)`
- [ ] When `log_writer` is `None`: behavior is identical to the current implementation (uses `backend.execute(prompt)`, no log files created)
- [ ] All existing call sites of `run_backend_sync` are updated to pass `None` as the `log_writer` argument so existing behavior is unchanged
- [ ] Test: `run_backend_sync` with `Some(log_writer)` writes separator, prompt summary, and raw output to the log file
- [ ] Test: `run_backend_sync` with `None` creates no log file
- [ ] Test: `write_prompt_summary` handles multibyte UTF-8 safely and limits preview to 500 characters (not bytes)
- [ ] `cargo test` passes with all existing tests remaining green
