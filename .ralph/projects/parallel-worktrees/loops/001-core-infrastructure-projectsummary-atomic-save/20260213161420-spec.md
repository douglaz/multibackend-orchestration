# Feature: Core Infrastructure — ProjectSummary, Atomic Save, and Worktree-Local Active Project

## Description
Introduce the foundational types and mechanisms that replace the index-based system, without yet removing the index. This includes: (1) adding `created_at` to `ProjectState` with backward-compatible deserialization, (2) making `ProjectState::save` use atomic temp-file-and-rename, (3) creating the `ProjectSummary` computed struct, (4) implementing `Workspace` methods for directory-scan project listing (`list_projects`, `project_exists`, `load_project_summary`), and (5) implementing the worktree-local active-project file mechanism (`active_project_id`, `set_active_project_id`) with git-dir resolution and non-git fallback. The existing `WorkspaceIndex` and all its consumers remain untouched — this loop only adds the new parallel API surface so that subsequent loops can migrate consumers one at a time.

## Acceptance Criteria
- [ ] `ProjectState` has a `created_at: DateTime<Utc>` field with `serde(default = "default_created_at")` returning `DateTime::<Utc>::MIN_UTC` as sentinel
- [ ] `ProjectState::new()` sets `created_at` to `Utc::now()`
- [ ] `ProjectState::save()` uses `tempfile::NamedTempFile::new_in(dir)` + `persist(path)` for atomic writes
- [ ] `ProjectSummary` struct exists with fields: `id`, `name`, `status`, `created_at`, `completed_at`, `total_feature_loops`, `total_completion_attempts`, `last_loop_number`, `parent_project`
- [ ] `ProjectSummary` is correctly derived from `ProjectState` (completed loop counts, fallback `created_at` from earliest loop `started_at`, computed `completed_at`)
- [ ] `Workspace::list_projects()` scans `.ralph/projects/*/state.json`, returns `Vec<ProjectSummary>` sorted by project ID
- [ ] `Workspace::list_projects()` skips non-directory entries silently, skips dirs missing `state.json` with stderr warning, skips unparseable `state.json` with stderr warning
- [ ] `Workspace::project_exists(id)` returns `true` iff `.ralph/projects/<id>/state.json` exists
- [ ] `Workspace::load_project_summary(id)` loads a single project's state and returns `ProjectSummary`
- [ ] New file `src/workspace/active.rs` implements worktree-local active-project resolution
- [ ] `active_project_id()` uses `git rev-parse --git-dir` to find the per-worktree git directory, reads `.git/ralph-active-project` (or `<gitdir>/ralph-active-project` for worktrees)
- [ ] `active_project_id()` falls back to `.ralph/.active-project-local` for non-git repos
- [ ] `active_project_id()` returns `None` for missing, empty, or whitespace-only files; logs warning and returns `None` for invalid project ID format
- [ ] `set_active_project_id(id)` validates project existence via `project_exists()` before writing, returns `ProjectNotFound` if not
- [ ] Unit tests cover: `ProjectState` `created_at` default/new, atomic save roundtrip, `ProjectSummary` derivation, `list_projects` scan (empty dir, multiple projects, malformed state, non-dir entries), `active_project_id` read/write roundtrip, missing/empty/invalid file handling
- [ ] All existing tests continue to pass (index system is not modified)
