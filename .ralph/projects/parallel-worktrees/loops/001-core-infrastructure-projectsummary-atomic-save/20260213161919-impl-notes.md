# Implementation Notes

## Decisions Made
- Added `created_at` to `ProjectState` in `src/project/state.rs` with `#[serde(default = "default_created_at")]`, where `default_created_at()` returns `DateTime::<Utc>::MIN_UTC` for backward-compatible deserialization.
- Updated `ProjectState::new()` to initialize `created_at` with `Utc::now()`.
- Reworked `ProjectState::save()` to use atomic writes via `tempfile::NamedTempFile::new_in(...)` + `persist(...)`.
- Added `src/workspace/summary.rs` with `ProjectSummary` and `summarize_project(id, state)` to derive:
  - completed feature/completion counts
  - last loop number
  - `completed_at` (latest completed loop/attempt when project status is `Completed`)
  - `created_at` fallback to earliest loop `started_at` when legacy sentinel is present
- Added `src/workspace/active.rs` for worktree-local active-project storage:
  - resolves git dir via `git rev-parse --git-dir`
  - stores in `<gitdir>/ralph-active-project`
  - falls back to `.ralph/.active-project-local` outside git repos
  - treats missing/empty/whitespace as unset and warns on invalid project ID format
- Extended `Workspace` in `src/workspace/mod.rs` with additive APIs (index system untouched):
  - `list_projects()`
  - `project_exists(id)`
  - `load_project_summary(id)`
  - `active_project_id()`
  - `set_active_project_id(id)` (with existence validation and `ProjectNotFound` on missing project)
- Added unit tests covering `created_at` default/new behavior, atomic save roundtrip, summary derivation, project scanning behavior, and active-project read/write + invalid/missing/empty handling.
