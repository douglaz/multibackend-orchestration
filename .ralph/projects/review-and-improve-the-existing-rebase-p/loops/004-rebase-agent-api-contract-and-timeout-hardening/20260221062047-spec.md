# Feature: Rebase Agent API Contract and Timeout Hardening

## Description
Loops 1 and 2 already delivered config plumbing, backend parsing, conflict classification, and iterative AI conflict recovery. The remaining gap is contract/conformance hardening: expose the required public entrypoint signature (`agent_backend: &str`) and enforce strict timeout/error propagation on all subprocess paths (including `rebase --abort` and post-`--continue` conflict checks).

## Acceptance Criteria
- [ ] `src/daemon/rebase_agent.rs` exposes `pub fn resolve_rebase_conflicts(worktree_path: &Path, rebase_target: &str, agent_backend: &str, deadline: Instant) -> Result<(), RalphError>`, with backend parsing handled internally.
- [ ] Unsupported/invalid backend strings passed to `resolve_rebase_conflicts` return clear, actionable `RalphError` messages.
- [ ] Runtime conflict recovery path calls the string-based entrypoint and preserves `"none"` behavior (no agent invocation, existing fallback behavior unchanged).
- [ ] All `git rebase --abort` calls in daemon runtime and rebase-agent fallback execute with bounded timeout derived from the shared deadline.
- [ ] Post-`git rebase --continue` conflict checks no longer swallow errors (`unwrap_or(false)` removed); timeout/spawn errors are propagated and surfaced.
- [ ] Existing failure-comment flow remains unchanged for non-conflict failures and agent-path failures.
- [ ] Unit/integration/validate tests are updated to cover entrypoint contract compliance and timeout/error-propagation behavior.

## Files to Modify/Create
- `src/daemon/rebase_agent.rs` - Add required public `&str` entrypoint, keep typed backend helper internal, bound abort with timeout, propagate post-continue check errors.
- `src/daemon/runtime.rs` - Use timeout-bounded abort path; invoke updated rebase-agent entrypoint while preserving conflict/non-conflict behavior.
- `src/cli/daemon.rs` - Adjust runtime plumbing only if needed to pass/retain backend spec string alongside validation.
- `tests/daemon_rebase_agent.rs` - Update integration tests to call the public string entrypoint and assert timeout-propagation/abort behavior.
- `src/validate/tests_daemon_rebase.rs` - Add/adjust conformance coverage for entrypoint contract and strict timeout/error propagation in fallback paths.
