# Feature: Timeout-Bounded Conflict Classification and Agent-Status Messaging

## Description
Loops 1, 2, and 4 already delivered config plumbing, backend parsing, conflict recovery looping, and core timeout enforcement. The remaining gap is final-review hardening: make conflict classification in `execute_rebase` fully deadline-bounded, and normalize backend handling so disabled mode and failure messages consistently indicate whether the rebase agent was attempted or skipped.

## Acceptance Criteria
- [ ] `execute_rebase` computes remaining deadline budget before conflict classification and returns a timeout error immediately if no budget remains.
- [ ] Conflict probing in the classification path uses a timeout-bounded call (`git::has_conflicts_with_timeout`) instead of unbounded `git::has_conflicts`.
- [ ] Classification logic is split so pure criteria (exit code + stderr markers) remains unit-testable, while I/O conflict probing is separately bounded.
- [ ] `execute_rebase` parses `agent_backend` once via `parse_rebase_agent_backend` and branches on `RebaseAgentBackend`, removing raw string equality checks.
- [ ] Disabled backend normalization works for trimmed values (for example `" none "`), and follows the disabled/skip path consistently.
- [ ] Conflict-failure messaging explicitly states agent status:
  - [ ] Disabled path says agent resolution was skipped/disabled.
  - [ ] Agent-attempted path (including `rebase --continue` failure mapping) says agent resolution was attempted.
- [ ] Existing non-conflict rebase failure behavior remains unchanged.
- [ ] Unit tests cover timeout-bounded classification behavior, normalized `"none"` handling in runtime branch logic, and attempted/skipped error-message wording.
- [ ] Integration/validate coverage is updated for disabled-backend normalization and actionable attempted/skipped conflict-failure messages.

## Files to Modify/Create
- `src/daemon/runtime.rs` - Enforce bounded-time classification budget, parse backend once to typed enum, and standardize attempted/skipped conflict error messages.
- `src/daemon/rebase_agent.rs` - Refactor classifier helpers for pure-vs-I/O split and improve `RebaseContinueFailed` message actionability.
- `tests/daemon_rebase_agent.rs` - Add/update integration tests for normalized disabled backend and attempted/skipped messaging.
- `src/validate/tests_daemon_rebase.rs` - Add/update conformance tests for timeout-bounded classification path and normalized disabled behavior.

- Requires: Rebase Agent API Contract and Timeout Hardening (Loop 4)
- Blocks: Project completion for AI-Assisted Conflict Recovery for Daemon Auto-Rebase
