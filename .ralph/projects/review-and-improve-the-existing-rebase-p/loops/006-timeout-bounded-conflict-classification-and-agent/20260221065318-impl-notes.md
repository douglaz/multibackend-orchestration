# Implementation Notes

## Decisions Made
- Split `classify_rebase_failure` into `classify_rebase_failure_pure` (exit code + stderr only, no I/O) and the existing `classify_rebase_failure` (which wraps the pure version + unbounded `git::has_conflicts`). The pure variant is used in `execute_rebase` where deadline-bounded I/O is required; the full variant is preserved for backward compatibility in tests and validate code that don't need timeout control.
- In `execute_rebase`, `parse_rebase_agent_backend` is called once at the top of the function. The parsed `RebaseAgentBackend` enum is used for the disabled/enabled branch, while the raw `agent_backend` string is still passed to `resolve_rebase_conflicts` (which re-parses it) to maintain the existing public API contract without introducing a new typed entrypoint.
- Error messages use consistent wording: disabled path says "agent resolution was skipped/disabled", all agent-attempted error variants (timeout, spawn, non-zero, unresolved, iteration cap, continue-failed) say "agent resolution was attempted".
- The `execute_rebase` disabled-path conflict message now includes "(agent resolution was skipped/disabled)" inline, keeping the stderr tail for diagnostics.

## Spec Deviations
- The spec says `execute_rebase` should "return a timeout error immediately if no budget remains" before classification. Implemented as: after the pure (no-I/O) classification indicates a likely conflict, `remaining("conflict classification")?` is called which returns a timeout error if budget is exhausted, before the `has_conflicts_with_timeout` I/O probe. The pure check itself needs no budget since it's just string/integer matching.
- The spec mentions `git::has_conflicts_with_timeout` for the classification path — this is used in `execute_rebase` via `crate::git::has_conflicts_with_timeout(worktree_path, classify_budget)`. The existing `classify_rebase_failure` (with unbounded I/O) is preserved for backward compatibility in unit tests that create real conflict repos, but the runtime path in `execute_rebase` now uses the bounded version.
