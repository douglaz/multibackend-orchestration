# Implementation Notes

## Decisions Made
- **Internal error model**: Created `AgentError` enum inside `rebase_agent.rs` with variants `Timeout`, `SpawnFailed`, `AgentNonZero`, `UnresolvedConflicts`, `IterationCapReached`, and `RebaseContinueFailed`, all mapped to `RalphError::Orchestration` with clear messages at the boundary via `into_ralph_error()`.
- **Rebase-in-progress detection**: Implemented `is_rebase_in_progress()` directly in `rebase_agent.rs` by checking for `.git/rebase-merge` or `.git/rebase-apply` directories, with worktree-aware fallback (reading `.git` file to find the real gitdir). This avoids adding to `src/git/mod.rs` since the function is specific to the agent's abort logic.
- **Agent command construction**: `build_agent_command()` invokes `claude` with `-p`, `--permission-mode acceptEdits`, `--allowedTools Bash,Edit,Write,Read,Glob,Grep`, `--model <model>`, and the prompt as the last positional arg. Restricts tools to those needed for conflict resolution.
- **GIT_EDITOR=true**: Set `GIT_EDITOR=true` for `git rebase --continue` to avoid interactive commit message editing.
- **execute_rebase signature change**: Added `agent_backend: &RebaseAgentBackend` parameter to `execute_rebase()`. The function now branches on `RebaseFailureKind::Conflict` with agent-enabled vs. agent-disabled. Non-conflict failures preserve the existing abort+error path unchanged.
- **Shared deadline plumbing**: The `deadline` from `execute_rebase` (computed from `rebase_timeout_seconds`) is passed through to `resolve_rebase_conflicts`, where it governs all agent invocations and `--continue` steps via `remaining_budget()`.
- **Integration tests**: Used PATH manipulation to inject mock `claude` scripts. Tests cover: successful single-commit recovery, multi-commit recovery (two conflicting commits), agent non-zero exit, agent success-without-resolution, and timeout scenarios.

## Spec Deviations
- **`src/git/mod.rs` not modified**: The spec listed it as a file to potentially modify for rebase-in-progress detection. Since the helper is tightly coupled to the agent's abort logic and has worktree-specific concerns, it was implemented in `rebase_agent.rs` instead, avoiding unnecessary changes to the git module.
- **Integration test PATH environment**: The integration tests in `tests/daemon_rebase_agent.rs` manipulate `std::env::set_var("PATH")` to inject mock `claude` binaries. This works for single-threaded test execution. The tests restore PATH after each test.
