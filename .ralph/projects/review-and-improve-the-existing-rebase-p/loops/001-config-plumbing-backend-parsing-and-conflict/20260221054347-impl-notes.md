# Implementation Notes

## Decisions Made
- Added `src/daemon/rebase_agent.rs` with:
  - `RebaseAgentBackend` enum (`None`, `Claude { model }`)
  - `parse_rebase_agent_backend(&str)` supporting `none`, `claude`, `claude(<model>)` and clear validation errors otherwise
  - `RebaseFailureKind` enum (`Conflict`, `Other`)
  - `classify_rebase_failure(exit_code, stderr, worktree_path)` implementing the exact conflict criteria (`exit_code == 1`, stderr indicator, and `git::has_conflicts == true`)
  - Unit tests for all required parse and classifier cases.
- Exported new module via `src/daemon/mod.rs`.
- Added global config key in `src/config/global.rs`:
  - `workspace.daemon_rebase_agent_backend: String`
  - serde/default plumbing with `default_daemon_rebase_agent_backend()` returning `"claude(opus)"`
  - updated default/deserialization tests for backward compatibility.
- Added project override in `src/config/project.rs`:
  - `daemon.rebase_agent_backend: Option<String>`.
- Threaded resolved value through daemon config/runtime:
  - `EffectiveDaemonConfig.rebase_agent_backend` in `src/config/mod.rs` with project override precedence.
  - `DaemonRuntimeConfig.rebase_agent_backend` in `src/daemon/runtime.rs`.
  - `src/cli/daemon.rs` now parses/validates resolved backend during startup and stores typed enum in runtime config.
- Kept runtime behavior unchanged beyond classifier extraction:
  - `execute_rebase` now classifies failure before abort and uses classification in error message, but still aborts and fails as before.
- Updated config CLI wiring in `src/cli/config.rs`:
  - project `config get/show` now includes `daemon.rebase_agent_backend`
  - `config set` supports `workspace.daemon_rebase_agent_backend` and `daemon.rebase_agent_backend` with parser validation.
- Added validate conformance coverage:
  - new `src/validate/tests_daemon_rebase.rs`
  - registered in `src/validate/mod.rs`
  - tests cover default value, missing-key backward compatibility, and `"none"` disabled parsing path.
