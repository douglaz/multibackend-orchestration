# Feature: Error model enrichment — TimeoutKind and BackendTimeout context

## Description
Introduce a `TimeoutKind` enum (`Idle`, `Walltime`) and enrich `RalphError::BackendTimeout` with `idle_seconds` and `timeout_kind` fields. Update all existing sites that construct or match on `BackendTimeout` to use the new shape.
