# Implementation Response (Iteration 1)

## Changes Made
1. **Added shared `validate_amendment_subsections` helper** (`src/workflow/parser.rs:653-669`): A reusable function that validates required subsection headings within an amendment block body. It checks each required `### <Subsection>` heading on its own line and returns `ParseError` with the amendment ID and missing subsection name on first failure. This addresses the recommended improvement of having a shared helper for consistent fail-closed rules.

2. **Enforced required subsections in `parse_final_reviewer_output`** (`src/workflow/parser.rs:384-391`): After extracting amendment blocks and validating no duplicate IDs, each amendment is now validated for `### Problem`, `### Proposed Change`, and `### Affected Files` subsections. Missing any of these returns a `ParseError` referencing the failing amendment ID.

3. **Enforced `### Rationale` in `parse_planner_position_output`** (`src/workflow/parser.rs:422`): After validating the `### Position` value (ACCEPT/REJECT), each amendment block is now checked for the `### Rationale` subsection.

4. **Enforced `### Rationale` in `parse_vote_output`** (`src/workflow/parser.rs:460`): After validating the `### Vote` value, each amendment block is checked for `### Rationale`.

5. **Enforced `### Rationale` in `parse_arbiter_output`** (`src/workflow/parser.rs:498`): After validating the `### Ruling` value, each amendment block is checked for `### Rationale`.

6. **Fixed existing duplicate-ID test data** (`src/workflow/parser.rs:1141-1146`): Updated `final_reviewer_rejects_duplicate_amendment_ids` test to include all required subsections in its amendment blocks, ensuring the test stays focused on the duplicate check.

7. **Added 8 new unit tests for subsection rejection**:
   - `final_reviewer_rejects_amendment_missing_problem` — verifies `### Problem` is required
   - `final_reviewer_rejects_amendment_missing_proposed_change` — verifies `### Proposed Change` is required
   - `final_reviewer_rejects_amendment_missing_affected_files` — verifies `### Affected Files` is required
   - `final_reviewer_rejects_second_amendment_missing_subsection` — verifies per-amendment validation (first OK, second fails)
   - `planner_position_rejects_missing_rationale` — verifies `### Rationale` is required
   - `vote_output_rejects_missing_rationale` — verifies `### Rationale` is required
   - `arbiter_output_rejects_missing_rationale` — verifies `### Rationale` is required
   - `planner_position_rejects_partial_rationale_coverage` — verifies partial coverage fails (first amendment has Rationale, second doesn't)
