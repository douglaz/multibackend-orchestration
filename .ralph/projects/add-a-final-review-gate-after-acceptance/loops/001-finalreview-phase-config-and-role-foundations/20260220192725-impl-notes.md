# Implementation Notes

## Decisions Made
- Added `Phase::FinalReview` to `src/project/state.rs` and updated all phase-label mappings in `src/workflow/orchestrator.rs`, `src/cli/status.rs`, `src/cli/project.rs`, and `src/cli/tail.rs` to emit `final_review`.
- Extended workflow config foundations:
  - `WorkflowConfig` now includes all six `final_review_*` fields with required defaults in `src/config/global.rs`.
  - `ProjectWorkflowOverrides` now includes matching `Option<T>` override fields in `src/config/project.rs`.
  - `EffectiveWorkflowConfig` now resolves all six fields with project > global precedence in `src/config/mod.rs`.
- Implemented final-review config validation in `src/config/mod.rs`:
  - canonical backend-spec deduplication for reviewer list,
  - empty/min-reviewer checks when enabled,
  - consensus-threshold bounds checks,
  - arbiter backend family validation,
  - arbiter/reviewer family overlap detection + warning.
- Extended backend role support:
  - `BackendRoleModels` and `RoleTimeouts` now support `final_reviewer` and `arbiter` (including `for_role`/`fill_from`) in `src/config/global.rs`.
  - `backend_role_model_specs` role sweep now includes `final_reviewer`/`arbiter` in `src/backend/mod.rs`.
- Added final-review artifact foundations in `src/project/artifacts.rs`:
  - `FinalReviewProposals`,
  - `FinalReviewPlannerPositions`,
  - `FinalReviewVotes`,
  - `FinalReviewArbiterRuling`,
  - `FinalReviewExit`,
  with corresponding `base_type` and filename behavior.
- Added/updated tests for:
  - final-review config validation and overlap detection (`src/config/mod.rs` tests),
  - role model/timeout behavior updates (`src/config/global.rs` tests),
  - `Phase::FinalReview` serde round-trip (`tests/state.rs`),
  - final-review artifact filenames/types (`src/project/artifacts.rs` tests),
  - tail wire-format label coverage (`src/cli/tail.rs` test),
  - backend role-model injection for new roles (`tests/backend.rs`).
- Removed two unrelated unused imports to keep `cargo check` warning-free (`src/backend/mod.rs`, `src/validate/tests_auto_init.rs`).

## Spec Deviations

- FinalReview transition flow is not implemented in this pass; a placeholder `Phase::FinalReview` orchestrator arm currently returns a clear orchestration error until the later flow feature is implemented.
