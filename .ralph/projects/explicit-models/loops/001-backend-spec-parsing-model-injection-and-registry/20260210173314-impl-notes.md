# Implementation Notes

## Decisions Made
- Added `BackendSpec` and `parse_backend_spec` in `src/backend/mod.rs` with validation for empty name/model and malformed parentheses to support `backend(model)` safely.
- Updated `src/backend/claude.rs` and `src/backend/codex.rs` so `backend_from_config` accepts `Option<&str>` model, prepends `--model <MODEL>` to args, and sets backend name to full spec (for example `claude(opus)`).
- Extended `BackendRegistry` with `get_or_create_for_spec(&mut self, spec: &str)` to parse specs, cache by full spec string, and lazily create model-specific backends with tmux wrapping preserved.
- Updated registry alternation/assignment behavior so model spec propagates only on the starting side (planner/reviewer on odd loops), while opposite roles use bare backend names.
- Updated orchestrator backend lookups to use `get_or_create_for_spec(...)`, enabling execution of model-qualified backend names from loop assignments/state.
- Updated `resolve_effective_config()` in `src/config/mod.rs` to parse `starting_backend` and validate only the base backend name.
