# Feature: Early Prompt Push, PR Lifecycle Hardening, Retry Policy, and Git Pollution Prevention

## Description
This loop implements the four remaining requirement areas that complete the draft-PR lifecycle feature set:

1. **Early Prompt Push** — Add `commit_and_push_initial_prompt()` in `commit.rs` that stages only the three prompt-input files, enforces a hard branch guard, and commits/pushes immediately after branch checkout in the orchestrator. This ensures the prompt is synchronized to the remote before any implementation work begins.

2. **PR Lifecycle Hardening** — Update `handle_pr_flow` in `runtime.rs` so that when an existing PR is found, it inspects draft status: if draft and completion conditions are met, mark it ready via `mark_pr_ready`; if PR has no diff against base and remains draft, close it via `close_pr` and clear the stored PR URL from task metadata and project state.

3. **`complete_task` Retry Policy** — Wrap the body of `complete_task` in a retry loop: max 3 attempts total, 30-second delay between attempts, retrying only transient failures (network/transport/rate-limit/subprocess errors). Validation, branch, and config logic errors must not be retried. Classify failures by matching against existing `RalphError` variants.

4. **Git Pollution Prevention** — Add generated-artifact patterns to `.gitignore` (covering `codex_output/`, `SPEC.md`, and any other backend side-effect paths). In `commit_and_push_phase_transition`, explicitly unstage tracked generated artifacts via `git rm --cached --ignore-unmatch` before the commit step, and handle "pathspec did not match" errors silently without deleting working-tree files.

5. **Remaining Conformance Tests** — Add the 6 missing tests from the required 12-test list to complete full coverage.
