# Review: SUGGESTIONS

## Required Changes

1. **Early Prompt Push — function missing**: `commit_and_push_initial_prompt()` does not exist in `src/git/commit.rs`.
   - Current: No such function exists anywhere in the codebase.
   - Expected: A public function `commit_and_push_initial_prompt(repo_root, project_id, branch)` that (a) resolves the HEAD branch and returns `RalphError::BranchMismatch` on mismatch, (b) stages only the three prompt-input files under `.ralph/projects/<id>/`, (c) returns `Ok(())` on empty staged diff, (d) commits and pushes on non-empty diff.
   - Reference: Spec acceptance criteria 1–5.

2. **Orchestrator call-site missing**: `orchestrator.rs` does not call `commit_and_push_initial_prompt` after branch checkout.
   - Current: After `checkout_branch` (line ~260) and `merge_base_branch` (line ~261), the orchestrator proceeds directly to the loop.
   - Expected: Insert a call between branch checkout and the first loop iteration.
   - Reference: Spec acceptance criterion 6.

3. **PR lifecycle — draft→ready promotion missing**: `handle_pr_flow` in `src/daemon/runtime.rs` does not call `is_pr_draft()` or `mark_pr_ready()`.
   - Current: When an existing PR is found, it edits title/body but never inspects or promotes draft status. The functions exist in `src/daemon/github.rs` (lines 616, 639) but are unused.
   - Expected: When an existing PR is found and task completed successfully, check `is_pr_draft()` and call `mark_pr_ready()`.
   - Reference: Spec acceptance criterion 7.

4. **PR lifecycle — no-diff draft closure missing**: `handle_pr_flow` detects no-diff but does not close the PR or clear the stored URL.
   - Current: Posts a no-diff comment and returns early. Does not call `close_pr()` or clear via `save_task_metadata`.
   - Expected: When a draft PR has no diff against base, close it and clear the PR URL.
   - Reference: Spec acceptance criterion 8.

5. **`complete_task` retry logic missing**: `complete_task` in `src/daemon/runtime.rs` has no retry loop.
   - Current: Each operation is attempted once; errors are logged and execution continues best-effort.
   - Expected: Max 3 total attempts, 30-second delay between attempts, retry only transient failures.
   - Reference: Spec acceptance criteria 9–10.

6. **Error classification missing**: `src/error.rs` has no `is_transient()` method on `RalphError`.
   - Current: Only `is_quota_error()` and `exit_code()` exist on the impl block.
   - Expected: An `is_transient()` method classifying network/transport/rate-limit/subprocess errors as transient and validation/branch/config errors as terminal.
   - Reference: Spec acceptance criterion 11.

7. **Git pollution prevention — `.gitignore` incomplete**: `.ralph/task_metadata/` pattern is missing from `.gitignore`.
   - Current: File contains `.ralph/**/*.log`, `.ralph/quick-prd/`, and `/SPEC.md` but not `.ralph/task_metadata/`.
   - Expected: Add `.ralph/task_metadata/` to `.gitignore`.
   - Reference: Spec acceptance criterion 12.

8. **Git pollution prevention — unstage in `commit_and_push_phase_transition` missing**: The function at `src/git/commit.rs` runs `git add -A` without unstaging generated artifacts.
   - Current: `git add -A` is followed directly by commit with no `git rm --cached` step. The sibling functions `commit_feature_loop` (line ~123) and `stage_implementation_changes` (line ~204) both include `git rm --cached -r --ignore-unmatch .ralph` but `commit_and_push_phase_transition` does not.
   - Expected: After `git add -A`, add `let _ = run_git(repo_root, &["rm", "--cached", "-r", "--ignore-unmatch", ".ralph"]);` matching the pattern in sibling functions.
   - Reference: Spec acceptance criteria 13–15.

9. **Conformance tests missing**: All 6 required new tests are absent from `src/validate/tests_pr_runtime.rs`.
   - Current: File contains 6 tests from loop 2 (draft watcher create, push order, cancellation, child args, e2e binary, persistence). None of the 6 loop 3 tests exist.
   - Expected: Add tests for: (1) early prompt push stages only prompt files, (2) branch mismatch safety, (3) draft→ready promotion, (4) no-diff draft closure, (5) retry transient 3 attempts, (6) no-retry terminal errors.
   - Reference: Spec acceptance criteria 16–21.
