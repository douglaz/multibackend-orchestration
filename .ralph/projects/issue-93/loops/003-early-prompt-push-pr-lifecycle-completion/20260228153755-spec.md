# Feature: Early Prompt Push, PR Lifecycle Completion, complete_task Retry, and Git Pollution Prevention

## Description
Implements the four remaining requirement groups for the draft-PR lifecycle feature:

1. **Early Prompt Push**: Add `commit_and_push_initial_prompt()` in `commit.rs` that stages only the three prompt-input files (`prompt.md`, `state.json`, `config.toml` under `.ralph/projects/<id>/`), enforces a hard branch guard (resolve HEAD branch, compare to expected project branch, return `BranchMismatch` on mismatch), skips commit when staged diff is empty, and commits+pushes when diff exists. Call it from `orchestrator.rs` immediately after successful branch checkout and before the implementation loop begins.

2. **PR Lifecycle Management**: Update `handle_pr_flow` in `runtime.rs` to: (a) check if the existing PR is a draft via `is_pr_draft()` and, when completion conditions are met, call `mark_pr_ready()` to promote it; (b) when the PR has no diff against base and remains draft, call `close_pr()` and clear the stored PR URL/state via `TaskMetadata`.

3. **complete_task Retry Behavior**: Update `complete_task` in `runtime.rs` with: max 3 attempts total, 30-second delay between attempts, retry only transient failures (network/transport/rate-limit/subprocess transient errors), do not retry validation/branch/config logic errors. This requires classifying `RalphError` variants into transient vs terminal categories.

4. **Git Pollution Prevention**: Add generated-artifact patterns (`.ralph/**/*.log`, `.ralph/quick-prd/`, `/SPEC.md`, `.ralph/task_metadata/`) to `.gitignore` if missing. In `commit_and_push_phase_transition`, explicitly unstage tracked generated artifacts via `git rm --cached` before commit, ignoring "pathspec not found" safely and never deleting working-tree files.

5. **Remaining Conformance Tests**: Add the 6 missing tests from the required 12:
   - Test 1: Early prompt push stages only prompt files.
   - Test 2: Early prompt push fails safely on branch mismatch.
   - Test 7: Draft PR is marked ready in ready transition path.
   - Test 8: No-diff draft PR is closed.
   - Test 9: `complete_task` retries transient failures exactly up to 3 attempts.
   - Test 10: `complete_task` does not retry terminal errors.
