# Review: SUGGESTIONS

## Required Changes

### 1. Missing PR URL orchestrator integration (runtime.rs:1162-1173, orchestrator.rs:135)

**Location**: `src/daemon/runtime.rs:1162-1173`, `src/workflow/orchestrator.rs:135`

**Issue**: The `pr_url` field is added to `RunOptions` and resolved in the daemon runtime before spawning child processes, but it is **never used** within the orchestrator itself. The orchestrator receives `options.pr_url` but does not persist it, propagate it, or make it available to any workflow phases.

**Required Fix**: The orchestrator must store and utilize the PR URL. Add a field to the orchestration context or project state to persist the PR URL across workflow phases. Without this, the PR URL is passed to child processes but never accessible to the orchestrator's internal logic (e.g., for marking PRs ready, updating PR descriptions, or linking artifacts to the PR).

**Suggested approach**:
- Add `pr_url: Option<String>` to the orchestration context or a persistent location in `ProjectState`
- Propagate `options.pr_url` into this field early in `Orchestrator::run`
- Expose the PR URL to phases that need it (e.g., completion phase, final review phase)

### 2. Draft PR watcher lacks persistence across daemon restarts (runtime.rs:1210, runtime.rs:1162-1173)

**Location**: `src/daemon/runtime.rs:1210`, `src/daemon/runtime.rs:1162-1173`

**Issue**: The draft PR watcher is skipped if `pr_url.is_some()` at spawn time (line 1210). However, `pr_url` is resolved by calling `github::find_existing_pr` (lines 1162-1173) **only once** at the moment of child dispatch. If the daemon restarts after a draft PR is created but before the child completes, the watcher will **not** run again for that task on the next daemon start, because the in-memory check happens only during initial dispatch.

**Consequence**: If a daemon restarts, the draft PR watcher may not resume for tasks that already have a PR. This is acceptable if the PR URL is already resolved and persisted. However, if the PR URL is not persisted (see issue #1), restarted tasks will lose their PR URL reference entirely.

**Required Fix**: Persist the PR URL in durable task metadata (e.g., a `.ralph/daemon/tasks/{task_id}.json` file or in the project state). On daemon restart, reload the PR URL for in-progress tasks so that:
1. The watcher does not redundantly create a second draft PR
2. The orchestrator and runtime can access the PR URL even after a daemon restart

**Suggested approach**:
- Write the PR URL to a durable task metadata file when the draft PR is created
- On daemon startup (during `dispatch_task` for resumed tasks), read the persisted PR URL and populate the `pr_url` variable before deciding whether to spawn the watcher

### 4. Draft PR watcher does not handle race conditions on PR creation (runtime.rs:238-254)

**Location**: `src/daemon/runtime.rs:238-254`

**Issue**: The draft PR watcher creates a draft PR when the branch is ahead of base (line 239: `github::create_pr(...)`). However, if two watchers or two daemon instances concurrently observe the same branch state, both may attempt to create a PR. GitHub will reject the duplicate PR creation, but the error handling (lines 249-253) only logs the error and does not distinguish between "PR already exists" and other failures.

**Consequence**: The watcher may fail to record the PR URL if another process created the PR first, leaving the task without a persisted PR URL reference.

**Required Fix**: After a PR creation failure, re-query `github::find_existing_pr` to check if another process created the PR. If found, treat it as success and persist the PR URL.

**Suggested code change** (lines 238-254):
```rust
match spawn_blocking_op(move || {
    github::create_pr(&owner_c, &repo_c, &br, &title, &body, true)
})
.await
{
    Ok(url) => {
        eprintln!("draft-pr-watcher: created draft PR for {task_id}: {url}");
        pr_created = true;
        // TODO: Persist PR URL to durable storage
    }
    Err(err) => {
        eprintln!("draft-pr-watcher: failed to create draft PR for {task_id}: {err}");
        // Re-check if another process created the PR
        let existing = github::find_existing_pr(&owner, &repo, &branch);
        if let Ok(Some(url)) = existing {
            eprintln!("draft-pr-watcher: found existing PR for {task_id}: {url}");
            pr_created = true;
            // TODO: Persist PR URL to durable storage
        }
    }
}
```
