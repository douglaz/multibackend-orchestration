# Feature: Draft PR Watcher Runtime and Child Process PR URL Plumbing

## Description
Implement the runtime-managed draft PR watcher and end-to-end PR URL propagation so `ralph` can automatically create draft PRs when a branch first moves ahead, expose the resulting PR URL to child executions, and always clean up watcher tasks safely across all exit paths.

This feature should focus on orchestration/runtime behavior and process wiring (not re-implementing GitHub API primitives already completed in Loop 1). It adds the execution control layer that uses those APIs in real workflows.

## Acceptance Criteria
- [ ] Add `draft_pr_watcher()` async task in runtime/orchestration flow that polls branch divergence on a fixed interval and uses cancellation-aware `tokio::select!` for immediate shutdown.
- [ ] Watcher creates a draft PR only when: branch is ahead of base, no PR URL is currently stored, and no concurrent creation attempt is active.
- [ ] Watcher performs unconditional push before draft PR creation, with observable ordering suitable for conformance assertions.
- [ ] Created PR URL is persisted/emitted so downstream execution can consume it.
- [ ] Add optional `--pr-url` to both `AutoArgs` and `RunArgs`, and plumb value through child process dispatch.
- [ ] When multiple PRs exist, dispatch resolves PR URL by exact head-branch match.
- [ ] Extend child runtime handle state with `ChildHandle.draft_pr_handle` and ensure watcher join/cancel on all exits (success, error, cancellation/interrupt).
- [ ] Add validate conformance tests for: draft create trigger, push-before-create ordering, cancellation shutdown, `--pr-url` plumbing timing, and real-binary e2e draft-create path.
- [ ] `cargo check`, `cargo test`, and validate suite pass with no orphan watcher tasks.

## Files to Modify/Create
- `src/runtime.rs` - implement `draft_pr_watcher()`, cancellation/select loop, single-flight creation guard, and handle lifecycle management.
- `src/workflow/orchestrator.rs` - start/stop watcher in orchestration lifecycle and wire emitted PR URL into flow state.
- `src/cli/args.rs` (or equivalent CLI args module) - add optional `--pr-url` to `AutoArgs` and `RunArgs`.
- `src/cli/run.rs` / `src/cli/auto.rs` (or equivalent command dispatch files) - pass PR URL into child invocation paths.
- `src/workflow/child.rs` (or equivalent child handle module) - add `draft_pr_handle` and robust teardown logic.
- `src/project/state.rs` (or equivalent state persistence module) - persist/clear PR URL updates emitted by watcher.
- `src/validate/tests_pr_runtime.rs` (new) - conformance tests for watcher behavior and child plumbing.
- `src/validate/mod.rs` - register new validate test module.

## Dependencies
- Requires: Loop 1 (GitHub API Extensions for Draft PR Lifecycle)
- Blocks: PR lifecycle completion logic hardening (`handle_pr_flow` ready/close transitions), `complete_task` retry policy tests, and final git-pollution/early-prompt integration verification
