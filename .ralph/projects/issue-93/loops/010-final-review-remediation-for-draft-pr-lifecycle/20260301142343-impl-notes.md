# Implementation Notes

## Decisions Made
- **Non-destructive `.ralph` unstaging**: Replaced `git rm --cached -r --ignore-unmatch .ralph` with `git reset HEAD -- .ralph` in `unstage_non_commit_artifacts()`. This restores `.ralph/` index entries to match HEAD rather than staging deletions, preserving tracked prompt inputs (e.g., `prompt.md`, `project.toml`, `config.toml`) committed via `commit_and_push_initial_prompt()`. The explicit `git rm --cached` for `GENERATED_ARTIFACT_PATHS` (e.g., `SPEC.md`) is retained since those are not tracked prompt inputs and should be removed from the index.
- **Resilient base-ref resolution**: Extracted a `resolve_ahead_base()` helper in `github.rs` that tries `origin/{configured_base}` first, then falls back to `detect_base_branch()` (which tries `origin/HEAD`, `origin/main`, `origin/master`, etc.), and finally returns a typed error if neither resolves. This aligns `has_commits_ahead_of_base()` with the same fallback strategy already used by `has_diff_with_base()`.
- **Bounded watcher failure handling**: Added a `consecutive_failures` counter to `draft_pr_watcher_with_sleep()` with a limit of 5 (`DRAFT_PR_WATCHER_MAX_CONSECUTIVE_FAILURES`). Each successful ahead-check resets the counter; each failure increments it with progressive logging. At the limit, the watcher logs an explicit terminal error and breaks out of the loop instead of silently looping forever.
- **Orchestrator test assertions**: Replaced the blanket `*l != "?? .ralph/"` filter with two targeted assertions: (1) no `.ralph/projects/` files are staged for deletion (`D  .ralph/projects/`), and (2) no uncommitted changes exist except untracked (`??`), ignored (`!!`), or working-tree-only modifications (` M`) of `.ralph/` files. The ` M` allowance is correct because `git reset HEAD -- .ralph` intentionally leaves tracked files in the index matching HEAD, so working-tree modifications show as unstaged (not staged for commit).
- **Conformance test for fallback base**: Added `pr_runtime::draft_watcher_fallback_base_when_configured_missing` — creates a repo where `master` doesn't exist as a remote ref (renamed to `main`), configures `master` as the base, and verifies the watcher still creates a draft PR by falling back to the detectable default branch.
- **Conformance test for non-destructive unstaging**: Added `pr_lifecycle::phase_transition_preserves_tracked_ralph_prompt_files` — commits tracked prompt files, runs `commit_and_push_phase_transition`, and asserts the files remain in the tree (no deletions in the diff).
