# Feature: Final Review Remediation for Draft PR Lifecycle (Safety + Robustness)

## Description
Most core objectives from `prompt.md` are already implemented across completed loops (early prompt push, draft PR watcher, PR lifecycle transitions, child `--pr-url` plumbing, and conformance coverage).  
The next logical feature is to close the remaining **final-review correctness gaps** that are still open:

1. **Non-destructive `.ralph` unstaging** in git commit paths  
   Replace `git rm --cached -r .ralph` behavior with index-only unstage/reset behavior so tracked orchestration files are never staged for deletion.

2. **Resilient ahead-of-base detection for draft watcher**  
   Harden `has_commits_ahead_of_base` so base branch mismatch (e.g. configured `master`, actual `main`) does not cause silent permanent “not ahead” behavior.

3. **Watcher failure handling for persistent base-resolution errors**  
   Runtime should not silently loop forever treating repeated base-ref failures as false; emit explicit actionable behavior (typed error handling and bounded/backoff failure strategy).

4. **Remove stray committed notes artifact**  
   Delete `20260228T151926-impl-notes.md` from tracked source tree.

This is a remediation/hardening feature that finishes unresolved review amendments (RVW-001/002/003) without re-planning already completed lifecycle functionality.

## Acceptance Criteria
- [ ] `unstage_non_commit_artifacts()` no longer uses `git rm --cached -r --ignore-unmatch .ralph`; it uses non-destructive staged-reset semantics for `.ralph` and keeps explicit artifact index removal only for intended generated files.
- [ ] In repos where `.ralph/projects/<id>/prompt.md` (and related tracked prompt inputs) are tracked, implementation/phase-transition staging does **not** stage deletions for those files.
- [ ] `has_commits_ahead_of_base()` resolves a valid comparison ref robustly (prefer configured base if available, otherwise fallback to resolvable remote/default base) and returns typed actionable errors when resolution fails.
- [ ] `draft_pr_watcher()` no longer silently treats repeated ahead-check errors as “not ahead forever”; behavior is explicit and bounded (e.g., backoff + terminal handling/logging).
- [ ] Conformance/runtime tests include a case where configured base branch is missing but default branch exists, and draft PR creation still occurs.
- [ ] Orchestrator tests no longer mask `.ralph` pollution via blanket `?? .ralph/` filtering; they use targeted assertions that tracked prompt inputs are not staged for deletion.
- [ ] `20260228T151926-impl-notes.md` is removed from repository tracking.
