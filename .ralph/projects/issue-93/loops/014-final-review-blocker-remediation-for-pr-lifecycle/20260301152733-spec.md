# Feature: Final Review Blocker Remediation for PR Lifecycle Safety and Base-Branch Robustness

## Description
Implement a focused remediation pass for outstanding final-review blockers that are **not yet safely resolved**:  
1) make `.ralph` unstaging non-destructive in commit flows,  
2) harden ahead-of-base detection so draft PR creation still works when configured base branch is missing locally, and  
3) remove stray non-source artifact noise from the repository.

This feature is the next logical step because core draft-PR lifecycle functionality exists, but current review findings indicate correctness/safety gaps that can still break behavior in real repositories and mask regressions in tests.

## Acceptance Criteria
- [ ] `unstage_non_commit_artifacts()` (and all callers) no longer uses destructive index deletion semantics for `.ralph/**`; tracked prompt/config files are never staged for deletion as a side effect of implementation/phase-transition commits.
- [ ] Unstaging logic uses a safe staged-reset strategy for orchestration paths (`git reset HEAD -- .ralph` or equivalent), with unborn-HEAD-safe fallback behavior.
- [ ] Generated artifact cleanup remains explicit and non-destructive (remove from index only where intended, never delete working tree files, pathspec-missing handled safely).
- [ ] `has_commits_ahead_of_base` resolves a usable base ref robustly (e.g., `origin/<configured>`, then remote default branch) before `rev-list --count`, and returns typed actionable errors on unresolved base.
- [ ] `draft_pr_watcher()` no longer silently treats persistent ahead-check failures as “not ahead forever”; it surfaces/handles persistent failures explicitly and avoids infinite silent non-creation behavior.
- [ ] Conformance coverage is added/updated for base-branch mismatch recovery (configured base missing, default exists, draft PR still created) and for `.ralph` tracked-file deletion regression prevention.
- [ ] Repository no longer contains `20260228T151926-impl-notes.md`.
- [ ] `nix develop -c cargo check`, `nix develop -c cargo test`, and validate tests pass with the new assertions.

## Files to Modify/Create
- `src/git/commit.rs` - replace destructive `.ralph` index removal with non-destructive unstage/reset logic; preserve explicit generated-artifact handling.
- `tests/orchestrator.rs` - remove masking behavior around `?? .ralph/`; add targeted assertions that tracked `.ralph/projects/<id>/prompt.md`, `project.toml`, and `config.toml` are not staged for deletion.
- `src/daemon/github.rs` - harden `has_commits_ahead_of_base` base-ref resolution and typed error propagation.

- `src/validate/tests_pr_lifecycle.rs` - optionally add/extend assertion preventing tracked prompt-input deletion staging in later commit flows.
