# Feature: Final Review Blocker Remediation (Safe Staging + Robust Draft Detection + Repo Hygiene)

## Description
Most of the draft-PR lifecycle scope is already implemented across completed loops (API extensions, watcher runtime, early prompt push, PR transitions, retry behavior, and conformance depth).  
The next logical feature is a **targeted remediation pass** for remaining release blockers identified in final review:

1. **Make `.ralph` unstaging non-destructive** in commit flows (avoid staging deletions of tracked prompt/config files).
2. **Harden ahead-of-base detection** so draft PR creation still works when configured base branch is missing locally (e.g., `master` vs `main` mismatch).
3. **Remove stray non-source artifact file** from version control.
4. **Strengthen tests** so these regressions cannot be masked.

This is a stabilization feature, not a net-new capability.

## Acceptance Criteria
- [ ] `unstage_non_commit_artifacts` no longer uses destructive index removal for `.ralph` paths; it uses reset/restore-style unstaging that preserves tracked files.
- [ ] Generated artifact cleanup remains explicit and safe (e.g., `SPEC.md`/other known generated files removed from index only), with no working-tree deletion.
- [ ] Behavior works in unborn-HEAD scenarios (graceful fallback when `HEAD` is unavailable).
- [ ] Orchestrator/commit-path tests assert that tracked `.ralph/projects/<id>/prompt.md`, `project.toml`, and `config.toml` are **not** staged for deletion.
- [ ] Existing blanket filtering that hides `?? .ralph/` pollution is removed/replaced with targeted assertions.
- [ ] `has_commits_ahead_of_base` resolves base robustly (`origin/<base>` when present, otherwise remote default branch) before `rev-list`.
- [ ] Persistent base-resolution failure is surfaced as typed actionable error handling in runtime flow (not silently treated as “not ahead forever”).
- [ ] Add/extend conformance coverage for missing configured base branch + available default branch, validating draft PR creation still occurs.
- [ ] Remove `20260228T151926-impl-notes.md` from repository tracking.
- [ ] `nix develop -c cargo check`, `nix develop -c cargo test`, and validate suite pass.

## Files to Modify/Create
- `src/git/commit.rs` - replace destructive `.ralph` index cleanup with non-destructive unstaging; keep explicit generated-artifact handling.
- `src/daemon/github.rs` - harden `has_commits_ahead_of_base` base-ref resolution and typed failure paths.
- `src/daemon/runtime.rs` - handle repeated ahead-check/base-resolution failures explicitly in watcher loop.
- `tests/orchestrator.rs` - remove masking filters and add assertions preventing staged deletion/pollution regressions.
- `src/validate/tests_pr_runtime.rs` - add conformance test for base-branch mismatch fallback behavior.
- `src/validate/tests_pr_lifecycle.rs` (optional but recommended) - add assertion that tracked prompt-input files are never staged for deletion by later commit paths.
- `src/validate/mod.rs` - register any newly added validate tests.
- `20260228T151926-impl-notes.md` - remove stray file from version control.
