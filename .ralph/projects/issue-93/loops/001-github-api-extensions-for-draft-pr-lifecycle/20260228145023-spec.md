# Feature: GitHub API Extensions for Draft PR Lifecycle

## Description
Extend the GitHub integration module (`src/daemon/github.rs`) with four new functions required by the draft PR lifecycle: `has_commits_ahead_of_base`, `mark_pr_ready`, `is_pr_draft`, and `close_pr`. Also add a `draft: bool` parameter to existing `create_pr` and `create_pr_with_body_file` API paths and wire it through all callers. Add a `BranchMismatch` error variant to `RalphError` for the branch safety guard needed by the early prompt push feature. These are foundational APIs that all subsequent PR lifecycle features depend on.

## Acceptance Criteria
- [ ] `has_commits_ahead_of_base(workdir, base_branch) -> Result<bool>` is implemented using `git rev-list --count <base>..HEAD` (or equivalent), returning `true` when count > 0.
- [ ] `mark_pr_ready(owner, repo, pr_number) -> Result<()>` is implemented using `gh pr ready <number> --repo <owner/repo>`.
- [ ] `is_pr_draft(owner, repo, pr_number) -> Result<bool>` is implemented by querying `gh pr view <number> --repo <owner/repo> --json isDraft` and parsing the boolean result.
- [ ] `close_pr(owner, repo, pr_number) -> Result<()>` is implemented using `gh pr close <number> --repo <owner/repo>`.
- [ ] `create_pr` gains a `draft: bool` parameter; when `true`, passes `--draft` to `gh pr create`.
- [ ] `create_pr_with_body_file` gains a `draft: bool` parameter; when `true`, passes `--draft` to `gh pr create`.
- [ ] All existing callers of `create_pr` and `create_pr_with_body_file` are updated to pass `draft: false` (preserving current behavior).
- [ ] A `BranchMismatch { expected: String, actual: String }` variant is added to `RalphError` for the early prompt push branch guard (used by later features).
- [ ] All new functions propagate errors through existing `RalphError::Orchestration` convention with descriptive messages.
- [ ] Unit tests are added for `is_pr_draft` JSON parsing (both `true` and `false` cases) and for the `BranchMismatch` error variant display.
- [ ] `nix develop -c cargo check` passes.
- [ ] `nix develop -c cargo test` passes.
