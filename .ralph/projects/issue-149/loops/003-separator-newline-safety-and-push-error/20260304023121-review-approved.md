## Notes
The implementation is minimal and correctly scoped:

1. **Separator newline safety**: Opens the log with `.read(true)` in addition to `.append(true)`, seeks to last byte, reads it, and conditionally prepends an extra `\n`. The append-mode semantics guarantee writes still go to the end regardless of the seek position used for reading. Error from the seek/read is propagated (not swallowed), which is correct since this is a pre-write I/O check, not the separator write itself (the spec only requires the separator *write* failure to be non-fatal, which is already handled by the existing `if let Err`).

2. **Push-error classification**: Three new non-retryable patterns (`"403"`, `"gh013"`, `"repository rule violation"`) are properly case-insensitive since the function lowercases the error string before matching. No risk of false positives on retryable patterns since these are substring matches on the lowercased form.
