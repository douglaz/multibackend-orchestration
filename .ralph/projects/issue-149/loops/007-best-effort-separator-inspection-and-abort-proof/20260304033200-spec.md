# Feature: Best-Effort Separator Inspection and Abort-Proof Watcher Timeout Test

## Description
Addresses two Round 2 final-review amendments that remain unfixed:

1. **FR-149-001**: In `open_log_file_append` (`src/daemon/process.rs`), metadata inspection (`file.metadata()`) and trailing-newline detection (`seek`/`read_exact`) propagate errors via `?`, which can fail command construction even though append logging itself would still work. Fix: downgrade these preflight checks to warnings and fall back to a conservative separator (`\n\n--- retrigger at <timestamp> ---\n\n`) when inspection fails. File-open failure remains fatal.

2. **FR-149-002**: The `await_watcher_with_timeout_impl_aborts_stuck_task` test (`src/daemon/runtime.rs`) spawns a task sleeping 5 seconds, times out at 25ms, then asserts the completion flag is still `false` after 50ms. This assertion passes regardless of whether the task was actually aborted — a non-aborted task is still sleeping at the 50ms mark. Fix: spawn a task that increments an atomic counter in a tight loop; after the helper returns, observe that the counter stops increasing, proving the task was actually aborted.

## Detailed Implementation

### `src/daemon/process.rs`

#### 1. Refactor `open_log_file_append` separator preflight to best-effort

Replace lines 184–216 with logic that catches inspection errors and falls back:

```rust
fn open_log_file_append(log_file: &Path) -> Result<std::fs::File> {
    let mut file = std::fs::OpenOptions::new()
        .create(true)
        .read(true)
        .append(true)
        .open(log_file)
        .map_err(|err| {
            RalphError::Orchestration(format!(
                "failed to open log file {} for append: {err}",
                log_file.display()
            ))
        })?;

    // Best-effort: determine whether the file already has content and whether
    // it ends with a newline.  Any failure here falls back to a conservative
    // separator instead of failing command construction.
    let has_content = match file.metadata() {
        Ok(meta) => meta.len() > 0,
        Err(err) => {
            eprintln!(
                "warning: failed to inspect log file {} metadata: {err}",
                log_file.display()
            );
            // Assume there is content so we emit a separator to be safe.
            true
        }
    };

    if has_content {
        let ends_with_newline = file
            .seek(SeekFrom::End(-1))
            .and_then(|_| {
                let mut last = [0_u8; 1];
                file.read_exact(&mut last).map(|_| last[0] == b'\n')
            });

        let timestamp = Utc::now().format("%Y-%m-%dT%H:%M:%SZ");
        let separator = match ends_with_newline {
            Ok(true) => format!("\n--- retrigger at {timestamp} ---\n\n"),
            Ok(false) => format!("\n\n--- retrigger at {timestamp} ---\n\n"),
            Err(err) => {
                eprintln!(
                    "warning: failed to inspect trailing newline for log file {}: {err}",
                    log_file.display()
                );
                // Conservative: add extra leading newline in case file doesn't end with one.
                format!("\n\n--- retrigger at {timestamp} ---\n\n")
            }
        };
        if let Err(err) = file.write_all(separator.as_bytes()) {
            eprintln!(
                "warning: failed to write retrigger separator to {}: {err}",
                log_file.display()
            );
        }
    }

    Ok(file)
}
```

**State invariant**: After this change, the only error that can fail `open_log_file_append` is `OpenOptions::open()`. All separator-related operations (metadata, seek, read_exact, write_all) are best-effort with warning logs on failure.

Replace the current test with one that uses an atomic counter loop:

```rust
#[tokio::test]
async fn await_watcher_with_timeout_impl_aborts_stuck_task() {
    let counter = Arc::new(AtomicU64::new(0));
    let counter_for_task = counter.clone();
    let join_handle = tokio::spawn(async move {
        loop {
            counter_for_task.fetch_add(1, Ordering::SeqCst);
            tokio::time::sleep(Duration::from_millis(1)).await;
        }
    });

    // Let the task run briefly so the counter is actively incrementing.
    tokio::time::sleep(Duration::from_millis(10)).await;
    let pre_timeout = counter.load(Ordering::SeqCst);
    assert!(pre_timeout > 0, "counter should be incrementing before timeout");

    await_watcher_with_timeout_impl(
        join_handle,
        "artifact watcher",
        "acme-widgets-77",
        Duration::from_millis(25),
    )
    .await;

    // Observe the counter over an additional window to confirm it has stopped.
    let snapshot_after = counter.load(Ordering::SeqCst);
    tokio::time::sleep(Duration::from_millis(50)).await;
    let snapshot_later = counter.load(Ordering::SeqCst);
    assert_eq!(
        snapshot_after, snapshot_later,
        "counter should stop changing after task is aborted (was {snapshot_after}, now {snapshot_later})"
    );
}
```

This proves the task was actually aborted: if it were still running, the counter would continue incrementing during the 50ms observation window.

**Import note**: Add `use std::sync::atomic::AtomicU64;` if not already imported in the test module.
