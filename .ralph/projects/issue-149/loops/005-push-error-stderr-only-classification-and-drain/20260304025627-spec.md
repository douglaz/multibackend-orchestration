# Feature: Push-Error Stderr-Only Classification and Drain Watcher Timeout

## Description
Addresses two final-review amendments:

1. **FR-20260304-01**: The `is_retryable_push_error` function classifies retry eligibility using the full formatted error string (`err.to_string()`), which includes the branch name. Numeric patterns like `"403"` or `"500"` in branch names (e.g., `fix/issue-403`) can cause misclassification. Additionally, unknown errors default to retryable (`true`), delaying permanent failures. Fix: classify on raw git stderr only and default unknown errors to non-retryable.

2. **FR-20260304-02**: `drain_all_children()` in `runtime.rs` awaits watcher join handles without a timeout, meaning a stuck watcher can block the shutdown/failure-completion path indefinitely. Fix: use `await_watcher_with_timeout()` consistently.

## Acceptance Criteria
- [ ] Push-error retry classification operates on raw git stderr, not the full `RalphError` string that embeds branch name.
- [ ] Unknown/unrecognized push errors default to non-retryable (`false`), failing immediately instead of delaying with retries.
- [ ] A branch name containing `"403"` or `"500"` does not affect retryability classification (tested).
- [ ] Unknown permanent errors (e.g., `"repository not found"`, unrecognized auth variants) fail without retry (tested).
- [ ] `drain_all_children()` uses `await_watcher_with_timeout()` for both artifact-watcher and draft-PR-watcher joins, matching `collect_children()` and `kill_aborted_children()`.
- [ ] `complete_task(..., "ralph:failed", ...)` in `drain_all_children()` still executes even when a watcher is stuck (bounded by 30s timeout).
- [ ] All existing push-retry tests continue to pass (updated as needed for new signature/behavior).
- [ ] `cargo check` passes with no new warnings.
- [ ] `cargo test` passes.

### `src/daemon/github.rs`

#### 1. New function: `is_retryable_push_stderr(stderr: &str) -> bool`
Replace the existing `is_retryable_push_error(err: &RalphError) -> bool` with a function that takes a raw stderr `&str`:

```rust
pub fn is_retryable_push_stderr(stderr: &str) -> bool {
    let lower = stderr.to_ascii_lowercase();

    // Explicit non-retryable patterns (permanent failures)
    let non_retryable_patterns = [
        "permission denied",
        "authentication",
        "non-fast-forward",
        "protected branch",
        "denied",
        "forbidden",
        "403",
        "gh013",
        "repository rule violation",
        "repository not found",
    ];
    if non_retryable_patterns.iter().any(|p| lower.contains(p)) {
        return false;
    }

    // Explicit retryable patterns (transient failures)
    let retryable_patterns = [
        "500", "502", "503", "504",
        "timeout", "timed out",
        "connection refused", "connection reset",
        "network", "dns", "resolve host",
        "could not resolve", "unable to access",
    ];
    if retryable_patterns.iter().any(|p| lower.contains(p)) {
        return true;
    }

    // Unknown errors are non-retryable to avoid delaying permanent failures.
    false
}
```

fn push_branch_with_git_bin(
    git_bin: &str,
    worktree_path: &Path,
    branch: &str,
) -> Result<(), String> {
    let output = Command::new(git_bin)
        .args(["push", "-u", "origin", branch])
        .current_dir(worktree_path)
        .output()
        .map_err(|err| format!("failed to run git push: {err}"))?;

    if !output.status.success() {
        return Err(String::from_utf8_lossy(&output.stderr).trim().to_string());
    }
    Ok(())
}

#### 4. Update `push_branch_with_retry_impl`
Classify on raw stderr, construct `RalphError` only when giving up:

```rust
fn push_branch_with_retry_impl(
    git_bin: &str,
    worktree_path: &Path,
    branch: &str,
    delays_secs: &[u64],
) -> Result<()> {
    let total_attempts = delays_secs.len() + 1;
    for (attempt_index, delay_secs) in std::iter::once(&0u64).chain(delays_secs.iter()).enumerate() {
        if attempt_index > 0 {
            thread::sleep(Duration::from_secs(*delay_secs));
        }
        match push_branch_with_git_bin(git_bin, worktree_path, branch) {
            Ok(()) => return Ok(()),
            Err(stderr) => {
                let attempt = attempt_index + 1;
                if !is_retryable_push_stderr(&stderr) || attempt == total_attempts {
                    return Err(RalphError::Orchestration(
                        format!("git push failed for branch {branch}: {stderr}")
                    ));
                }
                eprintln!(
                    "push-retry: push failed for branch {branch} in {} (attempt {attempt}/{total_attempts}), retrying in {delay_secs}s: {stderr}",
                    worktree_path.display()
                );
            }
        }
    }
    unreachable!()
}
```

Note: The loop structure needs to be adjusted slightly since the original uses `delays_secs.iter().enumerate()` where attempt 0 uses `delays_secs[0]`. The key behavioral change is: classification uses `is_retryable_push_stderr(&stderr)` on raw stderr only.
