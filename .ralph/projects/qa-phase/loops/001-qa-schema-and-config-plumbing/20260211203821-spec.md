# Feature: QA Schema and Config Plumbing

## Description
Add all data model, configuration, artifact, backend, and CLI plumbing required to support the QA phase. This is the foundational layer that introduces the `Phase::QA` variant, QA-related artifact kinds, QA fields on state structs, QA config keys at all levels (global, project, CLI override), QA backend/role-model support, and the `QaIterationLimitExceeded` error variant. No orchestrator workflow logic is included — this feature ensures the schema compiles, serializes/deserializes correctly, and preserves full backward compatibility with existing state and config files.
