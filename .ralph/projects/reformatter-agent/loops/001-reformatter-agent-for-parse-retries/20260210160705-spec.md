# Feature: Reformatter Agent for Parse Retries

## Description
Modify `execute_with_parse_retries()` in `src/workflow/orchestrator.rs` so that when a backend produces unparseable output, the **opposite backend** (resolved via `BackendRegistry::opposite()` + `BackendRegistry::get()`) is used for the reformat attempt (attempt 2 of 3) instead of the same backend. If the opposite backend is unavailable (single-backend config), fall back gracefully to using the original backend. Add a `registry: &BackendRegistry` parameter to the function signature and thread it through all five call sites. Update logging to identify the reformatter backend. Add a unit test verifying the opposite backend is used for the reformat attempt.

## Acceptance Criteria
- [ ] `execute_with_parse_retries` accepts a new `registry: &BackendRegistry` parameter
- [ ] All five call sites (planner, implementer initial, implementer feedback, reviewer, completer) pass `&registry` to the function
- [ ] Attempt 2 resolves the opposite backend via `registry.opposite(backend.name())` and `registry.get()`, and sends the reformat prompt to that backend
- [ ] If the opposite backend is unavailable (e.g., `opposite()` errors or `get()` returns `None`), the function falls back to using the original backend for attempt 2 (no error raised)
- [ ] Attempt 1 (original prompt to original backend) remains unchanged
- [ ] Attempt 3 (reminded prompt to original backend) remains unchanged
- [ ] Log message for attempt 2 includes the reformatter backend name: `"parse failed, requesting reformat via {reformatter_name} (attempt 2/3)"`
- [ ] A test verifies that the reformatter (attempt 2) uses the opposite backend, not the original backend
- [ ] Existing integration tests continue to pass
- [ ] No changes to `execute_with_timeout_retries`, prompt templates, parser functions, `BackendRegistry`, or `Backend` trait
- [ ] The total number of retry attempts remains 3

## Files to Modify/Create

- `tests/orchestrator.rs` - Add a test that verifies the reformatter agent uses the opposite backend for the reformat attempt (attempt 2)
