## Failures
1. `--dry-run` is not implemented per spec.
- Spec requires: print only the initial draft prompt and stop.
- Code only carries the flag through (`src/cli/quick_prd.rs:94`, `src/prd/quick.rs:35`) but never branches on it in execution (`src/prd/quick.rs:272`, `src/prd/quick.rs:286`).

- Mode is detected (`src/cli/quick_prd.rs:71`) but status logs are always printed unconditionally (`src/cli/quick_prd.rs:74`, `src/cli/quick_prd.rs:100`).
- This misses the requirement that non-interactive mode suppresses status output.
