# Feature: Serial Prompt-Review Panel

## Description
Replace the single-backend prompt-review pre-loop step with a serial multi-backend panel. The first backend in `prompt_review_backends` acts as the **refiner** (same behavior as today — produces `PromptReviewerDecision` with refined prompt). Remaining backends are **validators** that execute serially against the refined prompt and emit `ACCEPT` or `REJECT(<reason>)` verdicts. If any validator rejects, prompt review fails and aggregated reasons are surfaced. The singular `prompt_review_backend` config key is preserved as a backward-compatible alias.
