# Feature: Prompt-Review Optional-Skip & Guard-Ordering Fixes (FR-PR-001 + FR-PR-002)

## Description
Implements the two Round 2 final-review amendments that block project completion:

**FR-PR-001** – The prompt-review orchestrator currently picks only the first configured backend as refiner and skips the entire prompt review if that first backend is optional and unavailable. Instead, the full `prompt_review_backends` list must be resolved first (applying optional-skip semantics to each entry), and then the first *effective* backend becomes the refiner while remaining effective backends become serial validators. An error is raised only if no effective backends remain after filtering.

**FR-PR-002** – The `prompt-original.md` existence guard currently runs *after* `prompt-review.md` is written (line 506 vs line 368). If `prompt-original.md` pre-exists, the run fails but both files now exist, causing lifecycle reconstruction to incorrectly mark prompt review as completed. The guard must execute before any prompt-review artifact writes or validator execution.

- [ ] If no effective backends remain after optional filtering, orchestrator returns an error (not a silent skip)
