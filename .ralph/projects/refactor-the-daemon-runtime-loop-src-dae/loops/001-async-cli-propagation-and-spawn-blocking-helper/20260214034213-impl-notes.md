# Implementation Notes

## Decisions Made
- Added `spawn_blocking_op` in `src/daemon/runtime.rs` to standardize `tokio::task::JoinError` -> `RalphError::Orchestration` mapping for blocking operations.
- Converted daemon CLI entrypoints to async:
  - `src/cli/daemon.rs`: `execute` is now `pub async fn`, `execute_start` is now async.
  - `src/cli/mod.rs`: daemon dispatch now uses `daemon::execute(args).await`.
- Kept `execute_status` and `execute_abort` synchronous and called them from async `execute` via `spawn_blocking_op`.
- Converted `runtime::run` to `pub async fn` while preserving current sync internals by delegating to a new `run_sync(...)` executed through `spawn_blocking_op`.
- Added `#[derive(Clone)]` to `DaemonRuntimeConfig` so owned data can be moved into the blocking closure.
- Left `refine::refine_prompt` unchanged in this loop.
