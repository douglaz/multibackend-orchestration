# Implementation Notes

## Decisions Made
- Added a log-aware backend API path via `Backend::execute_with_log(prompt, Option<&mut LogWriter>)` so retries can stream directly to logs without breaking existing `execute()` callers (`src/backend/mod.rs:33`, `src/workflow/orchestrator.rs:2792`).
- Refactored `CliBackend` execution to chunked byte streaming using `read_buf` + `BytesMut`, writing raw bytes to both in-memory buffer and `LogWriter` as chunks arrive, and only doing `String::from_utf8_lossy` at successful return (`src/backend/mod.rs:187`, `src/backend/mod.rs:298`).
- Implemented explicit timeout/error cleanup with `kill()` + `wait()` and timeout footer logging (`src/backend/mod.rs:155`, `src/backend/mod.rs:305`, `src/output_log.rs:61`, `src/output_log.rs:118`).
- Updated orchestrator retry flow to pass `LogWriter` into backend execution and removed post-hoc output append (`src/workflow/orchestrator.rs:2792`).
- Added timeout footer helpers and byte-preservation tests in logging module (`src/output_log.rs:61`, `src/output_log.rs:259`, `src/output_log.rs:287`, `src/output_log.rs:300`).
- Added unit tests for exact byte preservation and timeout kill/reap verification (`src/backend/mod.rs:685`, `src/backend/mod.rs:716`).
- Added streaming conformance tests `mid_execution_visibility` and `timeout_cleanup`, plus dedicated mock scripts (`src/validate/tests_streaming.rs:25`, `src/validate/tests_streaming.rs:187`, `src/validate/tests_streaming.rs:258`, `src/validate/mock_scripts.rs:1290`, `src/validate/mock_scripts.rs:1406`).
- Added direct `bytes` dependency (`Cargo.toml:10`).
