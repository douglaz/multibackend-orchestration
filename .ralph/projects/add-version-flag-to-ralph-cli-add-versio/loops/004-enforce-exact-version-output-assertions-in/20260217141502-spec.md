# Feature: Enforce Exact Version Output Assertions in Commands Conformance Tests

## Description
Core behavior is already implemented: `Cli` has `#[command(version)]`, `assert_stdout_eq` exists, and version tests are registered.  
The remaining gap is conformance strictness: `commands::version_long_flag` and `commands::version_no_workspace` currently validate only output shape (`"ralph "` prefix) instead of exact output from `format!("ralph {}", env!("CARGO_PKG_VERSION"))`. This feature restores the exact assertions required by the project prompt and closes the completion blocker.

- [ ] Existing `assert_stdout_eq` helper remains the assertion primitive for exact stdout checks (no duplicate helper added).
