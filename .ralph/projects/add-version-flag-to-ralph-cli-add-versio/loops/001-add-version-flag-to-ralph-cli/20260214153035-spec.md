# Feature: Add `--version` flag to Ralph CLI

## Description
Add global CLI version support to `ralph` using Clap's built-in `#[command(version)]` derive attribute. This enables `ralph --version` and `ralph -V` to print the package version and exit with code `0`, without requiring an initialized workspace. Additionally, add an `assert_stdout_eq` helper to the test assertions module and implement three conformance tests validating long flag, short flag, and no-workspace behavior.

## Acceptance Criteria
- [ ] `#[command(version)]` is added to the `Cli` struct in `src/cli/mod.rs`
- [ ] `ralph --version` exits `0` and prints `ralph <Cargo.toml package version>`
- [ ] `ralph -V` exits `0` and produces identical output to `--version`
- [ ] `--version` works without an initialized `.ralph/` workspace
- [ ] `assert_stdout_eq` helper is added to `src/validate/assertions.rs` with exact-match semantics (trimmed comparison)
- [ ] `version_long_flag` test is added to `src/validate/tests_commands.rs` — asserts exit code `0` and stdout equals `format!("ralph {}", env!("CARGO_PKG_VERSION"))`
- [ ] `version_short_flag` test is added — asserts `-V` exit code `0` and trimmed stdout matches `--version` output
- [ ] `version_no_workspace` test is added — runs without `h.init_workspace()`, asserts exit code `0` and correct stdout
- [ ] All three test entries are registered in the `tests()` function
- [ ] `nix develop -c cargo check` passes
- [ ] `nix build -L` succeeds
- [ ] `./result/bin/ralph validate --bin ./result/bin/ralph --filter commands::version_` passes all three tests

## Files to Modify/Create
- `src/cli/mod.rs` — Add `#[command(version)]` attribute to the `Cli` struct (alongside existing `name` and `about` attributes)
- `src/validate/assertions.rs` — Add `assert_stdout_eq` public function that trims and compares stdout against an expected string
- `src/validate/tests_commands.rs` — Register `commands::version_long_flag`, `commands::version_short_flag`, and `commands::version_no_workspace` in `tests()` and implement all three test functions using `run_case`, `RalphHarness`, `assert_exit_code`, and `assert_stdout_eq`
