# Implementation Notes

## Decisions Made
- Added Clap global version handling via `#[command(version)]` on `Cli` in `src/cli/mod.rs` so `ralph --version` and `ralph -V` are handled before workspace-dependent logic.
- Added `assert_stdout_eq` to `src/validate/assertions.rs` with trimmed exact-match semantics, matching the required helper contract.
- Added and registered three conformance tests in `src/validate/tests_commands.rs`:
- `commands::version_long_flag` checks exit code `0` and stdout equals `format!("ralph {}", env!("CARGO_PKG_VERSION"))`.
- `commands::version_short_flag` checks `-V` exit code `0` and trimmed stdout matches `--version`.
- `commands::version_no_workspace` skips `h.init_workspace()` and verifies `--version` still exits `0` with correct stdout.
