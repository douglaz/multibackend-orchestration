# Implementation Notes

## Decisions Made

### Shared Global Config Mutator (`set_global_config_value`)
- Added `pub(crate) fn set_global_config_value(config: &mut GlobalConfig, key: &str, raw_value: &str) -> Result<()>` to `src/config/global.rs` (~280 lines of match arms covering all global config keys).
- Added `pub(crate) fn backend_config_mut(&mut self, name: &str) -> Result<&mut BackendConfig>` on `GlobalConfig` to provide mutable access to backend configs by name.
- All parsing helpers prefixed with `cfg_` (e.g., `cfg_parse_bool`, `cfg_parse_u32`, `cfg_parse_backend_enabled`) to avoid name collision with existing local helpers in `cli/config.rs` that are still needed for project-scoped config setters.
- Re-exported via `pub(crate) use global::set_global_config_value;` in `src/config/mod.rs`.

### CLI Delegation
- Replaced the entire body of `cli::config::set_global_value` with a single delegation call: `crate::config::set_global_config_value(config, key, raw_value)`.
- Removed three now-dead CLI-local functions: `parse_backend_enabled`, `set_backend_model`, `set_role_timeout`.
- Updated two existing tests (`set_role_timeout_sets_and_clears_supported_role` and `set_role_timeout_rejects_unknown_role`) that referenced the removed functions to instead exercise the same behavior through `set_global_value` with full key paths (e.g., `backends.claude.role_timeouts.acceptance_qa`).
- Project-scoped setter (`set_project_value`) and its `parse_optional_*` local helpers are intentionally untouched.

### Fast Harness Helpers
- `init_workspace_fast()` — calls `crate::cli::init::create_workspace(&ralph_root)` using the production API (plan_actions + execute_actions + Workspace::load), avoiding process spawn.
- `create_project_fast(id, name, prompt)` — writes a prompt file, loads the Workspace, and calls `crate::project::lifecycle::create_project(...)` with `PromptSource::File`.
- `set_config_fast(key, value)` — loads Workspace, calls `set_global_config_value`, saves via `workspace.save_config()`.
- `setup_mock_backends_fast(script)` — delegates to `set_config_fast` three times (claude.command, codex.command, gemini.enabled=false).

### Env-Removal Command Helper
- `ralph_env_with_removals(args, env_vars, env_removals)` — like `ralph_env` but additionally calls `command.env_remove(key)` for each entry in `env_removals`.

### Tests
- **Shared mutator parity tests** (7 tests in `config::global::tests`):
  - `shared_mutator_sets_workspace_fields` — workspace.default_backend, tmux, tmux_session, tmux_window_keep_seconds, daemon_poll_seconds, daemon_max_concurrent, daemon_labels, daemon_repo (set and clear-to-null).
  - `shared_mutator_sets_workflow_fields` — max_review_iterations, auto_commit, commit_message_style, prompt_change_action, qa_enabled, max_qa_iterations, planner_state_in_prompt, planner_previous_specs_in_prompt, planner_max_prior_loops (integer and "none"), session_reuse_enabled, session_reuse_roles.
  - `shared_mutator_sets_backend_fields` — claude.command, claude.timeout_seconds, codex.args (JSON), gemini.enabled (false/auto), claude.models.planner (set and clear), claude.role_timeouts.planner (set and clear).
  - `shared_mutator_sets_template_and_git_fields` — templates.planner, templates.qa, git.base_branch, git.auto_branch, git.sign_commits, git.branch_format.
  - `shared_mutator_rejects_unknown_key`, `shared_mutator_rejects_invalid_bool`, `shared_mutator_rejects_invalid_integer` — error-path coverage.
- **Env-removal tests** (2 tests in `validate::harness::tests`):
  - `env_removal_removes_variable_from_child` — sets and removes same var, confirms absent in child env.
  - `env_removal_preserves_non_removed_variables` — confirms kept vars present, removed vars absent.
