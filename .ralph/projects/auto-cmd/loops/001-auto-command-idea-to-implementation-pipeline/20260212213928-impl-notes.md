# Implementation Notes

## Decisions Made
- Added `src/cli/auto.rs` with:
  - `AutoArgs` (`clap::Args`) covering all required flags (`--idea`, `--spec-writer`, `--spec-reviewer`, `--max-spec-revisions`, project/run passthrough flags, `--tmux`/`--no-tmux`, `--dry-run`).
  - Non-empty `--idea` validation at parse-time (`value_parser`) and runtime guard.
  - `slugify_idea(idea: &str) -> String` implementing lowercase, dash normalization/collapse, trim, 40-char truncation, and trailing-dash cleanup.
  - `execute(args)` with 3 phases:
    1. quick-prd generation (tmux-disabled `BackendRegistry`, backend validation, backend health checks, `QuickPrdPipeline` run, summary printing)
    2. project creation (`create_project`, slugified/explicit id, 60-char name, `PromptSource::File(spec_path)`, optional starting backend)
    3. orchestration run (`Workspace::discover()` מחדש, `Orchestrator::run`, `until_complete: true`, role/tmux/skip-commit passthrough)
  - `--dry-run` short-circuit after phase 1 (prints generated spec and exits before create/run).
- Added all required unit tests in `src/cli/auto.rs`:
  - `test_slugify_idea_basic`
  - `test_slugify_idea_special_chars`
  - `test_slugify_idea_truncation`
  - `test_slugify_idea_consecutive_dashes`
  - `parses_auto_command_with_defaults`
  - `parses_auto_command_with_all_args`
  - `rejects_auto_with_empty_idea`
- Updated `src/cli/mod.rs`:

  - dispatch arm `Commands::Auto(args) => auto::execute(args).await`
