# Implementation Notes

## Decisions Made
- Updated `src/daemon/refine.rs` prompt instructions to require the 3-section format, including explicit cleaned-body constraints (no title, preserve structure, light edits only, exact delimiter order).
- Extended `RefinedPrompt` with `cleaned_body: Option<String>` and updated `parse_refined_output` to:
  - detect `=== CLEANED BODY ===` only on standalone trimmed lines,
  - split on the first standalone delimiter only,
  - keep strict `body` validation via existing `validate_output`,
  - degrade invalid/missing/too-short cleaned body to `None` via best-effort validation.
- Added `update_issue_body(owner, repo, issue_number, body)` to `src/daemon/github.rs` using `gh issue edit --body`.
- Updated dispatch flow in `src/daemon/runtime.rs` to destructure `cleaned_body` and perform best-effort issue-body update after title update, logging warning on failure and never aborting dispatch.
- Kept existing behavior intact:
  - `refined-prompt` comment still uses only title + structured `body`,
  - `ralph auto --idea` still receives only structured `body`,
  - no `cleaned_body` persistence in task state.
- Added required parser unit tests in `src/daemon/refine.rs`:
  - `parse_refined_output_three_section_success`
  - `parse_refined_output_no_cleaned_body_fallback`
  - `parse_refined_output_empty_cleaned_body_degraded`
  - `parse_refined_output_cleaned_body_preserves_structure`
  - `parse_refined_output_delimiter_in_content_not_split`
  - `parse_refined_output_multi_delimiter_first_split_point`
- Added required conformance tests in `src/validate/tests_daemon.rs` and registered them:
  - `daemon::refinement_cleaned_body_dispatched`
  - `daemon::refinement_no_cleaned_body_skips_edit`
  - `daemon::refinement_cleaned_body_failure_non_blocking`
